# Контент курса «Генеративный ИИ на практике»

Здесь живёт поурочный контент курса: слайд-планы, сценарии комиксов и вспомогательные файлы.

Семестры на платформе — **два отдельных курса**:

- **Курс 1 (семестр 1) — «Раскуривание древних машин».** Разговор с ИИ, промпты, данные из архивов.
  Итог — диагностический отчёт о состоянии завода.
- **Курс 2 (семестр 2) — «Воскрешение Электроника-84».** Химические рецептуры, агенты и MCP, локальные
  модели. Итог — завод снова работает.

## Как собрано занятие (пилот — `sem1/01-dobro-pozhalovat-v-apparatnuyu/`)

В папке занятия:
- `slides-plan.md` — план всех слайдов: тип (из `slides.md`), название, краткое содержание, поля.
  `welcome`/`congrats` сюда не входят — они на уровне своего курса (`sem1/course-slides.md`
  или `sem2/course-slides.md`).
- `comic.md` — по-панельный сценарий комиксов для `image_group`-слайдов.
- `files/` — дополнительные файлы: системные промпты персонажей, квизы, памятки (позже — данные/код).
- `links.md` — внешние ссылки и источники.
- `videos/` — **программы**, генерирующие видеоролики для `video`-слайдов (Manim для технических,
  доработанный pygame для остальных; подробности — в `_shared/video-guide.md`).

## Порядок работы

1. Для каждого занятия заполняется `slides-plan.md` по шаблону `_shared/slides-plan-template.md`.
2. Пишется `comic.md` (сюжет на `image_group`-слайдах ведёт всю историю).
3. Генерируются/подбираются файлы в `files/` и ссылки в `links.md`.

Остальные 31 занятие пока содержат README-заглушку с планом — контент генерируется по шагам.
