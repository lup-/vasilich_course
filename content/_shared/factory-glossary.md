# Заводской словарик

> Как говорят на заводе «БытХимИскИнДеталь» (2120 год). Источник правды по терминологии: в текстах,
> репликах, комиксах и файлах занятий используем заводские слова, а не «наши». Опирается на
> `world-bible.md`. Фразочки Василича — в `vasilich-phrases.md`.

## Словарь

| Заводское слово | Что это на самом деле |
|-----------------|-----------------------|
| **Аппаратная** | Комната с компьютерами и серверами (для нас — «серверная»). Заводчане говорят только «аппаратная». |
| **Мозги** | Процессор, «ум» машины. «Мозги завода» — сам ИИ «Электроник-84». |
| **Древние машины / древний ИИ** | Наши реальные технологии: LLM (ChatGPT, Claude…), Python, Jupyter, pandas, Ollama. Для людей 2120 года — артефакты далёкого прошлого. |
| **Макбук времён дедов** | Старый ноутбук, на котором установлена модель «Василич-5.7». |
| **Архив** | Базы данных и документы завода: CSV, Excel, PDF, JSON. |
| **Рецептурная книга** | Химические данные завода: SMILES, SDF, PubChem. |
| **Раскуривать** | Разбираться, осваивать что-то сложное («раскуривание древних машин»). |
| **Дать дуба / доиграться на скрипке** | Сломаться (про технику или ИИ). |
| **Изолента** | Универсальный крепёж и «заплатка» для всего; заодно — эвфемизм в ругательствах («твою ж изоленту»). |
| **Железо** | Компьютерная техника, «начинка» машин. |
| **Черт / черти** | Компьютер или ИИ. Так их зовут Василич и заводчане в разговоре («Вытащи из этого черта все данные!»). Бабушка Алиса своих машин «чертями» не зовёт — у неё «фиксики». |
| **Фиксик / фиксики** | Компьютер или ИИ. Так их ласково зовёт бабушка Алиса (вместо «чертей», которые у Василича): «Ох, деточка, фиксики у нас на весь завод завелись». См. `alisa-phrases.md`. |
| **Айсик** | Ещё более нежное прозвище ИИ (от «ИИ») в устах бабушки Алисы — в тёплые моменты: «Ох, айсик-то наш как старался». См. `alisa-phrases.md`. |
| **Черемша** | Непонятная сущность («непойми что») или медленный, но верный процесс. Так Василич и бабушка Алиса говорят вместо «черт/черти». См. `vasilich-phrases.md`, `alisa-phrases.md`. |
| **Бригада / смена** | Рабочие группы завода. Стажер закреплён за бригадой Василича. |

## Правила употребления

- «Серверную» в материалах курса не пишем — только **«аппаратная»**. Аппаратной заведует **бабушка Алиса**
  (персонаж — в `world-bible.md`, речь — в `alisa-phrases.md`).
- **«Черти»** — это только речь персонажей: компьютеры и ИИ так зовут Василич и иногда другие заводчане.
  Бабушка Алиса зовёт их «фиксиками», в тёплые моменты — «айсиком» (см. `alisa-phrases.md`).
  В основных материалах курса (теория, слайды, промпты, задания) используем нейтральные термины:
  **«ИИ», «LLM», «модель», «древняя машина»**.
- Модель «Василич-5.7» живёт в аппаратной на «макбуке времён дедов».
- Данные завода — всегда «архив», химия — «рецептурная книга».
- Разбираться в технологиях — «раскуривать».

## Как вводить новые слова

- Слово добавляем в этот словарь, только если оно уже встречается (или будет встречаться) в материалах курса.
- В занятии, где слово вводится впервые, даём «перевод» через реплику персонажа или примечание.
