Провайдеры без региональных ограничений для России. Любой бесплатный тариф достаточен для курса:

- **DeepSeek** (DeepSeek-V3/R1): чат — https://chat.deepseek.com, API — https://platform.deepseek.com
- **Qwen** (Alibaba): чат — https://chat.qwen.ai, API (DashScope) — https://dashscope.console.aliyun.com
- **OpenRouter** (агрегатор моделей: DeepSeek, Qwen, Llama и др.): https://openrouter.ai
- **Groq** (быстрый бесплатный инференс открытых моделей): https://groq.com
- **GigaChat** (Сбер): https://developers.sber.ru/gigachat
- **YandexGPT** (API в Yandex Cloud): https://cloud.yandex.ru/services/yandexgpt
- **Hugging Face** (чат с открытыми моделями): https://huggingface.co/chat
