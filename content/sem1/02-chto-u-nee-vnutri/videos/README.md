# Видеоролики занятия 02. «Что у неё внутри»

> Все ролики — это Python-программы, которые генерируют видео (см. `_shared/video-guide.md`).
> Студент запускает программу и проверяет результат; готовый MP4 подключается в поле `video_url`
> соответствующего `video`-слайда.

## Ролики

| Файл | Движок | Слайд | Что показывает |
|---|---|---|---|
| `manim/03-tokenizaciya.py` | ManimCE | 3 | Технический ролик «Фраза → токены → дополнение»: фраза «Без труда не вытащишь и рыбку из пруда» (поговорка бабушки Алисы) нарезается на токены-под-слова с ID, затем модель циклически дополняет текст токен за токеном — «рыбку», «из», «пруда», «.» |
| `manim/06-rnn-i-transformer.py` | ManimCE | 6 | Технический ролик «Узкое горлышко против матрицы внимания»: заводская фраза «Клей для цеха испорчен. Нужно выкинуть ___». Часть 1 — рекуррентная сеть (RNN): единственный блок «ПАМЯТЬ» обходит токены по одному, слова-чипы ложатся в него стопкой; старые чипы поднимаются, выцветают и улетают из памяти, а пройденные слова ряда блекнут — модель «забывает» начало и предлагает «выкинуть цех»; часть 2 — LSTM: у блока памяти три ворота — входные пропускают слова в память или отбрасывают («.» и «нужно»), ворота забывания удаляют неактуальное («для», «цеха»), выходные собирают важные для генерации слова — «клей» сохраняется и ответ верный (по ходу LSTM-части показываются чёрные карточки-пояснения для каждого типа ворот); экраны проблем после каждой архитектуры (у LSTM проблема памяти зачёркнута — решена); часть 3 — трансформер: общий блок внимания охватывает все токены сразу, слова расставлены по кругу и связаны каждое с каждым, выделяется связь со словом «клей» — модель отвечает верно. Финал: «на трансформерах стоят все современные языковые модели» |

## Как запустить ролик 03

Требуется установленный **ManimCE** (https://www.manim.community/).

```bash
# из папки занятия:
cd videos/manim
manim -r 1920,1080 --fps 30 03-tokenizaciya.py Tokenizaciya
```

Ролик выйдет примерно 105–110 секунд, 30 fps, разрешение 1920×1080. Отрендеренный файл — это то, что нужно
загрузить на платформу как `videos/03-tokenizaciya.mp4` и указать в `video_url` слайда 3
(`video_type: direct`).

## Как запустить ролик 06

```bash
# из папки занятия:
cd videos/manim
manim -r 1920,1080 --fps 30 06-rnn-i-transformer.py RNNvsTransformer
```

Ролик выйдет примерно 95–105 секунд, 30 fps, разрешение 1920×1080. Отрендеренный файл — `videos/06-rnn-i-transformer.mp4`,
указывается в `video_url` слайда 6 (`video_type: direct`).
