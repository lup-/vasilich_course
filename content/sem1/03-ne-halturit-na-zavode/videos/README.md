# Видеоролики занятия 03. «Не халтурить на заводе»

> Ролик генерируется Python-программой (см. `_shared/video-guide.md`): агент пишет сценарий кодом,
> студент запускает и проверяет результат; готовый MP4 подключается в поле `video_url`
> соответствующего `video`-слайда.

## Сценарий ролика

| Слайд | Движок | Что показывает |
|---|---|---|
| 3 | ManimCE | Технический ролик «Уверенно, но неверно»: модель «выдумывает» факт про завод (сколько тонн глицерина отгрузили 13 февраля 2099 года) токен за токеном по вероятностям, ответ выглядит уверенно (137 тонн, накладная №88-90), сверка с накладными из архива ничего не находит. Вывод: «УВЕРЕННО ≠ ПРАВИЛЬНО. ВЫВОД ИИ — ЧЕРНОВИК. ПРОВЕРЯЙ» |

Полный по-кадровый сценарий (~70 с) — в `slides-plan.md`, раздел «Видео: план ролика».
Отрендеренный файл подключается как `videos/03-gallyucinaciyu.mp4` в `video_url` слайда 3
(`video_type: direct`).

## Запуск

### «Уверенно, но неверно» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 3 03-gallyucinaciyu.py Gallyucinaciyu
```

- **Что проверять:** 5 кадров (~70 с), надписи читаемы, сцена «модель дописывает ответ токен за токеном
  по вероятностям» наглядна, сверка с архивом понятна, финальная мысль
  «УВЕРЕННО ≠ ПРАВИЛЬНО. ВЫВОД ИИ — ЧЕРНОВИК. ПРОВЕРЯЙ».
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный + кислотно-зелёный люминофор), чёрный
  контур, надписи заглавными рубленым шрифтом.
- Отрендеренный файл — `videos/03-gallyucinaciyu.mp4`, указывается в `video_url` слайда 3
  (`video_type: direct`).

> Если ролик ещё не собран — теорию закрывают слайд 2 (метафора Алисы) и слайд 4
> (формальное определение рисков).
