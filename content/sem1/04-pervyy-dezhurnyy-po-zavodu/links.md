# Ссылки занятия 04 «Первый дежурный по заводу»

## Теория (исходники курса — `prepared/`)

- `prepared/course-01-generative-ai/lectures/06-text-generation-apps.md` — приложения генерации текста:
  промпт, температура, токены, библиотека `openai`, секреты (база слайдов 2 и 10).
- `prepared/course-01-generative-ai/lectures/07-building-chat-applications.md` — чат-приложения,
  память диалога, системный промпт (база слайдов 3–5, 8).
- `prepared/course-01-generative-ai/assignments/07-building-chat-applications/` — практика по лекции 07
  (база слайдов 7, 13).

## Документация и инструменты

- https://opencode.ai/docs/ — установка и первые шаги с opencode (слайд 11, `embed`).
- https://openrouter.ai/collections/free-models — каталог бесплатных моделей OpenRouter (проверяем
  перед запуском, что слог `:free` ещё бесплатный).

## Платформы бота (слайды 10, 13)

- **Telegram:**
  - https://t.me/BotFather — получение токена бота (команда `/newbot`).
  - https://docs.aiogram.dev/ — документация библиотеки `aiogram` (асинхронный Telegram Bot API).
- **ВКонтакте:**
  - https://vk.com/dev/bots — обзор Bots API ВКонтакте.
  - https://vk.com/dev/bots_longpoll — Bots Long Poll API (получение событий без сервера).
  - https://github.com/python273/vk_api — библиотека `vk-api` (метод `VkBotLongPoll`).
