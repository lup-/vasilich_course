# Видео занятия 04 «Первый дежурный по заводу»

## Список роликов

| Файл | Движок | Слайд | Что показывает |
|---|---|---|---|
| `manim/04-pamyat-dialoga.py` | Manim (ManimCE) | 3 | Память диалога и окно контекста: каждый запрос уходит к модели вместе с системным промптом и всей историей сообщений; ответ добавляется в историю; когда история перерастает окно контекста — старые сообщения выпадают, модель «забывает» начало |

## Запуск

### «Память диалога» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 4 04-pamyat-dialoga.py PamyatDialoga
```

- **Что проверять:** 6 кадров (~85 с), надписи читаемы, схема «инструкция + история → модель → ответ
  → в историю» понятна, кадр про окно контекста нагляден (рамка окна, бюджет токенов, старейшее
  сообщение выпадает), финальная мысль «ПАМЯТЬ = ИСТОРИЯ В ЗАПРОСЕ, НО ОКНО КОНЕЧНО».
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный + кислотно-зелёный люминофор), чёрный
  контур, надписи заглавными рубленым шрифтом.
- Отрендеренный файл — `videos/04-pamyat-dialoga.mp4`, указывается в `video_url` слайда 3 (`video_type: direct`).
