# Квиз «Что даёт RAG»

> Материал для `quiz`-слайда 13 занятия 05 (по лекции 15 курса-01).

## Вопрос

**Что даёт генерация с расширением поиска (RAG)?**

Выбери один правильный вариант.

## Варианты

- Модель навсегда запоминает все документы завода и знает их и без поиска — `is_correct: false`
- Модель отвечает по проверяемым документам из базы знаний — меньше выдумок, и ответ можно сверить
  с источником — `is_correct: true`
- RAG заменяет модель на новую, которая уже выучила данные завода — `is_correct: false`

## Объяснение

RAG не даёт модели личной памяти и не переучивает её: на каждый вопрос машина ищет в базе знаний
(индексе эмбеддингов) самые близкие документы-чанки и отвечает по ним. Поэтому ответ актуален,
его можно проверить по источнику, а галлюцинаций меньше. Переучивать модель (fine-tuning)
при этом не нужно — это дешевле.
