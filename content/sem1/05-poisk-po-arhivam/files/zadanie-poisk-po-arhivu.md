# Задание «Собери поиск по архиву» (RAG)

> Материал для `open_question`-слайда 14 занятия 05. Краткая версия задания уже в `markdown` слайда;
> здесь — полный текст для человека, который проверяет работу, и детали для агента-исполнителя.
> Ответ на контрольный вопрос проверяется автоматически по эталону (ниже).

## Суть

Собрать через ИИ-агента **поиск по архиву (RAG)** по корпусу «документов завода» из
`files/dokumenty-arkhiva/`, ответить на контрольный вопрос (требует склейки четырёх документов),
сверить ответ с исходниками и сравнить с наивным поиском по словам. Ответ вводится на слайде 14
и проверяется автоматически.

## Что описать агенту (словами, код не писать)

1. **Индекс:** прочитать все документы из папки `dokumenty-arkhiva`, разрезать на чанки, превратить
   каждый чанк в эмбеддинг бесплатной локальной моделью `sentence-transformers`
   (`intfloat/multilingual-e5-small`), сложить векторы в индекс.
2. **Ответ по вопросу:** вопрос → эмбеддинг → топ-3 самых близких чанка по косинусному сходству →
   системный промпт «отвечай по приложенным документам, не выдумывай» → бесплатная модель OpenRouter
   `nvidia/nemotron-3-super-120b-a12b:free` отвечает по контексту.
3. **Сравнение:** наивный поиск по ключевым словам (совпадения слов) — для наглядной разницы.
4. **Секреты:** ключ OpenRouter — только в `.env`; файл `.env.example` с пустым ключом; `.env`
   не показывать.

## Требования к коду (что должен сделать агент)

- `search_archive.py` (или несколько файлов) — скрипт: сборка индекса + ответ на вопрос + сравнение
  с поиском по словам. Читает документы из папки `dokumenty-arkhiva`.
- `requirements.txt`: `sentence-transformers`, `openai` (клиент для OpenRouter), `python-dotenv`.
- `.env.example`: `OPENROUTER_API_KEY=`.
- Без жёстких ключей в коде; модель по умолчанию — `nvidia/nemotron-3-super-120b-a12b:free`;
  эмбеддинг-модель — `intfloat/multilingual-e5-small`.

## Контрольный вопрос

> **«Сколько мешков порошка останется на складе в конце месяца, если цех №7 стирает по 40 комплектов
> каждый день, пополнение идёт по приказу №14, а на начало месяца на складе было 4 мешка?»**

Правильный ответ (эталон для проверки):

- расход: 40 комплектов × 30 рабочих дней = **1200 комплектов** в месяц; по инструкции цеха №7
  (1 мешок на 100 комплектов) → **12 мешков уйдёт**;
- наличие: 4 мешка (остатки на 01.02) + 10 мешков (приказ №14) = **14 мешков есть**;
- итог: 14 − 12 = **2 мешка останется**.

Склейка четырёх документов: инструкция (расход) + график (30 рабочих дней) + приказ №14 (закупка)
+ остатки склада. Без любого из них ответ неполный. Вопрос устроен так, чтобы его нельзя было
ответить, просто взглянув на содержимое файлов: цифры и нормы разбросаны по документам, и нужна
арифметика.

## Как проверить

1. Собрать файлы из ответа агента у себя на компьютере, создать `.env`, установить зависимости.
2. Запустить скрипт, задать контрольный вопрос.
3. Сверить ответ с исходниками (файлы в `dokumenty-arkhiva`).
4. Посмотреть результат наивного поиска по словам и описать разницу.
5. Убедиться, что в коде нет ключей.
6. Ввести ответ на слайде 14 — он проверится автоматически.
