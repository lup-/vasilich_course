## Запуск

### «Мама, откуда взялись эмбеддинги?» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 5 05-embeddings-train.py Chisla
```

- **Что проверять:** корпус текстов с номерами токенов читается; 3D-сцена разделена на две колонки —
  слева «колесо предложений» (текущее в центре, предыдущее сверху и следующее снизу — меньше и
  полупрозрачно, прокручиваются), баннер с «???» на отдельной строке; справа сетка 6×6×6 с 29
  точками-токенами; 15 шагов обучения: чёрные карточки-пояснения («МОДЕЛЬ УГАДЫВАЕТ СЛОВО»,
  «ПОЗИТИВНОЕ СЭМПЛИРОВАНИЕ», «НЕГАТИВНОЕ СЭМПЛИРОВАНИЕ», «ОБУЧЕНИЕ ЗАКАНЧИВАЕТСЯ»); пролёт
  подписи из 3D в строку «???», вердикт «УГАДАЛА!/НЕ УГАДАЛА»; при промахе — стрелки и притяжение
  к центру; в финале 29 точек перекрашиваются в 4 кластера (СТИРКА/ХИМИЯ/РАСЧЁТ/УЧЁТ), легенда
  слева, 8 ключевых подписей; стрелка к «ПОРОШОК» с координатами → «эмбеддинг»; финал: 384
  измерения (~130 с).
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный + кислотно-зелёный люминофор), чёрный
  контур, надписи заглавными рубленым шрифтом.
- Отрендеренный файл — `videos/05-embeddings-train.mp4`, указывается в `video_url` слайда 3 (`video_type: direct`).

### «RAG: вопрос → вектор → поиск → модель» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 5 05-rag.py RagArkhyv
```

- **Что проверять:** 5 сцен (~75 с), поток «вопрос → 3D-индекс (4 чанка) → усреднение слов в
  векторы → расстояния → топ-2 (НАКЛАДНАЯ, ВЕДОМОСТЬ) → схема RAG (диалог + векторная база +
  модель, вопрос и топ-2 чанка с системным промптом уходят в модель, ответ «ЕСТЬ 2 МЕШКА»
  возвращается в диалог) → «без архива — из головы» (модель без документов отвечает с выдумкой,
  «ПРОВЕРЯЙ!») → финальная мысль «RAG = ВОПРОС + ДОКУМЕНТЫ ИЗ АРХИВА → ОТВЕТ ПО ИСТОЧНИКАМ».
  Подписи слов вопроса — зелёные, расстояния в индексе подписаны числами, топ-2 подсвечены
  зелёным.
- **Стиль:** как в первом ролике занятия.
- Отрендеренный файл — `videos/05-rag.mp4`, указывается в `video_url` слайда 8 (`video_type: direct`).
