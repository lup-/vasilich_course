# Видео занятия 05 «Поиск по архивам»

## Список роликов

| Файл | Движок | Слайд | Что показывает |
|---|---|---|---|
| `manim/05-embeddings.py` | Manim (ManimCE) | 3 | Эмбеддинги: смысл в числах — слова текста становятся точками; близкие по смыслу (используемые вместе) — рядом (облако слов); оси — у точек есть координаты; облако слов = индекс эмбеддингов; вектор из начала координат с числами |
| `manim/05-chisla.py` | Manim (ManimCE) | 5 | Что значат числа в эмбеддинге — координата «как будто» признак (упрощение); оси «научность» и «вещество» (псевдо-3D); честно: число — смесь признаков; у e5-small 384 числа |
| `manim/05-rag.py` | Manim (ManimCE) | 10 | RAG: дежурный ищет в архиве — вопрос → вектор → поиск в индексе → топ-3 чанка → контекст + вопрос → модель → ответ по документам; для сравнения — «из головы» без архива |

## Запуск

### «Эмбеддинги: смысл в числах» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 5 05-embeddings.py Embeddings
```

- **Что проверять:** 5 кадров (~45 с), надписи читаемы, слова превращаются в точки и близкие по смыслу
  ложатся рядом (два «облака»), оси появляются из начала координат, кадр «облако = индекс эмбеддингов»
  на месте, вектор к «ПОРОШОК» с числами понятен, финальная мысль «БЛИЗКИЙ СМЫСЛ — БЛИЗКИЕ ВЕКТОРЫ».
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный + кислотно-зелёный люминофор), чёрный
  контур, надписи заглавными рубленым шрифтом.
- Отрендеренный файл — `videos/05-embeddings.mp4`, указывается в `video_url` слайда 3 (`video_type: direct`).

### «Что значат числа в эмбеддинге» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 5 05-chisla.py Chisla
```

- **Что проверять:** 5 кадров (~46 с), надписи читаемы, упрощение «координата = признак» честно
  перекрыто кадром «это смесь признаков (НАУЧНОСТЬ · ЦВЕТ · ГЛЯНЦЕВОСТЬ)», оси «научность»/«вещество»
  выглядят как условный псевдо-3D, в финале — «у нашей модели 384 числа».
- **Стиль:** как в первом ролике занятия.
- Отрендеренный файл — `videos/05-chisla.mp4`, указывается в `video_url` слайда 5 (`video_type: direct`).

### «RAG: дежурный ищет в архиве» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 5 05-rag.py RagArkhyv
```

- **Что проверять:** 6 кадров (~74 с), поток «вопрос → индекс → топ-3 → контекст + вопрос → модель →
  ответ по документам» читается, кадр «без архива — из головы» нагляден (цифра «плывёт», крестик
  «ПРОВЕРЯЙ»), финальная мысль «RAG = ВОПРОС + ДОКУМЕНТЫ ИЗ АРХИВА → ОТВЕТ ПО ИСТОЧНИКАМ».
- **Стиль:** как в первом ролике занятия.
- Отрендеренный файл — `videos/05-rag.mp4`, указывается в `video_url` слайда 10 (`video_type: direct`).
