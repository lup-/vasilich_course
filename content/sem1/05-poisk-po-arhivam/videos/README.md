## Запуск

### «Эмбеддинги: смысл в числах» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 5 05-embeddings.py Embeddings
```

- **Что проверять:** 5 кадров (~45 с), надписи читаемы, слова превращаются в точки и близкие по смыслу
  ложатся рядом (два «облака»), оси появляются из начала координат, кадр «облако = индекс эмбеддингов»
  на месте, вектор к «ПОРОШОК» с числами понятен, финальная мысль «БЛИЗКИЙ СМЫСЛ — БЛИЗКИЕ ВЕКТОРЫ».
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный + кислотно-зелёный люминофор), чёрный
  контур, надписи заглавными рубленым шрифтом.
- Отрендеренный файл — `videos/05-embeddings.mp4`, указывается в `video_url` слайда 3 (`video_type: direct`).

### «Что значат числа в эмбеддинге» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 5 05-chisla.py Chisla
```

- **Что проверять:** корпус с номерами токенов читается; 3D-сцена разделена на две колонки — слева весь
  текст: «колесо предложений» — текущее предложение в центре, предыдущее сверху и следующее снизу
  (мельче и полупрозрачно, прокручиваются вверх), баннер предложения с «???» строго на отдельной строке, вердикт; справа сетка 6×6×6 с
  29 случайными точками-токенами; 15 шагов обучения:
  0) четыре чёрные карточки (~5 с): перед 1-м угадыванием — «МОДЕЛЬ УГАДЫВАЕТ СЛОВО» (выбирает ближайшее к центру группы слов), «ПОЗИТИВНОЕ СЭМПЛИРОВАНИЕ» (слова рядом притягиваются к центру), «НЕГАТИВНОЕ СЭМПЛИРОВАНИЕ» (горстку случайных «неправильных» слов отталкиваем, чтобы не слиплись в точку) и, перед финалом, «ОБУЧЕНИЕ ЗАКАНЧИВАЕТСЯ» (3-5 прогонов либо остановка обучения);
  1) в 3D сначала появляется точка-центр контекста, затем линия от центра к догадке (с правильной 3D-подписью);
  2) подпись догадки пролетает из 3D в строку «???» в левом баннере в нейтральном бежевом цвете;
  3) слово мигает, затем окрашивается в зелёный (успех) или красный (промах), пауза и поверх центрального предложения появляется плашка вердикта «УГАДАЛА!/НЕ УГАДАЛА»;
  3.5) со 2-го шага: 3 случайных «неправильных» токена подсвечиваются красным и отталкиваются от центра контекста (негативное сэмплирование);
  4) камера приближается зумом с панорамой на предложение;
  5) при промахе появляются стрелки и точки предложения вместе с подписями подтягиваются к центру контекста;
  6) зум откатывается;
  после обучения токены-«родственники» (порошок/сода/кислота/формула/теорема/расчёт/валенки/накладная)
  сбились в 4 явных цветных кластера (СТИРКА/ХИМИЯ/РАСЧЁТ/УЧЁТ): точки и 8 ключевых подписей
  окрашены в цвет своего кластера, легенда слева (цвет → примеры слов, без названий тем); финал
  «БЛИЗКИЙ СМЫСЛ — БЛИЗКИЕ ТОЧКИ» (~130 с).
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный + кислотно-зелёный люминофор), чёрный
  контур, надписи заглавными рубленым шрифтом.
- Отрендеренный файл — `videos/05-chisla.mp4`, указывается в `video_url` слайда 5 (`video_type: direct`).

### «RAG: дежурный ищет в архиве» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 5 05-rag.py RagArkhyv
```

- **Что проверять:** 6 кадров (~74 с), поток «вопрос → индекс → топ-3 → контекст + вопрос → модель →
  ответ по документам» читается, кадр «без архива — из головы» нагляден (цифра «плывёт», крестик
  «ПРОВЕРЯЙ»), финальная мысль «RAG = ВОПРОС + ДОКУМЕНТЫ ИЗ АРХИВА → ОТВЕТ ПО ИСТОЧНИКАМ».
- **Стиль:** как в первом ролике занятия.
- Отрендеренный файл — `videos/05-rag.mp4`, указывается в `video_url` слайда 10 (`video_type: direct`).
