# Занятие 06. «Этикетки и кнопки»

> Семестр 1 · Блок 1 «Мозги древних машин» · Курс 01, лекции 09, 11 · ~2 ч

**Сюжетная арка:** генерация изображений и function calling. Мешки порошка, соды и цемента одинаковые,
люди путают позиции и засыпают цемент в стиралку; продукция идёт в магазины без названий. Учимся
описывать этикетку словами (промпт, мета-промт) и давать модели «руки» — вызов функции «склад»,
чтобы она отвечала реальными позициями склада, а не из головы. Этикетки несут данные позиции (масса
мешка, для порошка — дозировка и мягкость воды, для цемента — марка). Практика: этикетка «ПОРОШОК-МАКС»
(обязательная контрольная точка) + «кнопка склад» через агента на платформе или в локальном opencode:
скрипт с function calling отвечает реальными позициями и генерирует этикетки для позиций в наличии.
