## Запуск

### «Из текста — картинка» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 6 06-iz-teksta-kartinka.py IzTekstaKartinka
```

- **Что проверять:** 5 кадров (~50 с), надписи читаемы, поток «промпт → модель → шум → картинка»
  читается, кадр «тот же промпт — картинка похожая, но другая» нагляден, финальная мысль
  «ИЗ ТЕКСТА — КАРТИНКА» + «МЕТА-ПРОМТ ЗАДАЁТ ГРАНИЦЫ».
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный + кислотно-зелёный люминофор), чёрный
  контур, надписи заглавными рубленым шрифтом. «Шум → картинка» — наглядное упрощение диффузии.
- Отрендеренный файл — `videos/06-iz-teksta-kartinka.mp4`, указывается в `video_url` слайда 3
  (`video_type: direct`).

### «Вызов функций: руки для модели» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 6 06-vyzov-funkcii.py VyzovFunkcii
```

- **Что проверять:** 6 кадров (~76 с), цикл «вопрос → модель решает → программа выполняет → результат →
  ответ модели» читается, кадр «без функции — из головы» нагляден (модель называет позиции как попало,
  крестик «ПРОВЕРЯЙ»), финальная мысль «ФУНКЦИЯ — РУКИ МОДЕЛИ: ВЫЗВАЛ → РЕАЛЬНЫЙ РЕЗУЛЬТАТ → ОТВЕТ
  ПО ДЕЛУ».
- **Стиль:** как в первом ролике занятия. Сюжетная рамка только в завязке (дежурный на пульте).
- Отрендеренный файл — `videos/06-vyzov-funkcii.mp4`, указывается в `video_url` слайда 8
  (`video_type: direct`).
