## Запуск

### «Из текста — картинка» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 6 06-iz-teksta-kartinka.py IzTekstaKartinka
```

- **Что проверять:** поток читается: (1) прямой процесс — промпт над рядом этикеток; слева чистая
  (`шаг=0`), затем копия сдвигается вправо и пикселезуется, процедура повторяется — в финале **5 изображений**
  (`шаг=0, 250, 500, 750, 1000`), всё блочнее и шумнее; размер «пикселей» шума **равен** размеру пикселей
  пикселизации (общая сетка блоков); (2) обучение (этап 2) — само начало сцены 2: рамка «ЦЕЛЕВОЙ РЕЗУЛЬТАТ» вокруг обеих картинок шума (нижняя граница чуть ниже); затем модель учится на 4 разных этикетках (порошок, глицерин, мыло, порошок-2); блок промпта (бежевый, чёрный текст, две строки: название этикетки + серийный номер (напр. «БАННОЕ», «ПАР», «МАКС»), без слова «ПРОМПТ:») стоит над входной картинкой и вместе с ней долетает до центра U-Net, входная картинка мгновенно исчезает и на её месте разлетаются чистая и шум (промпт гаснет плавно), без стрелок (скорость влёта равна скорости вылета, выходные появляются без фейда); веса U-Net внутри — круги (сетка 11 рядов; изначально точки, при «ВЕСА ПЕРЕСТРАИВАЮТСЯ» растут и зеленеют, НАКАПЛИВАЮТСЯ между шагами и не сбрасываются); при НЕ СОВПАЛО рисуется изогнутая стрелка от центра верхней границы «НЕ СОВПАЛО» в центр U-Net, затем веса обновляются; подпись «ВЕСА ПЕРЕСТРАИВАЮТСЯ» появляется над картинками с шумом чуть правее стрелки; все картинки второй сцены одинакового размера; первая сцена быстрее, вторая — чуть медленнее; итог (СОВПАЛО / НЕ СОВПАЛО) показывается в мигающем прямоугольнике: красный фон при НЕ СОВПАЛО, зелёный при СОВПАЛИ, чёрный текст; для каждой степени зашумления 250/500/750/1000 сначала неверная попытка: предсказанный шум отличается от эталонного (другой цвет/прозрачность), а «чистая» сохраняет следы шума; затем «ВЕСА ПЕРЕСТРАИВАЮТСЯ» (круги растут и зеленеют) и вторая попытка точная: шум совпадает (СОВПАЛИ), картинка чистая; эталонный шум стоит справа, правее разделённого шума; после 4-х станций рамка «ЦЕЛЕВОЙ РЕЗУЛЬТАТ» переезжает к чистой картинке, заголовок меняется на «ЭТАП 3: МОДЕЛЬ ГОТОВА, ГЕНЕРАЦИЯ», на вход подаётся случайный шум + запрос (подпись «запрос»), модель генерирует хозяйственное мыло — на выходе изображение в рамке (рамка поднята и подпись снизу; пауза ~2 с перед переходом); (4) генерация —
  шум → пошаговое очищение → этикетка; (5) два варианта из разного шума. Пикселизация — **реальная**
  (квадратные блоки, не круглые точки).
  Надписи читаемы, этикетки не накладываются друг на друга в кадре вариантов.
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный + кислотно-зелёный люминофор), чёрный
  контур, надписи заглавными рубленым шрифтом. Пикселизация и шум — наглядное упрощение диффузии.
- Отрендеренный файл — `videos/06-iz-teksta-kartinka.mp4` (~84 с), указывается в `video_url` слайда 3
  (`video_type: direct`).
