# Занятие 07. «Приказы по уставу»

> Семестр 1 · Блок 2 «Приказы по уставу» · Курс 02, раздел `basics` · ~2 ч

**Сюжетная арка:** основы промпт-инжиниринга: инструкции, роли, формализация промпта, few-shot,
настройки LLM (температура, top-p, max_tokens), комбинирование техник. Дежурный (модель) отвечает
«как попало», потому что приказы ему дают как попало; Василич учит: «подчинённому надо говорить чётко —
кто, что, когда». Практика: серия экспериментов — один запрос с разными ролями и примерами, крутим
температуру — и запись «устава» для модели (приказ-шаблон для смены).

- `slides-plan.md` — план слайдов занятия (17 слайдов, без `welcome`/`congrats`; миссия, сводная таблица,
  детали по слайдам, план видеоролика, доп. информация);
- `comic.md` — сценарий комикса: сцена 1 (слайд 1) и сцена 2 (слайд 17);
