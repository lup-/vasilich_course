# Квиз «Кто, что, когда — по уставу»

> Материал для `quiz`-слайда 5 занятия 07 (по лекции `formalizing` курса-02). Термины — в доп. инфо
> `osnovy-promptov`.

## Вопрос

**В приказе по уставу часть, которая отвечает на вопрос «кто это делает», — это…**

Выбери один правильный вариант.

## Варианты

- Роль — `is_correct: true`
- Задача — `is_correct: false`
- Контекст — `is_correct: false`
- Примеры — `is_correct: false`

## Объяснение

Роль отвечает на вопрос «кто»: «ты — технолог цеха стирки». Задача — это «что» (что сделать), контекст —
«когда/при каких условиях», примеры — «как это делали раньше». Вместе они и составляют приказ по уставу.
