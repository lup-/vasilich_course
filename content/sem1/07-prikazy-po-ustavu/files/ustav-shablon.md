# Шаблон устава для модели

> Заготовка для главной практики занятия 07 (слайд 16). Заполни поля — получишь готовый приказ
> для дежурного. Шпаргалка, как проводить эксперименты, — в `pamyatka-eksperimenty.md`,
> полный бриф задания — в `zadanie-ustav.md`.

## Что такое устав

Устав — это приказ-шаблон, по которому смена ставит задачи модели. Заполни один раз — переиспользуй:
все будут давать модель одинаково и получать ответ по делу.

## Заготовка приказа

```text
ПРИКАЗ ПО УСТАВУ

РОЛЬ (кто модель):
  «Ты — <кто: должность/специальность> завода „БытХимИскИнДеталь“.»

ЗАДАЧА (что сделать, одно действие):
  «Составь / посчитай / найди / проверь — <что именно> для <для кого>.»

КОНТЕКСТ (вводные и условия):
  — <данные и факты: продукция, склад, нормы>;
  — <ограничения: формат ответа, чего не делать>.

ПРИМЕРЫ (как делали раньше, 1–2 образца):
  <ввод>: <вывод>
  <ввод>: <вывод>

НАСТРОЙКИ:
  температура: низкая (факты) / выше (творчество)
  длина ответа: <сколько примерно>
```

## Пример заполненного устава (для «ПОРОШОК-МАКС»)

```text
ПРИКАЗ ПО УСТАВУ

РОЛЬ:
  «Ты — технолог цеха стирки завода „БытХимИскИнДеталь“.»

ЗАДАЧА:
  «Составь памятку для новой смены: как хранить и дозировать порошок „ПОРОШОК-МАКС“.»

КОНТЕКСТ:
  — порошок «ПОРОШОК-МАКС», мешок 25 кг;
  — дозировка 100 г на стирку;
  — хранить в сухом месте, склад 3;
  — ответ — короткий список, без воды.

ПРИМЕРЫ:
  «Как хранить соду»: «в сухом месте, герметичная упаковка»
  «Как хранить цемент»: «на поддоне, под навесом»

НАСТРОЙКИ:
  температура: 0.3 (факты)
  длина: до 150 слов
```

## Правила поверх устава

1. **Коротко.** Лишние абзацы — лишние токены (деньги). Только нужное: роль, задача, контекст, пара примеров.
2. **Без секретов.** Пароли и ключи в промпт не пишем — только рабочие данные (приватность).
3. **Проверяй.** Ответ сверяем с фактами (накладная, файл склада, инструкция), не доверяем на слово.
