## Запуск (когда ролик будет написан)

### «Приказ по уставу» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 7 07-prikaz-po-ustavu.py PrikazPoUstavu
```

- **Что проверять:** 5 кадров (~60 с), бланк «ПРИКАЗ ПО УСТАВУ» заполняется полями (роль, задача,
  контекст, примеры) и читается, кадр «ответ по делу» нагляден, сравнение «без устава vs по уставу»
  понятно, финальная мысль «ПРИКАЗ ПО УСТАВУ = РОЛЬ + ЗАДАЧА + КОНТЕКСТ + ПРИМЕРЫ».
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный + кислотно-зелёный люминофор), чёрный
  контур, надписи заглавными рубленым шрифтом.
- Отрендеренный файл — `videos/07-prikaz-po-ustavu.mp4`, указывается в `video_url` слайда 3
  (`video_type: direct`).
