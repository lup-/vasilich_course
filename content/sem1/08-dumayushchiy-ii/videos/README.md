## Запуск (когда ролик будет написан)

### «Думает вслух» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 8 08-dumaet-vslukh.py DumaetVslukh
```

- **Что проверять:** 5 кадров (~60 с), ответ «наобум» крупно и понятно, пошаговый расчёт (425 − 216 = 209)
  читается, сравнение «наобум vs по шагам» наглядно, сверка с бумагой склада «ОСТАТОК: 209 КГ» совпадает,
  финальная мысль «ПОПРОСИ ПОКАЗАТЬ ХОД РЕШЕНИЯ — ОТВЕТ ТОЧНЕЕ».
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный + кислотно-зелёный люминофор), чёрный
  контур, надписи заглавными рубленым шрифтом.
- Отрендеренный файл — `videos/08-dumaet-vslukh.mp4`, указывается в `video_url` слайда 3
  (`video_type: direct`).
