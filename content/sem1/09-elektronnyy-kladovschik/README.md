# Занятие 09. «Электронный кладовщик»

> Семестр 1 · Блок 2 «Приказы по уставу» · Курс 02, разделы `basic_applications` + `applied_prompting` · ~2 ч

**Сюжетная арка:** на складе разлад — в системе заказы разложены по полочкам («ХимСнаб» №214, «СодаТрест» №88), а по почте приходят накладные реальных поставок простынёй, всё в одну строку, и каждую надо сверить с заказом: где полное соответствие, где недосдача, а где излишки. Василич поручает собрать электронного помощника; Алиса объясняет: прикладной промптинг — поручение с точным ТЗ, один конвейер `заказ+накладная→таблица→сверка→исход`. Сквозной конвейер прогоняется на двух поставках без перенастройки.

**Практика:** сквозной конвейер кладовщика — заказ из системы + накладная из почты → сверочная таблица (наименование/заказано/поставлено/отклонение + ИТОГО) → сверка с инструкцией цеха (п.1.1–1.6, 4.2–4.5) → ветвление исходов: полное соответствие → письмо «заказ принят» + акт приёмки (п.4.4); расхождение больше 1% → письмо о расхождении (+акт расхождения п.4.3, излишек п.4.5); вопрос вне инструкции → эскалация дежурному кладовщику (п.6.4). Две поставки: «ХимСнаб» №214 — совпадает с заказом (108 900 = 108 900 руб, 6 позиций), «СодаТрест» №88 — не совпадает (заказ 73 000 против накладной 71 300 руб, 5 позиций: недосдача −20%, излишек ≈+11%). Кладовщик остаётся на складе до конца семестра (занятия 11–13, 15–16).
