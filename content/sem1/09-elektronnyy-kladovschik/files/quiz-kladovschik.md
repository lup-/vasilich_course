# Квиз «Что в промпте у кладовщика?»

> Материал квиза слайда 8 занятия 09. По теории слайда 7 (задание `build_chatbot_from_kb` курса-02) и контрасту с RAG занятия 5.

## Вопрос

**«Из чего собирается промпт электронного кладовщика, который сверяет поставку с заказом и отвечает по инструкции?»**

## Варианты

- { text: «Роль (кладовщик) + заказ из системы + накладная из почты + инструкция цеха в метках START CONTEXT/END CONTEXT + задача», is_correct: true }
- { text: «Только вопрос пользователя, без всякого контекста», is_correct: false }
- { text: «Список всех секретов завода, чтобы отвечать на любые вопросы», is_correct: false }
- { text: «Полная база знаний целиком в одном запросе», is_correct: false }

## Объяснение

Промпт кладовщика — это роль + рабочие бумаги (заказ из системы, накладная из почты) + нужный документ-инструкция в метках START CONTEXT/END CONTEXT + задача. В отличие от RAG (занятие 5, много документов через векторный поиск, топ-3 чанка) здесь три коротких документа целиком — все влезают в окно (занятие 8). Полную базу в одно окно не впихнуть, а секреты в промпты не кладут вовсе (приватность). Задача без контекста — модель отвечает «из головы», то есть выдумывает. А если ответа нет даже в бумагах — кладовщик не выдумывает, а эскалирует вопрос дежурному кладовщику (п.6.4 инструкции).
