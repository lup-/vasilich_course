# Занятие 09. «Заставить ИИ работать»

> Семестр 1 · Блок 2 «Приказы по уставу» · Курс 02, разделы `basic_applications` + `applied_prompting` · ~2 ч

**Сюжетная арка:** прикладной промптинг — переводим навыки в реальную пользу завода. Василич: «Раз черт
думать умеет — пусть и работает!» Алиса объясняет: прикладной промптинг — это поручение модели с точным
ТЗ (роль, задача, контекст, формат, тон). Практика: письмо поставщику (сравнение тонов), таблица из сырой
накладной, памятка-чек-лист для смены и чат-бот на базе знаний завода («дежурный по инструкциям»).

  детали по слайдам, план видеоролика, доп. информация);
- `comic.md` — сценарий комикса: сцена 1 (слайд 1) и сцена 2 (слайд 18);

  (слайд 17), квиз `quiz-dispetcher.md` (слайд 13), системный промпт `system-prompt-vasylich-57.md`;
