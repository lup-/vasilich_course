## Вопрос

**«Из чего собирается промпт чат-бота, который отвечает по базе знаний?»**

- { text: «Полная база знаний целиком в одном запросе», is_correct: false }

## Объяснение

Промпт дежурного — это роль + нужный документ из базы (контекст в метках START CONTEXT/END CONTEXT) +
история диалога + вопрос. Полную базу в одно «окно» не впихнуть (занятие 8 — длинный текст), а секреты
в промпты не кладут вовсе (приватность). Вопрос без контекста — модель отвечает «из головы», то есть
выдумывает.
