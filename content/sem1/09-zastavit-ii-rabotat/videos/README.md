## Запуск (когда ролик будет доделан)

### «Конвейер диспетчера» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 9 09-konveyer-dispetchera.py KonveyerDispetchera
```

- **Что проверять:** 5 кадров (~60 с), поиск документа по смыслу нагляден (лист выезжает из стопки),
  сборка промпта из блоков читается, ответ по фактам документа, сравнение «НЕ ЗНАЮ» (галочка) против
  «ВЫДУМАЛ» (крест) понятно, финальная мысль «ОТВЕЧАЙ ТОЛЬКО ПО СВОИМ ДОКУМЕНТАМ».
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный + кислотно-зелёный люминофор), чёрный
  контур, надписи заглавными рубленым шрифтом.
- Отрендеренный файл — `videos/09-konveyer-dispetchera.mp4`, указывается в `video_url` слайда 12
  (`video_type: direct`).
