# Квиз «Какой формат?»

> Материал квиза слайда 8 занятия 11. По теории слайдов 5–7 (лекция 02 курса-04: форматы CSV/JSON/Excel).

## Вопрос

**«Файл из архива начинается вот так:**
```json
[
  {"sensor": "temp", "time": "2026-01-10T08:00", "value": 23.4},
  {"sensor": "vlag", "time": "2026-01-10T08:00", "value": 41.0}
]
```
**Какой это формат и почему?»**

## Варианты

- { text: «JSON: фигурные скобки и пары „ключ: значение“, внутри — вложенные объекты и списки», is_correct: true }
- { text: «CSV: это таблица со строками и запятыми», is_correct: false }
- { text: «Excel: файл таблиц Microsoft, его видно по фигурным скобкам», is_correct: false }
- { text: «PDF: документ, у которого все страницы начинаются с фигурных скобок», is_correct: false }

## Объяснение

Это **JSON**: данные записаны в фигурных скобках, как пары «ключ: значение» (`"sensor": "temp"`),
а сами записи — вложенный список. Так устроены логи датчиков и ответы веб-API. CSV — это строки
с запятыми и заголовками, Excel — таблица с листами и формулами, а PDF — «запечатанный» документ,
не данные.
