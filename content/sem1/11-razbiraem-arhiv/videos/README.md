## Запуск

### «Форматы данных» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 11 \
    11-formaty-dannyh.py FormatyDannyh
```

- **Что показывает (кадры):** 1) три файла архива (`tovary-sklada.csv`, `datchiki-ceh7.json`,
  `ostatki-sklada.xlsx`); 2) CSV — строки через запятую, заголовок, «открывается блокнотом»;
  3) JSON — фигурные скобки и пары «ключ: значение», вложенные списки, «отвечают веб-API»;
  4) Excel — сетка ячеек, вкладки листов, формула `=СУММ(A1:A10)`; 5) PDF — страница «запечатана»,
  текст как картинка (извлекать — отдельная история, занятие 14); 6) вывод: «ФОРМАТ ПОДСКАЗЫВАЕТ,
  КАК ЧИТАТЬ ФАЙЛ».
- **Что проверять:** надписи читаемы (заглавные, рубленый шрифт), в CSV виден разделитель
  (ржущим цветом), в JSON подсвечены «ключ: значение», в Excel видна сетка и вкладки листов,
  финальная мысль на месте, ~75 с.
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный/бежевый + кислотно-зелёный люминофор),
  чёрный контур, надписи заглавными.
- Отрендеренный файл — `videos/11-formaty-dannyh.mp4`, указывается в `video_url` слайда 4
  (`video_type: direct`).
