## Запуск

### «Как работают сводки: pandas» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 12 \
    12-svodki-pandas.py SvodkiPandas
```

- **Что показывает (кадры):** 1) таблица продаж завода (дата, регион, менеджер, товар, сумма);
  2) рамка «DataFrame», столбцы подсвечиваются по очереди (читаем и смотрим); 3) дубликаты
  «сливаются», пропуск мигает ржавым и заполняется нулём; 4) ненужные строки гаснут (фильтрация);
  5) строки собираются в стопки по регионам с суммами и сортируются; 6) сетка «перекручивается»
  в сводную: регионы — строки, месяцы — столбцы; 7) финальная формула: сводка = цепочка команд,
  и «что посчитал — пересчитай!».
- **Что проверять:** надписи читаемы (заглавные, рубленый шрифт); подсветка столбцов видна;
  слияние дубликатов и мигание пропуска наглядны; в «сводной» сетка действительно «перекручивается»;
  финальная мысль на месте, ~90 с.
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный/бежевый + кислотно-зелёный люминофор),
  чёрный контур, надписи заглавными.
- Отрендеренный файл — `videos/12-svodki-pandas.mp4`, указывается в `video_url` слайда 4
  (`video_type: direct`).
