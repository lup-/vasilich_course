# Памятка: как заказать график агенту и проверить результат

> Материал занятия 13 «Графики для дирекции». Это шпаргалка: как словами «заказать» агенту график
> по таблице и как убедиться, что он построил всё правильно и не наврал. Программировать не нужно —
> агент пишет код, ты проверяешь.

## Формула заказа графика агенту (6 пунктов)

1. **Данные**: «у меня есть таблица `prodazhi-zavoda.csv` со столбцами: дата, регион, менеджер, товар, сумма».
2. **Тип графика**: «построй линейный график / столбчатую диаграмму / круговую / гистограмму».
3. **Оси**: «по оси X — месяц, по оси Y — сумма продаж».
4. **Агрегация**: «просуммируй продажи по месяцам».
5. **Оформление**: «добавь заголовок "Продажи по месяцам 2025", подписи осей, включи сетку, поверни подписи осей, чтобы не налезали».
6. **Сохранение**: «сохрани график в PNG-файл `prodazhi-mesyacy.png` до вызова show()».

Например:

> «Прочитай `prodazhi-zavoda.csv`. Сделай очистку данных как на прошлом занятии: убери дубликаты, пропуски в сумме заполни нулями, переведи сумму в числа. Построй столбчатую диаграмму продаж по регионам, отсортированную по убыванию. Добавь заголовок "Продажи по регионам", подписи осей X ("Регион") и Y ("Сумма, руб."), сетку. Добавь значения над столбцами. Сохрани в `prodazhi-regiony.png`.»

## Выбор типа графика под вопрос

| Вопрос к данным | Лучший тип графика | Команда агенту |
|---|---|---|
| Как менялось во времени? | Линейный (`plt.plot`) | «построй линейный график продаж по месяцам» |
| Кто больше, кто меньше? | Столбчатый (`plt.bar`) | «построй столбчатую диаграмму продаж по регионам» |
| Каковы доли от целого? | Круговая (`plt.pie`) | «построй круговую диаграмму долей регионов» |
| Как распределены заказы? | Гистограмма (`plt.hist`) | «построй гистограмму распределения сумм заказов» |
| Хочу покрутить и наводить | Интерактивный (`px.line`) | «построй интерактивный график в Plotly» |

## Как проверить результат

1. **Сверяй контрольные суммы с таблицей.** Сумма высот столбцов на столбчатой диаграмме должна совпасть с общей суммой файла. По региону Центр должно выходить ≈ 486 758 руб., по Северу ≈ 402 619 руб., по Югу ≈ 373 748 руб.
2. **Проверь оси и заголовок.** На графике без подписей осей и заголовка дирекция не поймёт, что нарисовано. Требуй подписи с единицами измерения («руб.», «шт.»).
3. **Проверь крайние значения.** Посмотри на линейный график: минимум должен быть в январе (≈ 73 659 руб.), пик — в мае (≈ 133 503 руб.). Если пик в другом месяце — агент неправильно перевёл даты.
4. **Проверь сохранённый файл.** Файл PNG не должен быть пустым или белым. Напоминай агенту: `plt.savefig(...)` вызывается **до** `plt.show()`.

## Вопросы агенту по ходу работы

- «Добавь подписи значений над столбцами, чтобы были видны точные цифры.»
- «Поверни подписи осей на 45 градусов, чтобы они не накладывались друг на друга.»
- «Каковы главные выводы из этих графиков? Сформулируй 3 тезиса для дирекции.»
- «Проверь, совпадают ли суммы на графике с группировкой по таблице.»
