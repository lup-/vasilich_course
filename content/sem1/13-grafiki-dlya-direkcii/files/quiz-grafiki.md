# Квиз «Какой график и для чего?»

> Материал квиза слайда 7 занятия 13. По теории слайдов 3–6 (лекция 06 курса-04: визуализация данных, matplotlib, Plotly).

## Вопрос

**«Директор спрашивает, как менялись продажи завода по месяцам в течение года. Какой график просим у агента?»**

- { text: «Линейный график — линия продаж по месяцам», is_correct: true }
- { text: «Столбчатую диаграмму продаж по регионам», is_correct: false }
- { text: «Круговую диаграмму долей регионов в общих продажах», is_correct: false }
- { text: «Гистограмму распределения сумм чеков», is_correct: false }

## Объяснение

`Линейный график` лучше всего показывает динамику и изменение показателей во времени (по месяцам, дням, годам) — на нём сразу видны тренды, сезонность, провалы и пики.

Остальные типы графиков предназначены для других вопросов:
- `Столбчатая диаграмма` лучше подходит для сравнения отдельных категорий (например, регионов или менеджеров);
- `Круговая диаграмма` показывает структуру и доли частей от целого 100%;
- `Гистограмма` показывает частоту попадания чисел в диапазоны (распределение сумм заказов).
