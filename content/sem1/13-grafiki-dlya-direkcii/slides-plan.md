## Миссия занятия

> «Дирекции нужны картинки, молодежь: где завод теряет деньги. Цифры в таблице никто читать не будет —
> дай им график, чтоб бабка на рынке поняла! Только график сверяй с таблицей: красиво наврать
> и электрон умеет.» — Прораб Василич

**Задача квеста:** через агента построить по данным склада графики для дирекции — линейный (продажи

интерактивную диаграмму Plotly; подписать оси и легенду словами; проверить выводы по контрольным суммам
и объяснить, «где завод теряет деньги».

на каждом заголовок, подписи осей и сетка; выводы сверены с таблицей (суммы регионов сходятся, аномалия
«Кладовщика» — 60 000 — на графике на виду); студент понимает, как словами «заказать» агенту график
и как проверять, что он не наврал.

### 5. rich_text — «matplotlib: статичные графики для отчёта»

- **Назначение:** формальное объяснение после видео (п.7 шаблона), по лекции 06 курса-04: matplotlib —
  «классика» для отчётов; базовые команды и оформление описываются словами, код пишет агент. Одна мысль:
  статичный график для отчёта должен иметь заголовок, подписи осей, сетку — и сохраняться в PNG
  (до `show`).
- **Содержание** (`markdown`):

````markdown
**matplotlib: статичные графики для отчёта.**

«matplotlib, деточка, — это „классика“: простые и надёжные картинки для отчётов. Код пишет фиксик, а ты командуешь словами — имба, прям рил. Словарь — короткий:

```python
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 5))        # размер, чтобы не было мелко
plt.plot(месяцы, суммы, marker="o")  # линейный
plt.bar(регионы, суммы)             # столбчатый
plt.pie(доли, labels=регионы)       # круговая
plt.hist(суммы, bins=20)            # гистограмма

plt.title("Продажи по месяцам")     # заголовок
plt.xlabel("Месяц")                 # ось X
plt.ylabel("Сумма, руб.")           # ось Y
plt.grid(True)                      # сетка — легче читать
plt.legend(...)                     # легенда, если несколько линий
plt.xticks(rotation=45)             # поверни подписи X, чтобы не налезали
plt.savefig("graf.png")             # сохрани В ФАЙЛ — до show!
```

Обязательное оформление: читаемый размер, осмысленный заголовок, подписи осей с единицами, сетка.
Не больше 3–4 серий на одном графике — иначе каша. И главный подводный камень: если вызвать `show()`
раньше `savefig()`, картинка сохранится пустой — сохраняй до показа.

Подробнее — [графики для дирекции](@grafiki-dlya-direkcii).»
````

### 6. rich_text — «Plotly: интерактив для исследования»

- **Назначение:** формальное объяснение по лекции 06 курса-04: Plotly — интерактив для исследования;
  в отчёте можно оставить статичные графики, а в разборе — интерактивный. Одна мысль: интерактив умеет
  то, что статичный не умеет: навести, зумить, посмотреть точное число.
- **Содержание** (`markdown`):

````markdown
**Plotly: интерактив для исследования.**

«А ещё есть, деточка, интерактивные графики — Plotly. Ох, ёшкин кот, красота! Это как навести курсор на точку и увидеть точное
число, зумить нужный кусок, спрятать лишнюю серию по клику. Для разбора — самое то:

```python
import plotly.express as px

fig = px.line(месяцы, y=суммы, title="Продажи по месяцам (интерактив)")
fig.update_layout(xaxis_title="Месяц", yaxis_title="Сумма, руб.")
fig.show()
```

Статичный график — для отчёта (всё уже видно и подписано). Интерактивный — для исследования
(покрутить, посмотреть точно). Фиксику заказывается так же словами: „сделай интерактивный линейный
по месяцам, чтобы наводить и видеть число“.

Подробнее — [графики для дирекции](@grafiki-dlya-direkcii).»
````

```markdown
Польза: готовые графики — это часть диагностического отчёта для дирекции в конце семестра.
```
