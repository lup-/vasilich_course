## Запуск

### «Как читать график» (ManimCE)

```bash
python -m manim render -ql -p --format mp4 --resolution 1920,1080 --fps 30 --seed 13 \
    13-grafiki-chtenie.py GrafikiChtenie
```

- **Что показывает (кадры):**
  1) таблица продаж завода (дата, регион, менеджер, товар, сумма); по числам бегает рамка (ничего не понятно, цифры спрятаны);
  2) 4 вопроса-ключа: время → линия, сравнение → столбцы, доли → круг, распределение → гистограмма;
  3) точки «вылетают» из таблицы в сетку, образуя линию (виден провал января и пик мая);
  4) столбчатая диаграмма по регионам (Центр, Север, Юг) + круговая долей;
  5) демонстрация интерактива Plotly (курсор наводится на точку → подсказка, рамка зумит участок);
  6) подсвеченная сверка графика и таблицы (столбец Центр и строка таблицы горят одинаково люминофором) → формула «сверяй с таблицей».
- **Что проверять:** надписи читаемы (заглавные, рубленый шрифт); анимация вылета точек в график плавная; интерактив Plotly показан наглядно; финальная мысль на месте, ~90 с.
- **Стиль:** палитра `comic-style.md` (болотный/ржавый/пыльный/бежевый + кислотно-зелёный люминофор), чёрный контур, надписи заглавными.
- Отрендеренный файл — `videos/13-grafiki-chtenie.mp4`, указывается в `video_url` слайда 4 (`video_type: direct`).
