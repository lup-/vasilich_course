# Занятие 14. «zhivye-dannye» / «Растворитель для конкурентов»

> Семестр 1 · Блок 3 «Пыльные архивы» · Курс 04, лекции 07–08 + задания 04–05 + курс 05, лекция 06

**Сюжетная арка:** над проходной намалевали слово суперстойкой краской конкурента «ХимБытИскИнЛакоКраск» — вода и мыло
не берут. Лаборатория разобрала образец и составила протокол (PDF). Задача: через агента извлечь
состав из PDF, проверить компоненты через PubChem («источник правды»), найти статьи по растворимости
в CrossRef/OpenAlex и собрать техпаспорт растворителя-новинки «Сольвент №1».

## Что в этой папке

- `slides-plan.md` — план слайдов занятия (типы из `slides.md`, без `welcome`/`congrats`);
- `comic.md` — сценарий комикса по панелям (стиль — `../_shared/comic-style.md`);
- `files/` — файлы занятия:
  - `issledovanie-kraski.pdf` — протокол исследования образца краски (PDF с таблицей состава);
  - `pamyatka-zhivye-dannye.md` — памятка «как заказать агенту живые данные и проверить результат»;
  - `zadanie-rastvoritel.md` — бриф главной практики (слайд 12);
  - `quiz-zhivye-dannye.md` — материал квиза (слайд 8);
  - `dannye/` — снапшоты ответов API (PubChem/CrossRef/OpenAlex) для пути «на платформе»;
- `links.md` — внешние ссылки и источники;
- `videos/` — план видеоролика (см. `videos/README.md`).
