# Памятка: как заказать агенту «живые данные» и проверить результат

> Занятие 14, слайды 9–12. Шпаргалка для главной практики «Собери техпаспорт растворителя».
> Код пишет агент — ты описываешь задачу словами, запускаешь и проверяешь.

## Формула заказа данных (лекция 07 курса-04)

Расскажи агенту четыре вещи:

1. **Что нужно** — например: «состав краски из протокола лаборатории»;
2. **Откуда взять** — файл `issledovanie-kraski.pdf` или URL API (PubChem/CrossRef/OpenAlex);
3. **Какой результат** — таблица, техпаспорт, ссылки-DOI;
4. **Как проверить** — доли в сумме 100%, цифры из базы, DOI открывается.

Пример фразы для агента:

> «Прочитай `issledovanie-kraski.pdf` через PyMuPDF. Вытащи таблицу состава краски и сверь,
> что доли в сумме дают 100%. Для компонентов из таблицы запроси PubChem по названию
> (формула, масса, SMILES, InChIKey) и покажи таблицу. Найди через CrossRef статьи про
> растворимость акриловых смол и выпиши DOI. Собери техпаспорт растворителя.»

## Ключевые API (все бесплатные, без ключей)

| Что | Где | Пример |
|---|---|---|
| Свойства вещества | PubChem PUG REST | `https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/acetone/property/MolecularFormula,MolecularWeight,CanonicalSMILES,InChIKey/JSON` |
| Поиск статей | CrossRef | `https://api.crossref.org/works?query=poly+methyl+methacrylate+solubility+acetone&rows=3` |
| Поиск статей | OpenAlex | `https://api.openalex.org/works?search=acrylic+resin+solubility` |

## Как проверять (по-заводски: не доверяй черту на слово)

1. **Источник правды.** Агент назвал вещество — запроси его по названию в PubChem и сравни
   формулу, массу и SMILES с тем, что дал агент. Не совпало — правь.
2. **Названия-синонимы.** По названию «ксилол» PubChem может вернуть ошибку — изомеров несколько.
   Уточни конкретное вещество или работай по CID/InChIKey.
3. **Доли и суммы.** Доли компонентов из PDF своди в 100%. Цифра не бьётся — агент что-то потерял
   при извлечении, перечитай PDF.
4. **DOI.** У каждого вывода про растворимость — ссылка-DOI на статью. DOI должен открываться
   (`https://doi.org/<DOI>`).
5. **Статусы.** В коде проверяй `resp.status_code`: 200 — успех, 404 — неверное имя/URL,
   429 — слишком много запросов (добавь паузу).

## Приватность и лимиты

- Секреты (если появятся API-ключи) — только в `.env`, не в код и не в чат. Здесь все API без ключей.
- В публичные сервисы уходят только рабочие данные, без секретов.
- Не гоняй запросы в цикле по 10 000 раз — у публичных API есть лимиты, добавляй паузы.

## Запасные данные (если нет интернета)

Снапшоты настоящих ответов API лежат в папке `dannye/`:

- `pubchem-aceton.json`, `pubchem-etilacetat.json`, `pubchem-ksilol.json` — свойства веществ;
- `crossref-rastvorimost.json`, `openalex-rastvorimost.json` — статьи с DOI.

Если на платформе нет доступа к интернету — попроси агента распарсить эти JSON вместо живых запросов.
