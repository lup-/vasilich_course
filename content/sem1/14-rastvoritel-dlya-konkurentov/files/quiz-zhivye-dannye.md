# Квиз занятия 14 «Растворитель для конкурентов»

> Материал контрольной точки слайда 8. Один вопрос с вариантами — проверка ключевого приёма занятия:
> «предложенное» агентом вещество сверяем с источником правды (PubChem), а не принимаем на веру.

## Вопрос

**Агент сообщил: «растворитель для акриловой краски — ацетон». Как убедиться, что он не выдумал вещество?**

## Варианты

- [ ] **Запросить PubChem по названию и сравнить формулу, массу и SMILES** ← правильный
- [ ] Поверить агенту на слово — модель умная
- [ ] Спросить вторую модель; если подтвердит — верить
- [ ] Проверить растворитель по запаху

## Объяснение

PubChem — «источник правды» по веществам: запрашиваем по названию официальные формулу, массу
и SMILES и сравниваем с тем, что дал агент. Второе мнение модели — тоже мнение, а не факт.
Проверяем по базе, а не на веру.
