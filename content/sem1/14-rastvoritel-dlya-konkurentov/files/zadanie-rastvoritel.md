# Задание: собери техпаспорт растворителя

> Материал главной практики слайда 12 занятия 14. Бриф для агента — что сказать ему словами.
> Файлы: `issledovanie-kraski.pdf` (протокол лаборатории, скачай со слайда 9),
> `pamyatka-zhivye-dannye.md` (шпаргалка с формулой заказа данных и API),
> `dannye/` (снапшоты API — фолбэк, если нет интернета).

## Суть

Над проходной завода намалевали слово суперстойкой краской конкурента «ХимБытИскИнЛакоКраск» — вода и мыло её не берут.
Лаборатория разобрала образец и составила протокол (PDF). Нужно: вытащить состав из протокола,
проверить каждый компонент по PubChem (источник правды), найти научные статьи про растворимость
акриловых смол и собрать техпаспорт растворителя-новинки «Сольвент №1» — с проверенными цифрами
и ссылками-DOI.

## Что сделать

1. Запусти агента (opencode) в папке с файлом `issledovanie-kraski.pdf` (или выполни задание
   на платформе — данные уже в заготовке кода) и опиши задачу словами (рецепт — в памятке):

   > «Прочитай `issledovanie-kraski.pdf` через PyMuPDF: вытащи текст и таблицу состава краски
   > (компонент, массовая доля, роль). Сверь, что доли в сумме дают 100%.
   > Для ключевых компонентов запроси PubChem по названию (формула, масса, SMILES, InChIKey):
   > метилметакрилат (акриловая смола), диоксид титана, ксилол, бутилацетат.
   > Также проверь по PubChem кандидатов в растворитель: ацетон, этилацетат, ксилол.
   > Найди через CrossRef и OpenAlex минимум одну научную статью про растворимость акриловых смол
   > (плёнкообразователь) и выпиши DOI.
   > Собери техпаспорт растворителя „Сольвент №1“: состав (этилацетат 45%, ацетон 35%, ксилол 20%),
   > для каждого компонента проверенные цифры из PubChem и ссылку-DOI.
   > Выведи через print(): таблицу компонентов (название, формула, масса, InChIKey) и итоговый
   > техпаспорт с выводами.»

2. Проверь результат своими глазами (по памятке):
   - доли из протокола в сумме = 100% (42 + 18 + 4 + 20 + 12 + 4);
   - у ацетона в выводе: C3H6O, 58.08, `CC(=O)C`, `CSCPPACGZOOCGX-UHFFFAOYSA-N`;
   - у этилацетата: C4H8O2, 88.11, `CCOC(=O)C`, `XEKOWRVHYACXOJ-UHFFFAOYSA-N`;
   - есть минимум одна ссылка-DOI на статью про растворимость акриловых смол.

3. Добейся, чтобы **в выводе были таблица компонентов, состав растворителя и ссылки-DOI**
   (через `print(...)`) и нажми «Проверить».

## Два пути выполнения (любой подходит)

- **Локально (рекомендуется):** скачай `issledovanie-kraski.pdf` и памятку со слайда 9, запусти
  opencode в папке с файлом, опиши задачу словами. Агент сам читает PDF и стучится в живые API
  (PubChem/CrossRef/OpenAlex) — это и есть «живые данные».
- **На платформе:** опиши задачу агенту в чате, вставь его код кнопкой «Вставить код в редактор»,
  запусти. Состав и снапшоты ответов API уже встроены в заготовку кода. Если интернет на платформе
  недоступен — используй встроенные снапшоты (аналоги `files/dannye/`).

## Контрольные ответы

- Сумма долей из протокола: **100 %** (акриловая смола 42, диоксид титана 18, сажа 4,
  ксилол 20, бутилацетат 12, присадки 4).
- Ацетон: C3H6O / 58.08 / `CC(=O)C` / `CSCPPACGZOOCGX-UHFFFAOYSA-N`.
- Этилацетат: C4H8O2 / 88.11 / `CCOC(=O)C` / `XEKOWRVHYACXOJ-UHFFFAOYSA-N`.
- п-Ксилол: C8H10 / 106.16 / `CC1=CC=C(C=C1)C` / `URLKBWYHVLBVBO-UHFFFAOYSA-N`.
- Метилметакрилат: C5H8O2 / 100.12 / `CC(=C)C(=O)OC` / `VVQNEPGJFQJSBK-UHFFFAOYSA-N`.
- Пример статьи про растворимость ПММА в ацетоне: **DOI 10.1016/j.supflu.2005.12.018**.
- Техпаспорт «Сольвент №1»: этилацетат 45 % + ацетон 35 % + ксилол 20 % (растворители
  для акриловых смол — «подобное растворяется в подобном»).
