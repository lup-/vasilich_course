## План ролика «Как стучаться в чужие двери» (Manim, ~90 с)

**Одна мысль:** данные приходят из чужого API ящиком JSON, успех проверяется статусом,
а ответ сверяют с источником правды.

| № | Время | Кадр | Что происходит | Надписи в кадре |
|---|-------|------|----------------|-----------------|
| 1 | 0–12 с | Завязка | Протокол лаборатории в PDF «заперт»; данные лежат и в интернете; ноутбук «стучится» в чужую дверь | «ЖИВЫЕ ДАННЫЕ: ИНТЕРНЕТ — ЕЩЁ ОДИН СКЛАД» |
| 2 | 12–30 с | Запрос | URL с параметрами `?name=acetone` летит к серверу; сервер отвечает: сначала статус, потом ящик JSON | «ЗАПРОС: URL + ПАРАМЕТРЫ → СТАТУС → JSON» |
| 3 | 30–48 с | Статусы | Таблица статусов: 200/404/401/429/5xx; «200» горит люминофором, ошибки — ржавым | «200 — УСПЕХ · 404 — НЕТ ТАКОГО · 429 — ПОДОЖДИ» |
| 4 | 48–70 с | JSON → таблица | Ящик JSON открывается, пары «ключ: значение» складываются в строки таблицы (ацетон: формула, масса, SMILES) | «JSON → ТАБЛИЦА pandas» |
| 5 | 70–90 с | Сверка | Таблица сверяется с PubChem («источник правды»); финальная формула | «СВЕРЯЙ С ИСТОЧНИКОМ: НЕ ДОВЕРЯЙ ЧЕРТУ НА СЛОВО» |

**Что НЕ показываем:** лиц и сюжета — ролик чисто технический, про работу с API.
После ролика — слайды 5–7 (PubChem, CrossRef/OpenAlex, PyMuPDF), затем квиз (слайд 8).
