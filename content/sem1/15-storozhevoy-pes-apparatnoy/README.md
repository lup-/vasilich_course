# Занятие 15. «Сторожевой пёс аппаратной»

> Семестр 1 · Блок 3 «Пыльные архивы» · Курс 04, лекции 09–11

**Сюжетная арка:** Логи цеха валятся потоком, датчики ночью «выдумывают» невозможные значения
(минус 150 градусов в сушилке!). Собираем «сторожевого пса аппаратной» — скрипт-пайплайн, который
сам читает журнал датчиков, чистит и проверяет качество данных, считает статистику и бьёт тревогу
при аномалиях. Ночью сторож ловит настоящую аварию (скачок давления 8.4 атм на Линии 1).

- `slides-plan.md` — план слайдов занятия (типы из `slides.md`, без `welcome`/`congrats`);
- `comic.md` — сценарий комикса по панелям (стиль — `../_shared/comic-style.md`);
- `files/` — файлы занятия:
  - `dannye/zhurnal-datchikov.xlsx` (+ `.csv`) — журнал датчиков цеха за ночную смену, 291 строка,
    с встроенными дефектами (дубликаты, пропуски, «галлюцинации датчиков», мусор, одна настоящая
    аномалия);
  - `dannye/normy-datchikov.csv` — справочник допустимых диапазонов по датчикам;
  - `pamyatka-payplajn.md` — памятка «как заказать агенту пайплайн и проверить»;
  - `zadanie-storozh.md` — бриф главной практики (слайд 10);
  - `quiz-kachestvo-dannyh.md` — материал квиза (слайд 7);
- `links.md` — внешние ссылки и источники.
