# Памятка: как заказать агенту пайплайн и проверить результат

> К занятию 15. Слайд 8 (ресурсы) и слайд 10 (практика). Лекции 09–11 курса-04.

## Формула заказа (4 пункта)

1. **Что есть** — файл(ы) и формат (например, `zhurnal-datchikov.xlsx` — журнал датчиков цеха);
2. **Что сделать** — очистить, посчитать, найти аномалии, собрать сводку;
3. **Какой результат** — что показать и/или сохранить (`svodka.txt`);
4. **Как проверить** — контрольные суммы, сходимость цифр, код для каждой цифры.

## Пример запроса

```
Прочитай zhurnal-datchikov.xlsx. Удали дубликаты, разберись с пропусками, приведи числа
с запятой к числу, убери мусор. Посчитай статистику по значению. Сверь каждый датчик
с normy-datchikov.csv. Отдели невозможные значения от настоящих тревог. Если есть тревога —
собери экстренную сводку, сохрани в svodka.txt и выведи через print(). Покажи, откуда взялось
каждое контрольное число.
```

## Почему «по шагам», а не «всё сразу»

Сразу вся задача — риск запутаться и не найти, где сломалось. Разбивай на этапы и проверяй каждый:

| Этап | Что проверяем |
|---|---|
| Загрузка | Первые строки, типы данных, число строк |
| Очистка | Сколько дубликатов/пропусков убрали |
| Качество | Число строк до и после, контрольные суммы |
| Статистика | Среднее, медиана, минимум, максимум |
| Аномалии | Сверка с нормами, «галлюцинации» отдельно от тревог |
| Сводка | Тревога в выводе, файл сохранён |

## Чек-лист сомнения (каждую цифру проверяем)

1. **Источник** — откуда данные, за какой период, полные ли?
2. **Количество** — число строк сходится с ожидаемым?
3. **Контрольная сумма** — итог по группам = общий итог?
4. **Единицы** — рубли/тысячи, градусы/доли, проценты?
5. **Смысл** — похоже ли на правду? «Рекордное» значение — повод проверить.
6. **Второй способ** — пересчитать иначе (вручную, другой библиотекой, Excel).

## Галлюцинации ИИ и датчиков

- ИИ может уверенно назвать цифру, которой нет в данных: требуй «покажи код, которым посчитано».
- Датчики тоже «галлюцинируют»: невозможное значение (−150°C в сушилке, давление 9999 атм) —
  это сбой датчика, строка-мусор, а не авария производства.
- Среднее обманчиво при выбросах: сравнивай со **медианой**; если среднее сильно больше — ищи выброс.
