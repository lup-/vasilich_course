# Задание «Собери сторожа аппаратной» (слайд 10)

## Контекст

Ночная смена 13 января 2120 г. Логи цеха валятся потоком, датчики «выдумывают» невозможные
значения, а проверять всё вручную некому. Задача — через агента собрать «сторожевого пса
аппаратной»: скрипт-пайплайн, который сам читает журнал датчиков, чистит, проверяет качество
и при аномалиях бьёт тревогу.

## Что нужно сделать (6 шагов)

1. **Прочитать журнал.** Локально — файл `dannye/zhurnal-datchikov.xlsx` (или `.csv`).
   На платформе — встроенный фрагмент `zhurnal` в коде. Показать первые 5 строк и типы данных.
2. **Очистить.** Удалить дубликаты; решить, что делать с пропусками; привести числа с запятой
   («22,5» → 22.5); удалить мусор («шум»). Объяснить, что удалили и почему.
3. **Проверить качество.** Сколько строк было и стало; сколько найдено дубликатов и пропусков.
4. **Посчитать статистику** по колонке «значение»: среднее, медиану, минимум, максимум, разброс.
5. **Найти аномалии.** Сверить каждый датчик с нормами (`dannye/normy-datchikov.csv` или таблица
   в коде). Отдельно пометить невозможные значения («галлюцинации датчиков») и настоящие тревоги.
6. **Сформировать экстренную сводку.** Если есть тревога — список строк-аномалий (время, датчик,
   что не так), сохранить в файл `svodka.txt` и вывести через `print()`.

## Контрольные числа (для полного локального журнала)

| Показатель | Значение |
|---|---|
| Строк в журнале | 291 |
| Дубликатов | 3 |
| Пропусков | 5 |
| Строк после очистки | 282 |
| Аномалий по нормам | 5 |
| Настоящих тревог | 1 |

Настоящая тревога: **Р1-Л1, давление 8.4 атм, Линия 1, 03:10**. Остальные 4 аномалии —
«галлюцинации датчиков» (физически невозможные значения: −150°C, 9999 атм, вибрация 420,
расход 99999).

> На платформе, если работаешь со встроенным фрагментом журнала (14 строк), числа будут меньше —
> это нормально. Главное — логика: очистка, сверка с нормами и тревога «давление 8.4 атм в 03:10»
> в сводке.

## Как сформулировать задачу агенту (локальный путь)

```
Прочитай файл dannye/zhurnal-datchikov.xlsx. Удали дубликаты, разберись с пропусками,
приведи числа с запятой к числу, убери мусор. Посчитай статистику по значению. Сверь каждый
датчик с dannye/normy-datchikov.csv. Отдели невозможные значения от настоящих тревог.
Если есть тревога — собери экстренную сводку, сохрани в svodka.txt и выведи через print().
Покажи, откуда взялось каждое контрольное число.
```

## Как проверить результат

- Число строк сходится (291 → 282), дубликатов 3, пропусков 5.
- Каждая аномалия показана кодом, а не «на словах».
- В сводке есть тревога: давление 8.4 атм, Линия 1, 03:10.
- «Галлюцинации датчиков» помечены отдельно и не выданы за аварии.
- Выводы опираются на цифры из данных.
