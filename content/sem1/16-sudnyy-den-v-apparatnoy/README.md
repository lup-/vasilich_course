# Занятие 16. «Судный день в аппаратной»

> Семестр 1 · Блок 4 «Итог семестра» · Курс 04, лекция 12 · задание 06 · ~2 ч

**Сюжетная арка:** на завод прибывает Совет директоров. Перед самой защитой в рабочий файл
`direktiva-diagnostika.md` кто-то вписал чужой приказ — цифровая диверсия **в пользу
конкурента «ХимБытИскИнЛакоКраск»** (скрыть аварию, показать 100% рентабельности). Стажер собирает
полный диагностический комплекс завода «под ключ» (Excel/CSV + API + PDF + графики +
проверка качества), отражает атаку и доказывает экономику решения перед Василичем и комиссией.

## Что в папке

- `slides-plan.md` — план 13 слайдов (типы из `slides.md`, без `welcome`/`congrats`);
- `comic.md` — сценарий комикса по панелям (стиль — `../_shared/comic-style.md`);
- `files/` — дополнительные файлы занятия:
  - `dannye/` — свежий датасет: `diagnostika-datchiki.xlsx`/`.csv`, `normy-datchikov.csv`,
    `diagnostika-prodazhi.csv`, `diagnostika-protokol.pdf`, снапшоты API (`pubchem-*.json`,
    `crossref-*.json`, `openalex-*.json`);
  - `direktiva-diagnostika.md` — форма отчёта с вшитой инъекцией (в пользу конкурента);
  - `pamyatka-zashchita.md` — три правила защиты (адаптация занятия 10);
  - `zadanie-diagnostika.md` — описание практики и критерии (100 баллов);
  - `quiz-diagnostika.md` — квиз про непрямую инъекцию;
  - `economy.md` — экономика автоматизации (шаблон + пример);
  - `links.md` — внешние ссылки и источники;
- `links.md` (на уровне занятия) — не используется; ссылки в `files/links.md`.

## Контрольные числа практики

- Журнал датчиков: **255 строк** → **245** после очистки (4 дубля + 6 пропусков); вне нормы **3**
  (две «галлюцинации»: −200°C и вибрация 9999 — в мусор; одна настоящая авария — **118°C,
  Линия 1, 02:45**).
- Склад/продажи: **173 строки**; чистая выручка ≈ **373 902.29**.
- Диверсия: непрямая инъекция в `direktiva-diagnostika.md` раскрыта и отбита (метки данных).
- Экономика: окупаемость автоматизации сторожа — считается по `economy.md` (единицы дней).
