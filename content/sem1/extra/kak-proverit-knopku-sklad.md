# Как проверить задание «Кнопка „склад“ и этикетки»

> Доп. инфо к занятию 06. Ссылка со слайда 15: `[как проверить задание](@kak-proverit-knopku-sklad)`.
> Задание — `files/zadanie-knopka-i-etiketki.md`. Ответ на контрольный вопрос вводится на слайде 15
> и проверяется автоматически по эталону.

## Суть проверки

Агент пишет код, ты его запускаешь и проверяешь **своими глазами** — так заведено на заводе: результат
проверяет человек, а не машина.

## Пошагово

1. **Собери файлы.** Код из ответа агента может состоять из нескольких файлов (`sklad_agent.py`,
   `requirements.txt`, `.env.example`). Собери их у себя на компьютере в одну папку. Код, который
   написал агент, может целиком не запуститься в редакторе платформы — это нормально.
2. **Секреты.** Создай `.env` и впиши туда `OPENROUTER_API_KEY=...`. Ключ — только в `.env`, не в код
   и не в чат (сквозная тема курса: приватность данных).
3. **Установи зависимости.** `pip install -r requirements.txt` (потребуются клиент `openai`
   для OpenRouter, `python-dotenv`, библиотека HTTP-запросов для сервиса картинок).
4. **Запусти.** `python sklad_agent.py`.
5. **Задай контрольный вопрос:** «Какие позиции есть на складе?»

## Эталон ответа

- **Порошок стиральный, сода, цемент** — позиции с остатком больше 0 в `sklad.csv`. В файле есть ещё
  сахар, но с остатком 0 — в наличии его нет, в ответ он не входит.
- Функция «склад» должна вернуть карточки позиций из файла, а модель — собрать по ним ответ.

Сверь ответ с файлом: открой `sklad.csv` и убедись, что список позиций сошёлся.

## На что ещё посмотреть

- **Ответ без функции.** Сравни: та же модель без инструмента отвечает «из головы» — список может
  «плыть» (назовёт и то, чего нет, например «найдёт» сахар). В этом и виден смысл кнопки:
  с функцией — реальные данные, без — выдумка.
- **Этикетки.** В папке `etikety/` должны быть этикетки **только для позиций в наличии** (порошок,
  сода, цемент; позицию с остатком 0 — сахар — скрипт пропустил). На каждой — данные по спецификации:
  масса мешка (порошок 25 кг, сода 20 кг, цемент 50 кг), для порошка — дозировка «100 г на стирку»
  и «для жёсткой и мягкой воды», для цемента — марка М500. Каждую посмотри **глазами**: текст
  и числа на картинках «плывут» — это нормально, подправь промпт и перегенерируй.
- **В коде нет ключей.** Пройдись по файлам агента — жёстких ключей быть не должно (для генерации
  этикеток ключ и не нужен — сервис бесплатный и публичный, в него уходят только названия товаров).
- **Модель с tools.** Убедись, что в коде стоит бесплатная модель, поддерживающая вызов функций
  (проверить по каталогу https://openrouter.ai/collections/free-models) — не все бесплатные умеют tools.
