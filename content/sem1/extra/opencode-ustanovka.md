# opencode: ИИ-агент на своём компьютере

> Доп. инфо к занятиям 04 и 05. Ссылки: занятие 04 (слайды 10, 11, 13), занятие 05 (слайды 14, 15):
> `[opencode](@opencode-ustanovka)`. Официальная документация — https://opencode.ai/docs/.

## Зачем

**opencode** — открытый ИИ-агент для терминала. Ты описываешь задачу словами, агент пишет и запускает
код, а ты проверяешь результат. Программировать при этом не нужно — ровно как на заводе: Василич
поручает, стажёр проверяет. С локальным opencode практику курса можно гонять у себя на компьютере —
по-настоящему и бесплатно (модели берём из бесплатного каталога OpenRouter).

## Установка

Проще всего — скрипт установки (macOS/Linux):

```bash
curl -fsSL https://opencode.ai/install | bash
```

Или через npm:

```bash
npm install -g opencode-ai
```

Другие способы (Homebrew, Arch, Windows/WSL и т.д.) — на https://opencode.ai/docs/. После установки
проверь:

```bash
opencode --version
```

## Настройка модели

В курсе используем бесплатные модели OpenRouter. Ключ OpenRouter кладём в файл `.env` в папке проекта:

```bash
OPENROUTER_API_KEY=sk-or-...
```

Секреты — только в `.env` (он добавлен в `.gitignore`), не в код и не в чат. Перед запуском проверяй,
что модель ещё бесплатная: https://openrouter.ai/collections/free-models.

## Первый запуск

1. Открой терминал в папке с задачей: `cd /путь/к/папке`.
2. Запусти агента: `opencode`.
3. Опиши задачу словами — как рассказывал бы младшему помощнику: что собрать, из чего, как проверить.
4. Агент напишет файлы и команды, ты их запускаешь и проверяешь результат своими глазами.

## Советы

- Задачу описывай подробно: что должно получиться, какие данные использовать, как проверить.
- Результат проверяй всегда сам (сквозная тема курса: не доверяй ИИ без проверки).
- Если что-то пошло не так — опиши ошибку агенту словами, он поправит.
- Полезные команды: `/help` — справка, `/undo` — откатить последнее изменение.
