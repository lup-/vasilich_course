## Что такое промпт

Промпт — текст, который мы отдаём модели. Хороший промпт — это «приказ по уставу»: подчинённому
(модели) говорят чётко, и она отвечает по делу; скажешь «как попало» — сделает «как попало».

## Части промпта (формализация)

- **Роль** — кто модель: «ты — технолог цеха стирки». Роль меняет стиль, тон и точность.
- **Инструкция / задача** — что сделать: «составь памятку», «посчитай», «найди».
- **Вопрос** — что нам нужно: «где лежит порошок?», «сколько соды уходит в месяц?».
- **Контекст** — вводные и условия: данные, ограничения, формат ответа.
- **Примеры (few-shot)** — образцы «ввод → вывод», по которым модель повторяет формат.

Не все части обязательны, порядок свободный. Правило: **инструкцию лучше ставить в конец** — тогда
модель выполняет задание, а не «дочитывает контекст» вместо работы.

## Инструкции

Самая простая техника: дать модели задание. Модели умеют выполнять задачи, которые словами не опишешь:
вычистить имена из текста, убрать лишнее, оценить по критериям, собрать данные в формат.

## Роли

Назначить модели роль — «как сказать подчинённому, с какой должности он сегодня работает». Роль меняет
стиль и может повысить точность (например, «ты — математик» помогает при расчётах). Один запрос —
разные роли — разные ответы: у технолога с цифрами, у снабженца с закупками. Роль надо проверять:
помогла она или навредила.

## Примеры: few-shot

**Zero-shot** — без примеров; **one-shot** — один пример; **few-shot** — два и больше. Примеры задают
формат вывода, который словами трудно объяснить (таблица, список «имя: должность», метка «хорошо/плохо»).
Обычно чем больше примеров, тем точнее ответ. Техника называется также in-context learning.

```text
«Отличный порошок, ничего не прилипает»: хорошо
«Мешок порвался по дороге»: плохо
«Крышка не закрывается»: плохо
```

## Настройки LLM (конфигурация)

- **Температура** — «насколько строго по уставу»: низкая (≈0.2) — сухой стабильный ответ, высокая (≈1.5) —
  фантазия и разнообразие, вплоть до бессмыслицы. Для фактов держим низкой.
- **Top-p** — отсечка по вероятности выборов (nucleus sampling): влияет на разнообразие похоже
  на температуру.
- **Max tokens** — лимит длины ответа: мало — модель «обрежется» на полуслове.
- Прочие: stop sequences (на чём остановиться), штрафы за повторения (frequency/presence penalty).

Даже с температурой 0 и top-p 0 модель может дать не одинаковый ответ при повторе (случайность в
вычислениях GPU) — проверяем результат.

## Комбинирование техник

Почти любой хороший промпт — комбинация: роль + инструкция + контекст + примеры + настройки.
Три правила устава:

1. **Коротко.** Лишние абзацы — лишние токены (деньги). Только нужное.
2. **Без секретов.** В промпт не пишем пароли и ключи — только рабочие данные (приватность).
3. **Проверяй.** Роль и примеры помогают, но не гарантируют правду: ответ сверяем с фактами.
