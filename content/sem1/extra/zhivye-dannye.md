## Веб-API: дверь на чужой склад (лекция 07 курса-04)

Многие данные живут не в файлах, а в интернете. **Веб-API** — это «двери» на сайтах, через которые
программа получает данные: приходишь по адресу (**URL**), называешь, что нужно (параметры после `?`),
забираешь ответ в формате **JSON**.

Ключевые шаги запроса:

1. **Запрос:** `requests.get(url, params=...)`;
2. **Проверка статуса:** `resp.status_code`;
3. **Разбор ответа:** `resp.json()`;
4. **Таблица:** из словаря/списка делаем DataFrame;
5. **Анализ и график:** дальше как с любой таблицей.

### Статусы ответа

| Код | Значение | Что делать |
|---|---|---|
| 200 | Успех | Продолжать |
| 400 | Неверный запрос | Проверить параметры URL |
| 401 / 403 | Нет прав / нужен ключ | Добавить ключ (в `.env`), проверить |
| 404 | Нет такого ресурса | Проверить URL |
| 429 | Слишком много запросов | Подождать |
| 5xx | Проблема на сервере | Подождать, повторить |

**API-ключ** — секретный код для части API. В код и в чат его не вставляем: секреты живут в `.env`
и подгружаются в окружение. Все API занятия 14 бесплатные и без ключей.

## PubChem: источник правды по веществам (лекция 06 курса-05)

**PubChem** — крупнейшая бесплатная база соединений: миллионы веществ со структурой и свойствами.
Когда агент «придумывает» вещество — сверяемся с PubChem.

PUG REST — данные по ссылке, формат:

```
https://pubchem.ncbi.nlm.nih.gov/rest/pug/<домен>/<идентификатор>/<операция>/<выход>
```

Примеры (проверены):

- SMILES и свойства по названию:
  ```
  https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/acetone/property/MolecularFormula,MolecularWeight,CanonicalSMILES,InChIKey/JSON
  ```
- Числовой ID (CID) по названию:
  ```
  https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/acetone/cids/TXT
  ```

Из Python всё сводится к «запрос → JSON → таблица», как в курсе-04:

```python
import requests

url = ("https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/acetone"
       "/property/MolecularFormula,MolecularWeight,CanonicalSMILES,InChIKey/JSON")
props = requests.get(url).json()["PropertyTable"]["Properties"][0]
print(props["MolecularFormula"], props["MolecularWeight"])
print(props["CanonicalSMILES"])
print(props["InChIKey"])
```

Полезные идентификаторы:

- **CID** — числовой ID соединения: стабилен, удобен для ссылок;
- **InChIKey** — короткий (27 символов) «отпечаток» молекулы: если совпадает — это одно вещество,
  удобен для дедупликации.

**Приём проверки «придуманной» молекулы:** агент назвал вещество — запроси PubChem по названию,
сравни формулу/массу/SMILES с тем, что дал агент. Не совпало — правь.

Частые проблемы: `404` — неверное имя (например, «ксилол» без указания изомера вернёт ошибку — уточни
CID или конкретное вещество); медленные ответы на много веществ — добавляй паузы; русские названия —
надёжнее английское имя.

## Научные статьи: CrossRef и OpenAlex

**DOI** — цифровой идентификатор статьи, её «паспорт». Любой вывод в техпаспорте подкрепляется
ссылкой-DOI, которую можно открыть (`https://doi.org/<DOI>`).

- **CrossRef** — реестр цитирований: `https://api.crossref.org/works?query=...&rows=3`;
- **OpenAlex** — открытая база публикаций: `https://api.openalex.org/works?search=...`.

Пример запроса к CrossRef:

```python
import requests

otvet = requests.get("https://api.crossref.org/works",
                     params={"query": "poly methyl methacrylate solubility acetone",
                             "rows": 3}).json()
for statya in otvet["message"]["items"]:
    print(statya["DOI"], "—", statya["title"][0][:60])
```

Проверено: запрос «растворимость ПММА в ацетоне» возвращает статью
**DOI 10.1016/j.supflu.2005.12.018** («High-pressure viscosity and density of poly(methyl methacrylate)
+ acetone …»).

## PDF: текст и таблицы (лекция 08 курса-04)

PDF — формат для печати, а не для обработки: он хранит координаты текста, а не структуру таблиц.
Поэтому извлечение — итеративный процесс: извлекли → посмотрели → уточнили.

Базовое извлечение текста:

```python
import fitz  # PyMuPDF

doc = fitz.open("issledovanie-kraski.pdf")
for page_num in range(len(doc)):
    print(doc[page_num].get_text()[:500])
```

Весь документ сразу в Markdown для ИИ — надстройка PyMuPDF4LLM:

```python
import pymupdf4llm

md = pymupdf4llm.to_markdown("issledovanie-kraski.pdf")
print(md[:3000])
```

Таблицы:

```python
page = doc[0]
tables = page.find_tables()
if tables.tables:
    df = tables[0].to_pandas()   # таблица → DataFrame
```

Текстовый PDF vs скан: текстовый — `get_text()` работает сразу; скан — нужен OCR (распознавание
символов по картинке).

Частые проблемы: пустой текст — вероятно скан; таблица «разъехалась» — попробовать `find_tables()`
или другой метод; огромный PDF тормозит — извлекать по страницам.

## Проверка результата

- Доли компонентов из PDF сводим в 100% и сверяем с протоколом глазами.
- «Придуманное» агентом вещество сверяем с PubChem (формула, масса, SMILES, InChIKey).
- У каждого вывода про растворимость — открывающаяся ссылка-DOI.
- В коде проверяем `resp.status_code` — иначе «успех» может оказаться ошибкой.

## Приватность и экономика

- Публичные API без ключей: в них уходят только рабочие данные, без секретов. Ключи (если появятся) —
  в `.env`.
- Лимиты: не гоняем запросы в цикле по 10 000 раз, добавляем паузы.
- Экономика: технолог-химик разбирал бы образец полдня со справочниками; агент с API — минуты,
  а новый образец — повторный запуск. Проверенные цифры и ссылки — это готовая часть
  диагностического отчёта завода.
