# Библиотека мемов для курса

Подбор мемов под контент через **векторный поиск по описаниям** (локально, без API).

## Что где лежит

| Файл | Что это |
|---|---|
| `train-00000-of-00001.parquet` | исходный датасет (2508 мемов: картинка + русское описание) |
| `catalog.parquet` | каталог: `id, path, text, text_len, is_clean, flag_reason` |
| `embeddings.npy` + `embeddings-meta.json` | векторный индекс описаний (модель `paraphrase-multilingual-MiniLM-L12-v2`, 384-d) |
| `images/{id}.jpg` | сами картинки (2507 шт., JPEG 512×512) |
| `prepare.py` | сборка каталога + извлечение картинок + флаг «чистоты» |
| `embed.py` | расчёт эмбеддингов |
| `pick_meme.py` | **поиск мемов под запрос** (запускать через обёртку `pick_meme`) |
| `pick_meme` | обёртка запуска (bash): использует `.venv`, работает из корня репозитория |
| `requirements.txt` | зависимости (устанавливаются в `.venv`) |

## Как пользоваться

Из корня репозитория (окружение подхватывается автоматически):

```bash
memes/pick_meme "не доверяй ИИ без проверки результата"
memes/pick_meme "API-ключи в .env, приватность" --top 10
memes/pick_meme "кот не хочет работать" --json   # машиночитаемо для агента
```

Параметры:
- `--top N` — сколько кандидатов вернуть (по умолчанию 5);
- `--min-score 0.3` — отсечка по косинусной близости (0..1);
- `--all` — включить помеченные мемы (мат/оскорбления) — только для ручного просмотра;
- `--json` — вывод списком JSON `{id, score, is_clean, path, text}`.

## Правила для агента

1. **По умолчанию показываются только «чистые» мемы** (`is_clean=True`). Мемы с флагом
   (`is_clean=False`, причины в `flag_reason`) **не предлагать в контент курса** — это мат,
   оскорбления или национализм (нарушает правила курса).
2. Описания — русские, но сам текст на картинке часто английский; флаг учитывает оба языка.
3. Подбор субъективен: агент предлагает топ кандидатов, **человек выбирает и проверяет**
   картинку глазами (сквозная тема курса: не доверяй ИИ без проверки).
4. Картинку после выбора брать по `path` (`images/{id}.jpg`). Не редактировать каталог и индекс.

## Пересборка (если менялся исходный parquet)

```bash
memes/.venv/bin/python memes/prepare.py && memes/.venv/bin/python memes/embed.py
```

Первая установка окружения: `python3 -m venv memes/.venv && memes/.venv/bin/pip install -r memes/requirements.txt`.
Модель (~240 МБ) скачивается один раз в `~/.cache/fastembed`.
