# Программа курса: Генеративный ИИ для начинающих (Microsoft)
> Оригинал: [microsoft/generative-ai-for-beginners](https://github.com/microsoft/Generative-AI-For-Beginners). Контент подготовлен на основе официального русского перевода (`translations/ru`). Язык: русский (RU).
## О курсе
Практический курс из 21 урока о том, как создавать приложения с генеративным ИИ и большими языковыми моделями (LLM). Уроки разделены на два типа: **«Учимся»** (теория концепций генеративного ИИ) и **«Создаём»** (концепция + код на Python и TypeScript). Каждый урок включает примеры, упражнения, задание, проверку знаний и раздел «Продолжайте обучение».
## Цели обучения
После прохождения курса вы сможете:
- объяснять, что такое генеративный ИИ и как работают большие языковые модели;
- выбирать подходящие модели и провайдеров под свою задачу;
- применять инженерию подсказок (prompt engineering) для предсказуемых результатов;
- строить приложения: генерация текста, чат-боты, поиск по векторным базам, генерация изображений;
- использовать вызовы функций, проектировать UX, обеспечивать безопасность и управлять жизненным циклом ИИ-приложения (LLMOps);
- применять RAG, открытые модели (Hugging Face), AI-агентов, тонкую настройку LLM и малые языковые модели (SLM).
## Предварительные требования
- Базовые знания программирования (Python и/или TypeScript);
- доступ к одному из провайдеров LLM (Azure OpenAI, OpenAI, Microsoft Foundry, Hugging Face, локальные модели через Ollama/Foundry Local) — задания опциональны по провайдерам.

## Структура курса: задания
Задания представляют собой Jupyter-ноутбуки (`*.ipynb`) с упражнениями и описания в секции «Задание» каждой лекции. Ноутбуки находятся в `assignments/`, примеры кода — в `code/`. Доступны варианты под провайдеров: Azure OpenAI (`aoai-*`), OpenAI (`oai-*`), Microsoft Foundry/GitHub Models (`githubmodels-*`).
## Как использовать подготовленную папку
- `program.md` — настоящая программа курса;
- `lectures/` — 22 лекции в Markdown (00–21), картинки не скопированы (вместо них — комментарии);
- `assignments/` — ноутбуки-задания по урокам;
- `code/` — примеры кода из уроков.

## Продолжительность
Ориентировочно 21 занятие; каждый урок рассчитан примерно на 2–4 часа (чтение + упражнения + задание).
