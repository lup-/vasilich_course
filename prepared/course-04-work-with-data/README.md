# course-04-work-with-data
Авторский курс-модуль «Работа с данными с помощью ИИ» двухсеместровой программы «Генеративный ИИ на практике». Подготовлен как исходник для дальнейшей сборки общей программы.

## Источники
- Материал авторский, создан на основе проверенных публичных ресурсов (см. `references/`).
- Проверенные ссылки: pandas, Python Data Science Handbook, PyMuPDF, Jupyter, Kaggle Learn, Plotly, matplotlib, n8n.

## Структура
- `program.md` — программа курса
- `lectures/` — 12 лекций (.md)
- `assignments/` — задания: ноутбуки (.ipynb) + файлы-инструкции (.md)
- `references/` — список проверенных ссылок-источников

## Примечания
- Язык: русский (RU). Картинки и медиа не копируются (заменены комментариями).
- Аудитория: студенты с нулевым Python; код пишется через LLM-агентов, студент проверяет результат.
- Сквозные темы программы: офисная автоматизация (Excel, n8n) и экономика/оценка применения ИИ.
