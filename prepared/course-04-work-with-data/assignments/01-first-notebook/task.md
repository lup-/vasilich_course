# Задание 01. Знакомство с ноутбуком и первая таблица

## Цель
Освоить базовую работу в Jupyter (Google Colab): ячейки, запуск, таблицы. Подготовиться к формату сдачи всех заданий курса.

## Что сделать
1. Откройте https://colab.research.google.com → Новый ноутбук.
2. Выполните шаги из `assignment.ipynb` по порядку (Shift+Enter в каждой ячейке).
3. Заполните ячейку «Мои выводы».
4. Скачайте ноутбук: File → Download → .ipynb.

## Ответьте на вопросы (запишите в ячейку «Мои выводы»)
1. Что такое ячейка кода и ячейка Markdown? Чем они отличаются?
2. Какая команда запускает ячейку?
3. Что получилось в таблице после шага 3 (сколько строк, какие столбцы)?
4. Чему равна общая стоимость всех товаров (столбец «итого»)?
5. Какие 2 трудности возникли (если возникли) и как вы их решили?

## Критерии приёма
- [ ] Ноутбук содержит все 5 шагов (выводы видны под ячейками).
- [ ] Ячейка «Мои выводы» заполнена (5 ответов).
- [ ] Файл скачан в формате `.ipynb`.
