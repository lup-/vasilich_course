# Задание 03. Графики и интерактивная визуализация

## Цель
Научиться строить графики (matplotlib) и интерактивные диаграммы (Plotly) через агента и правильно их оформлять.

## Что сделать
1. Возьмите `sales.csv` из задания 02 (или создайте новый).
2. Загрузите в Colab и откройте `assignment.ipynb`.
3. Выполните шаги 1–4.
4. По желанию: попросите агента добавить круговую диаграмму долей регионов и гистограмму распределения сумм.
5. Заполните выводы.

## Ответьте на вопросы (запишите в выводы)
1. Что показывает линейный график продаж по месяцам? Есть ли рост/спад/сезонность?
2. Какой регион лидирует на столбчатой диаграмме? Совпадает ли это с таблицей из задания 02?
3. Чем интерактивный график Plotly удобнее статичного matplotlib? Что можно делать с ним мышью?
4. Назовите 3 обязательных элемента оформления, которые вы добавили на графики (или попросили агента добавить).
5. Есть ли на графиках выбросы или неожиданные значения? Что бы вы проверили дальше?

## Критерии приёма
- [ ] Все графики построены, оси и заголовки подписаны.
- [ ] Интерактивный график Plotly присутствует.
- [ ] Выводы заполнены (5 ответов).
