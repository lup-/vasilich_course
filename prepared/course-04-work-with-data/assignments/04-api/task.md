# Задание 04. Данные из API: погода

## Цель
Научиться получать данные из публичного веб-API (без ключей), превращать JSON в таблицу и анализировать.

## Что сделать
1. Откройте `assignment.ipynb` в Colab.
2. Замените координаты в шаге 1 на координаты вашего города (можно найти в Google Maps: щёлкнуть правой кнопкой по карте — координаты вверху).
3. Выполните шаги 1–4.
4. По желанию: получите ещё курс валют с бесплатного API (например, https://open.er-api.com) и постройте таблицу.
5. Заполните выводы.

## Ответьте на вопросы (запишите в выводы)
1. Какой статус ответа получили? Что он означает?
2. Какой город и какой период прогноза вы взяли? Сколько строк в таблице?
3. Какая максимальная и минимальная температура за период?
4. Что такое «JSON» применительно к ответу API? Как он превратился в таблицу?
5. Зачем в запросе параметры (`latitude`, `longitude`)? Что будет, если их перепутать местами?

## Критерии приёма
- [ ] Шаг 1 выполнен с вашими координатами (статус 200).
- [ ] Таблица прогноза построена.
- [ ] График построен с подписями.
- [ ] Выводы заполнены (5 ответов).
