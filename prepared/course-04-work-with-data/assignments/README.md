# Задания курса-04 «Работа с данными»

Каждое задание — папка с ноутбуком `assignment.ipynb` и файлом-инструкцией `task.md`.

## Как сдавать
1. Выполните задание в Google Colab (https://colab.research.google.com).
2. Скачайте ноутбук: File → Download → .ipynb.
3. Заполните файл `task.md` (ответы на вопросы) — к нему приложите скриншоты/итоги, где нужно.
4. Сдайте оба файла (или ноутбук с выводами внутри).

## Список заданий
| № | Задание | Папка | Лекции |
|---|---|---|---|
| 01 | Знакомство с ноутбуком и первая таблица | `01-first-notebook/` | 02–03 |
| 02 | pandas: чистка и анализ таблицы продаж | `02-pandas-sales/` | 04–05 |
| 03 | Графики и интерактивная визуализация | `03-visualization/` | 06 |
| 04 | Данные из API: погода | `04-api/` | 07 |
| 05 | Извлечение данных из PDF | `05-pdf/` | 08 |
| 06 | Итоговый проект: отчёт «с нуля» | `06-final-project/` | 10–12 |

## Важно
- Код пишется через LLM-агента, но вы отвечаете за проверку результатов (контрольные суммы, свежий взгляд на числа).
- В каждом ноутбуке есть ячейки `TODO` и пустые — заполняйте их или просите агента это сделать.
- Пункты «Выводы» обязательны: без них задание не засчитывается.
