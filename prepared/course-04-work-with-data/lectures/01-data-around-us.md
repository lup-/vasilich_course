# 01. Данные вокруг нас: зачем ИИ для работы с данными

> Семестр: 1 · Курс: «Работа с данными» (course-04) · Время: ~2 часа

## Введение

Каждый день мы работаем с данными, даже не замечая этого: таблица Excel с продажами, PDF-файл с договором, список клиентов, выгрузка из бухгалтерии, файл CSV из банка. Обычно эта работа — самая скучная часть любого дела: скопировать, переформатировать, посчитать, составить отчёт. Именно здесь ИИ-инструменты (чат-боты и агенты) дают максимальный эффект.

В этом курсе мы будем учиться использовать ИИ как **рабочий инструмент для работы с данными**. Главная идея: вы не обязаны уметь программировать. Вы должны уметь:

1. объяснить задачу на понятном языке;
2. проверить, что ИИ сделал правильно;
3. исправить его, если он ошибся.

## Что такое данные и почему они «вокруг нас»

Данные — это информация, записанная в какой-то форме. Примеры из повседневной работы:

- **Таблицы**: Excel, CSV, Google Sheets — продажи, бюджеты, списки сотрудников;
- **Документы**: PDF, Word — договоры, отчёты, инструкции, статьи;
- **Веб-данные**: цены на сайтах, курсы валют, погода, данные госуслуг;
- **Тексты**: письма, отзывы клиентов, комментарии.

Часто данные нужно **преобразовать**: из одного формата в другой, из «сырого» вида в удобный, из набора чисел в понятный отчёт с графиками.

### Типовые задачи, которые решает этот курс

| Задача | Классический способ | Способ с ИИ |
|---|---|---|
| Свести продажи по месяцам и регионам | Вручную в Excel, 2 часа | Агент пишет код за 5 минут, вы проверяете |
| Достать текст из PDF-договора | Копировать вручную | Агент извлекает автоматически |
| Получить курс валют и построить график | Искать вручную, рисовать в Excel | Агент скачает с API и нарисует график |
| Собрать еженедельный отчёт | Делать каждый раз заново | Агент/автоматизация делает по расписанию |

## Что умеет ИИ с данными

Современные большие языковые модели (LLM) и агенты умеют:

- **писать код**: сгенерировать Python-скрипт для обработки таблицы, извлечения данных из PDF, запроса к API;
- **запускать код**: агенты (или инструменты вроде Jupyter) могут выполнить этот код и вернуть результат;
- **объяснять**: рассказать, что означает таблица, почему цифры такие, какие выводы можно сделать;
- **преобразовывать**: перевести данные из одного формата в другой, исправить ошибки, объединить файлы;
- **готовить отчёты**: собрать текст, таблицы и графики в единый документ.

Важно понимать: модель **не «знает» ваши файлы сама по себе**. Она видит их только тогда, когда вы их прикрепляете или даёте агенту доступ к папке. Всё, что агент делает с файлами, — это результат чтения их содержимого и выполнения кода.

### Простая схема работы с агентом

```
Вы (задача на русском языке)
      │
      ▼
Агент (пишет код на Python: pandas, matplotlib, PyMuPDF...)
      │
      ▼
Компьютер (запускает код, читает файлы)
      │
      ▼
Результат (таблица, график, PDF-отчёт)
      │
      ▼
Вы проверяете результат
```

## Пределы возможностей ИИ

Честно о границах — это важно, потому что слепое доверие ИИ — главная причина ошибок:

1. **Галлюцинации**: ИИ может уверенно придумать цифру или факт, которых нет. Всегда проверяйте числа по исходным данным.
2. **Устаревшие знания**: модель может не знать о свежих изменениях (новый курс валют, новая версия программы). Поэтому для актуальных данных используем живые источники: API, файлы, интернет.
3. **Сложность**: задачи с сотнями тонких условий ИИ решает хуже. Разбивайте их на шаги.
4. **Приватность**: нельзя отправлять в облачные чат-боты чужие персональные данные или коммерческие секреты. Для этого существуют локальные модели (отдельный курс-07) и режимы «без обучения на ваших данных».

## Практический минимум: как общаться с агентом

Формула хорошего задания агенту:

1. **Что есть** (вход): «у меня есть файл `sales.csv` с колонками дата, регион, сумма».
2. **Что сделать** (операция): «посчитай продажи по месяцам и регионам».
3. **Какой результат** (выход): «сохрани таблицу в Excel и нарисуй график по месяцам».
4. **Как проверить** (критерий): «сумма всех продаж должна совпасть с исходной таблицей».

Не бойтесь уточнять: «покажи первые 5 строк таблицы», «что ты сделал? объясни», «проверь, что итог равен сумме столбца».

## Задание на дом (обязательное к следующему занятию)

1. Найдите на компьютере любой файл с данными: таблицу Excel, CSV-выгрузку или PDF-отчёт (подойдёт даже счёт за телефон).
2. Откройте его обычным способом и посмотрите, что внутри.
3. Сформулируйте на русском языке 3 задачи, которые можно было бы решить с этими данными (посчитать, сгруппировать, нарисовать график, извлечь что-то из PDF).
4. Спросите у вашего ИИ-инструмента (ChatGPT/Claude/AI Studio): «Какие 3 задачи можно решить с такими данными? Что бы ты предложил первым делом?» — и сравните с вашим списком.
