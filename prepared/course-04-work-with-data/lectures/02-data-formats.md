# 02. Форматы данных: CSV, JSON, Excel

> Семестр: 1 · Курс: «Работа с данными» (course-04) · Время: ~2 часа

## Введение

Прежде чем поручать агенту обработку данных, полезно понимать, с каким форматом вы имеете дело. Формат определяет: как данные записаны, чем их можно открыть и какие операции с ними легче выполнить. Знание форматов — половина успеха: вы сможете точно объяснить агенту, что за файл у вас на руках.

## CSV — «простая таблица в тексте»

CSV (Comma-Separated Values) — таблица, записанная как обычный текст. Каждая строка — одна запись, значения разделены запятыми (или точкой с запятой, или табуляцией).

Пример файла `sales.csv`:

```csv
date,region,amount
2026-01-05,Москва,1500
2026-01-05,СПб,900
2026-01-12,Москва,2100
2026-01-19,Казань,600
```

Что важно знать:

- Открывается любым текстовым редактором, Excel, Google Sheets.
- Очень компактный, легко передаётся по почте и между системами.
- Стандарт «де-факто» для обмена данными между программами и сайтами.
- Не хранит форматирование, цвета, формулы — только «голые» данные.
- Первая строка часто содержит названия столбцов (заголовки).

**Разделитель** — частый источник проблем. В русской локали Excel часто использует «;» (потому что запятая занята десятичной точкой). Если агент неправильно прочитал CSV — первым делом проверьте разделитель.

## JSON — «структурированные данные для машин»

JSON (JavaScript Object Notation) — формат для данных со сложной структурой: вложенные объекты и списки. Выглядит так:

```json
{
  "city": "Москва",
  "temperature": -3,
  "forecast": [
    {"day": "2026-01-01", "temp": -3},
    {"day": "2026-01-02", "temp": -5}
  ]
}
```

Что важно знать:

- Основной формат веб-API: сайты возвращают данные в JSON.
- Поддерживает вложенность (объект внутри объекта, список внутри списка).
- Не очень удобен для чтения человеком, зато идеален для программ.
- Не хранит типы в явном виде строго: число, строка, список, объект.

Если вы видите ответ API вроде `{"temp": -3, "city": "Москва"}` — это JSON. Агент легко превратит его в таблицу.

## Excel (xlsx) — «таблица с форматированием»

Excel — формат рабочих таблиц Microsoft: листы, столбцы, формулы, цвета, диаграммы.

Что важно знать:

- Может содержать **несколько листов** (Sheet1, Sheet2...) — указывайте агенту, какой лист нужен.
- Может содержать **формулы** (например, `=СУММ(A1:A10)`) — при чтении через код важно, получаем ли мы значения или формулы.
- Хранит форматирование, стили, объединённые ячейки — это удобно человеку, но мешает машинной обработке.
- Часто является «точкой входа» в данных для офисных работников: бухгалтерия, продажи, логистика — всё в Excel.

## Другие форматы, которые могут встретиться

| Формат | Что это | Где встречается |
|---|---|---|
| TSV | Таблица с разделителем-табуляцией | Выгрузки из баз данных |
| XML | Старый структурированный формат | Наследие, документы |
| Parquet | Колоночный «бинарный» формат | Большие данные, машинное обучение |
| PDF | Документ (не данные!) | Отчёты, договоры — извлекать сложно |
| HTML | Веб-страницы | Скрейпинг сайтов |

Особый случай — **PDF**. Формально это не «данные», а готовая картинка-документ: страницы, текст, таблицы «запечатаны». Извлечение из PDF — отдельная тема (лекция 08), потому что PDF не хранит структуру таблицы как таблицу.

## Как определить формат файла

1. **Расширение**: `sales.csv`, `report.xlsx`, `data.json`.
2. **Содержимое** (открыть блокнотом):
   - `CSV` — строки с запятыми/точкой с запятой;
   - `JSON` — фигурные скобки и двоеточия;
   - `xlsx` — на самом деле это ZIP-архив: файл начинается с символов `PK`.
3. **Приложение**: Excel открывает xlsx/csv, блокнот — csv/json.

Если расширение не совпадает с содержимым — доверяйте содержимому. Расширение можно переименовать, формат — нет.

## Практика: дайте агенту понять формат

Хорошая формулировка задачи агенту всегда включает формат:

> «В файле `sales.csv` (разделитель — запятая) столбцы: дата, регион, сумма. Прочитай его и покажи первые 5 строк.»

Или:

> «В файле `data.json` список объектов с полями name и price. Преврати в таблицу CSV.»

## Задание на дом

1. Создайте в любом редакторе или Excel небольшой файл CSV (10 строк) про что угодно: ваши покупки, список дел, книги.
2. Откройте его блокнотом и посмотрите на сырой текст.
3. Скажите агенту: «Прочитай мой файл X, покажи первые 5 строк и названия столбцов». Проверьте, что он всё понял правильно.
4. Попросите агента создать такой же файл в формате JSON и покажите разницу.
