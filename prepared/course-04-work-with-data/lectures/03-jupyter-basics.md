## Введение

Чтобы агент мог запускать код и показывать результаты (таблицы, графики), нужна среда выполнения. Лучшая среда для этого — **Jupyter Notebook**: документ, который сочетает текст, код и результат работы кода прямо в одном файле.

Вам не нужно уметь программировать — но нужно понимать, как устроен ноутбук, потому что это ваше основное рабочее место на весь курс.

## Что такое Jupyter Notebook

Jupyter Notebook — это файл с расширением `.ipynb`, состоящий из **ячеек**. Есть два главных типа ячеек:

1. **Ячейка кода** — содержит Python-код. При запуске выполняется, а результат печатается под ячейкой.
2. **Ячейка Markdown** — содержит текст (в том числе формулы, заголовки, списки). Используется для пояснений.

Пример простого ноутбука:

```
[Markdown]  Заголовок: Анализ продаж за январь

[Код]       import pandas as pd
            df = pd.read_csv("sales.csv")
            df.head()

[Вывод]     date        region  amount
            2026-01-05  Москва  1500
            2026-01-05  СПб     900
            ...
```

Ключевое свойство ноутбука: код и результат хранятся вместе. Это значит, что:

- вы можете посмотреть, что именно делал агент (код) и что получилось (результат);
- вы можете перезапустить ячейки и увидеть, что ничего не сломается;
- ноутбук удобно отправлять преподавателю или коллеге — всё в одном файле.

## Как запустить Jupyter

Три распространённых способа:

1. **В браузере, без установки** — Google Colab (https://colab.research.google.com): открываете, загружаете ноутбук, работаете. Ничего устанавливать не нужно. Ограничения: нужен интернет, бесплатный аккаунт.
2. **Локально** — установить Python + JupyterLab: `pip install jupyterlab`, затем `jupyter lab`. Полный контроль, работает офлайн.
3. **Через агент** — многие агенты (Claude, Gemini CLI и др.) сами запускают Python и могут работать с ноутбуками. Вы описываете задачу, агент пишет код, выполняет, показывает результат.

Для курса рекомендуем начать с **Google Colab** — это самый простой путь, ничего устанавливать не надо.

## Ключевые навыки работы с ноутбуком

Даже не умея программировать, вы должны уметь:

- **Запускать ячейку**: кнопка ▶ или Shift+Enter.
- **Создавать ячейку кода**: кнопка «+ Code».
- **Создавать ячейку текста**: кнопка «+ Text» (Markdown).
- **Перезапускать всё**: меню Runtime → Restart session (в Colab). Полезно, когда что-то «зависло».
- **Сохранять файл**: Ctrl+S или автосохранение.
- **Скачивать ноутбук**: File → Download → .ipynb (для сдачи заданий).

## Ваше главное правило: «Сначала спроси, потом запускай»

Наш курс строится на том, что код пишет агент. Но ноутбук — это **ваша** территория: вы должны понимать, что в нём происходит, хотя бы на уровне «эта ячейка читает файл, эта считает, эта рисует график».

Полезные вопросы агенту по ходу работы:

- «Что делает эта ячейка? Объясни простыми словами.»
- «Покажи первые 5 строк таблицы.»
- «Проверь, что итоговая сумма совпадает с исходной.»
- «Добавь комментарий к каждой ячейке, что она делает.»

Комментарии (строки, начинающиеся с `#`) — ваш друг: просите агента подписывать ячейки, чтобы ноутбук был читаемым.

## Как выглядит хороший ноутбук-решение

Структура, к которой мы будем стремиться в заданиях:

1. **Заголовок** (Markdown): название задания, ФИО, дата.
2. **Постановка** (Markdown): задача словами.
3. **Загрузка данных** (код): чтение файла, показ первых строк.
4. **Обработка** (код): фильтрация, расчёты — с пояснениями в Markdown.
5. **Результат** (код): таблица-итог или график.
6. **Выводы** (Markdown): что получилось, какие цифры, что они означают.

Если ноутбук отвечает на вопрос «что делаем, что получили, какие выводы» — он хорош.

## Частые проблемы и решения

| Проблема | Решение |
|---|---|
| «NameError: name 'df' is not defined» | Нужно запустить ячейку, где df создаётся (запускать сверху вниз) |
| «ModuleNotFoundError» | Нужно установить библиотеку: в Colab — `!pip install имя` |
| Результат не обновился | Перезапустите ячейку или весь runtime |
| Файл не найден | Проверьте путь и имя файла; в Colab сначала загрузите файл |
| Ячейка «висит» долго | Прервать выполнение (кнопка stop), упростить задачу |
