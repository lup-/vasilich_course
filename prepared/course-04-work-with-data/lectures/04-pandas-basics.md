## Введение

**pandas** — главная Python-библиотека для работы с таблицами. Она умеет читать CSV, Excel, JSON, фильтровать строки, считать суммы и средние, сортировать, объединять таблицы. Именно её агент будет использовать в 90% задач этого курса.

Вам не нужно запоминать синтаксис — код пишет агент. Но вам нужно понимать **что означают основные операции**, чтобы проверять результат и давать агенту правильные команды.

## Главное понятие: DataFrame

**DataFrame** — это таблица с именованными столбцами. У неё есть:

- **столбцы** (колонки) с именами: `дата`, `регион`, `сумма`;
- **строки** (записи);
- **индекс** — номер строки (обычно 0, 1, 2...).

Работа с DataFrame — это ответы на вопросы:
- Какие здесь столбцы и что в них?
- Сколько строк?
- Отфильтровать те строки, которые подходят под условие.
- Посчитать сумму/среднее по столбцу.
- Сгруппировать по значению другого столбца.

## Чтение данных

Агент читает файл одной командой:

```python
import pandas as pd

df = pd.read_csv("sales.csv")        # CSV
df = pd.read_excel("sales.xlsx", sheet_name="2026")  # Excel, конкретный лист
df = pd.read_json("data.json")       # JSON
```

Самый первый шаг любой работы с данными — **посмотреть на таблицу**:

```python
df.head()        # первые 5 строк
df.tail()        # последние 5 строк
df.info()        # типы столбцов, количество непустых значений
df.describe()    # статистика по числовым столбцам: среднее, минимум, максимум
df.columns       # список названий столбцов
```

Почему это важно: до того как считать и строить графики, нужно убедиться, что данные загрузились правильно (правильный разделитель, правильные имена столбцов, нет мусора).

## Базовые операции

### Фильтрация — «оставь только нужные строки»

```python
# Только продажи в Москве
moscow = df[df["регион"] == "Москва"]

# Только суммы больше 1000
big = df[df["сумма"] > 1000]

# Несколько условий: Москва И сумма > 1000
moscow_big = df[(df["регион"] == "Москва") & (df["сумма"] > 1000)]
```

### Сортировка — «упорядочь»

```python
# По сумме по убыванию
df.sort_values("сумма", ascending=False)
```

### Расчёты — «посчитай»

```python
df["сумма"].sum()          # итоговая сумма
df["сумма"].mean()         # средняя сумма
df["сумма"].max()          # максимум
df["сумма"].count()        # сколько записей
```

### Новый столбец — «добавь вычисляемый»

```python
# 20% от суммы как «бонус»
df["бонус"] = df["сумма"] * 0.2

# Уже существующая колонка, изменили
df["сумма"] = df["сумма"].astype(float)  # перевести в числа
```

## Как формулировать задачу агенту

Плохо: «Обработай файл и покажи результат».

Хорошо:
> «Прочитай `sales.csv`. Покажи первые 5 строк и опиши столбцы. Затем:
> 1) оставь только продажи за январь;
> 2) посчитай сумму продаж по каждому региону;
> 3) отсортируй по убыванию суммы;
> 4) выведи итоговую таблицу. К каждой ячейке добавь короткий комментарий, что она делает.»

Этот «рецепт»: читаем → смотрим → фильтруем → считаем → выводим — основа всех ваших заданий.

## Проверка результата

Главное правило: **перепроверяйте итоги вторым способом**.

- Если агент посчитал сумму по регионам — проверьте, что сумма всех регионов равна общей сумме файла.
- Сравните с суммой через Excel (откройте тот же файл, выделите столбец, посмотрите «Автосумму»).
- Если цифры не сходятся — почти наверняка ошибка в данных (дубликаты, строки с мусором) или в условии фильтра. Спросите агента: «проверь, нет ли пропусков и дубликатов».

## Типичные ошибки и что они значат

| Сообщение | Что происходит | Что делать |
|---|---|---|
| `df["сумма"].sum()` даёт странное число | В столбце текст, а не числа (запятая вместо точки) | Попросить агента перевести в числа, заменить запятые на точки |
| Пустая таблица после фильтра | Условие не совпадает (опечатка в названии региона) | Показать уникальные значения: `df["регион"].unique()` |
| Дубликаты в итоге | В файле повторяются строки | `df.drop_duplicates()` |
| `NaN` | Пропущенные значения | Решить: заполнить, удалить или показать отдельно |
