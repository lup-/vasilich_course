## Группировка: «посчитай по группам»

Самая частая операция в реальной работе: «посчитай что-то по каждому региону / месяцу / менеджеру».

```python
# Сумма продаж по регионам
df.groupby("регион")["сумма"].sum()

# Средняя сумма по регионам
df.groupby("регион")["сумма"].mean()

# Несколько метрик сразу
df.groupby("регион")["сумма"].agg(["sum", "mean", "count", "max"])
```

Словами агенту:

> «Сгруппируй продажи по региону и покажи сумму, среднюю, количество и максимум. Отсортируй по сумме по убыванию.»

Группировка по двум колонкам — «по региону и по месяцу»:

```python
df.groupby(["регион", "месяц"])["сумма"].sum()
```

## Сводные таблицы: «Excel-сводная средствами кода»

Сводная таблица (pivot table) — это перекрутка: строки — одно измерение, столбцы — другое, ячейки — агрегат.

```python
# Регионы в строках, месяцы в столбцах, в ячейках — сумма
pd.pivot_table(df, values="сумма", index="регион", columns="месяц", aggfunc="sum")
```

## Объединение таблиц: «склей данные из разных файлов»

Частая ситуация: продажи в одном файле, справочник менеджеров — в другом. Их нужно соединить по общему ключу (например, по ID менеджера).

```python
sales = pd.read_csv("sales.csv")        # дата, регион, manager_id, сумма
managers = pd.read_csv("managers.csv")  # manager_id, имя, отдел

merged = sales.merge(managers, on="manager_id", how="left")
```

- `how="left"` — все строки из sales, а данные менеджеров — где нашлись;
- `how="inner"` — только строки, где ключ есть в обеих таблицах.

Словами агенту:

> «Соедини таблицу продаж со справочником менеджеров по столбцу manager_id. Для менеджеров, которых нет в справочнике, оставь пусто и покажи, сколько таких строк.»

## Даты: «работаем со временем»

Даты в таблицах обычно хранятся как текст. Чтобы считать по дням/месяцам, их превращают в специальный тип `datetime`.

```python
df["дата"] = pd.to_datetime(df["дата"])     # превратить текст в дату
df["месяц"] = df["дата"].dt.to_period("M")  # выделить месяц

# Продажи по месяцам
df.groupby(df["дата"].dt.to_period("M"))["сумма"].sum()

# Только за конкретный период
df[df["дата"] >= "2026-03-01"]
```

Типичные задачи с датами:
- «продажи по месяцам и кварталам»;
- «сколько дней прошло между заказом и оплатой»;
- «самый прибыльный день недели» (`df["дата"].dt.dayofweek`).

## Пропуски и дубликаты: «чистим данные»

Реальные данные почти всегда грязные: есть пустые ячейки (NaN), дубликаты, странные значения.

```python
df.isna().sum()              # сколько пропусков в каждом столбце
df = df.dropna()             # удалить строки с пропусками
df = df.fillna(0)            # заполнить пропуски нулями
df = df.drop_duplicates()    # удалить дубликаты

# Сколько и какие дубликаты
df.duplicated().sum()
```

**Решения о пропусках принимаете вы** (или спрашиваете агента о вариантах), потому что у каждой задачи своя логика: для суммы продаж пропуск — это 0, а для среднего возраста — уже нет.

## Как проверять сложные результаты

1. **Контрольная сумма**: сумма по группам должна равняться общей сумме.
2. **Количество строк**: сумма строк по группам = количество строк после фильтрации.
3. **Свежий взгляд**: пересчитайте одну группу вручную (или в Excel).
4. **Визуализация**: непонятные цифры легче увидеть на графике (лекция 06).
