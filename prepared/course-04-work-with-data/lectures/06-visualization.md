## Введение

Цифры в таблице — это сырьё. График — это понимание. Одного взгляда на диаграмму достаточно, чтобы увидеть тенденцию, выброс или проблему, которые в таблице ищутся долго.

В этом курсе мы используем две библиотеки:

- **matplotlib** — «классика»: статичные графики, простые и надёжные, для отчётов;
- **Plotly** — интерактивные графики: можно наводить курсор, зумить, фильтровать. Идеально для исследований.

Опять же: код пишет агент. Вы объясняете, что хотите увидеть, — агент рисует.

## Какие графики бывают и когда их использовать

| Тип | Что показывает | Когда использовать |
|---|---|---|
| Линейный график | Изменение во времени | Продажи по месяцам, курс, температура |
| Столбчатая диаграмма | Сравнение категорий | Продажи по регионам |
| Круговая диаграмма | Доли от целого | Структура расходов |
| Гистограмма | Распределение значений | Сколько заказов в каждом диапазоне сумм |
| Точечный график | Связь двух величин | Цена против количества |
| Ящик с усами (boxplot) | Разброс, выбросы | Сравнение зарплат по отделам |

Как просить агента:

> «Нарисуй линейный график: продажи по месяцам. По оси X — месяц, по оси Y — сумма. Подпиши оси и добавь заголовок.»

> «Построй столбчатую диаграмму продаж по регионам, отсортированную по убыванию.»

## matplotlib: базовый пример

```python
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("sales.csv")
monthly = df.groupby(df["дата"].dt.to_period("M"))["сумма"].sum()

plt.figure(figsize=(10, 5))
plt.plot(monthly.index.astype(str), monthly.values, marker="o")
plt.title("Продажи по месяцам")
plt.xlabel("Месяц")
plt.ylabel("Сумма, руб.")
plt.grid(True)
plt.show()
```

Ключевые настройки, которые стоит знать словами, чтобы требовать от агента:
- подписи осей и заголовок;
- размер рисунка (`figsize`) — чтобы не было мелко;
- сетка (`grid`) — легче читать;
- легенда, если несколько линий.

## Plotly: интерактивность

```python
import plotly.express as px

fig = px.line(monthly, title="Продажи по месяцам")
fig.update_layout(xaxis_title="Месяц", yaxis_title="Сумма, руб.")
fig.show()
```

Интерактивный график в ноутбуке можно двигать, зумить и смотреть точные значения по наведению. Для отчётов-исследований это очень удобно.

## Как «сказать» агенту, что рисовать

Полная формула хорошей просьбы о графике:

1. **Данные**: «у меня таблица sales.csv со столбцами дата, регион, сумма».
2. **Тип графика**: «построй столбчатую диаграмму».
3. **Оси**: «по X — регион, по Y — сумма».
4. **Агрегация**: «суммируй продажи по регионам».
5. **Оформление**: «подпиши оси, добавь заголовок, поверни подписи X, чтобы не налезали».
6. **Сохранение**: «сохрани в PNG-файл».

Хороший пример:

> «Из sales.csv сделай сводную продаж по регионам. Построй столбчатую диаграмму: регион по X, сумма по Y, отсортированную по убыванию. Добавь заголовок "Продажи по регионам, январь 2026" и подписи осей. Сохрани в sales_by_region.png.»

## Оформление: что отличает хороший график от плохого

- Читаемый размер (не меньше ~10×5);
- осмысленный заголовок, подписи осей с единицами;
- подписи по X, повёрнутые, чтобы не налезали;
- не больше 3–4 серий на одном графике (иначе каша);
- подписи значений на столбцах — если их немного;
- единый стиль в пределах отчёта.

## Типичные ошибки визуализации

| Проблема | Как исправить |
|---|---|
| График «плоский», ничего не видно | Выбрать другой масштаб, убрать выбросы, логарифмическую шкалу (попросить агента) |
| Подписи X налезают друг на друга | `plt.xticks(rotation=45)` |
| Круговая диаграмма с 20 секторами | Использовать столбчатую, а «прочие» объединить |
| Данные не совпадают с таблицей | Сверять график с контрольными суммами |
| График отображается, но PNG пустой | `plt.savefig(...)` вызывать перед `plt.show()`, или просить агента сохранять явно |
