## Введение

Многие полезные данные живут не в файлах, а в интернете: курсы валют, погода, котировки, данные о товарах. Чтобы забрать их автоматически, используются **веб-API** (Application Programming Interface) — специальные «двери» на сайтах, через которые программы получают данные.

Задача ИИ здесь идеальна: вы описываете, что хотите получить, агент пишет код запроса, забирает данные, превращает в таблицу и рисует график.

## Что такое API простыми словами

Сайт для браузера — это картинки и текст. Сайт для программы — это API: по адресу `https://api.example.com/data` программа получает структурированные данные в формате JSON.

Пример запроса:

```
https://api.example.com/weather?city=Москва
```

Ответ (JSON):

```json
{
  "city": "Москва",
  "temperature_c": -3,
  "humidity": 80
}
```

Ключевые понятия:

- **URL** — адрес запроса, часто с параметрами после `?` (`city=Москва`);
- **JSON** — формат ответа (см. лекцию 02);
- **API-ключ** — секретный код для некоторых API (регистрация обязательна). Без ключа работают многие публичные API.

## Как работает запрос в коде

```python
import requests
import pandas as pd

# Запрос к публичному API погоды (без ключа)
url = "https://api.open-meteo.com/v1/forecast"
params = {
    "latitude": 55.75,
    "longitude": 37.62,
    "hourly": "temperature_2m",
}
resp = requests.get(url, params=params)
data = resp.json()   # превращаем ответ в Python-структуру

# Из вложенного JSON делаем таблицу
temps = data["hourly"]["temperature_2m"]
times = data["hourly"]["time"]
df = pd.DataFrame({"время": times, "температура": temps})
df.head()
```

Ключевые шаги для понимания:

1. **Запрос**: `requests.get(url, params=...)`.
2. **Проверка статуса**: `resp.status_code` — 200 значит «успех».
3. **Разбор ответа**: `resp.json()`.
4. **Превращение в таблицу**: из словаря/списка делаем DataFrame.
5. **Анализ и график**: дальше как с любой таблицей.

## Статусы ответа: короткий справочник

| Код | Значение | Что делать |
|---|---|---|
| 200 | Успех | Продолжать |
| 400 | Неверный запрос | Проверить параметры URL |
| 401 / 403 | Нет прав / нужен ключ | Добавить ключ, проверить его |
| 404 | Нет такого ресурса | Проверить URL |
| 429 | Слишком много запросов | Подождать |
| 5xx | Проблема на сервере | Подождать, повторить |

Агент справляется с этим сам, но умение прочитать `resp.status_code` поможет объяснять проблемы.

## Типичные публичные API для практики (бесплатно, без ключа)

- **Погода**: Open-Meteo (https://open-meteo.com) — бесплатно, без ключа, хорошая документация.
- **Курсы валют**: open.er-api.com — бесплатно, без ключа.
- **Данные о странах**: restcountries.com — список стран, столиц, языков.
- **Цены на криптовалюты**: CoinGecko API — бесплатно.

В заданиях и на практике мы используем именно такие API: без регистрации и без ключей, чтобы ничего не тратить.

## Безопасность и этика

- **Не отправляйте API-ключи в открытом виде** (не вставляйте в код, который попадёт в общий чат/репозиторий). Ключ — это пароль.
- **Не злоупотребляйте**: у публичных API есть лимиты запросов. Не запускайте запросы в цикле по 10 000 раз.
- **Проверяйте данные**: API может вернуть ошибку или пустые значения — смотрите статус и содержимое.
- **Приватность**: не запрашивайте персональные данные людей без необходимости.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `HTTPError` / статус не 200 | Показать статус агенту, проверить URL и параметры |
| JSON «не похож на ожидаемое» | Изучить структуру: `data.keys()`, вложенность |
| Русские символы «крякозябры» | Правильная кодировка: `requests.get(url).text` / `.json()` корректно обрабатывает UTF-8 |
| Слишком большая таблица | Ограничить период, выбрать нужные поля |
| Агент не знает параметры API | Дать ему документацию (ссылку) |
