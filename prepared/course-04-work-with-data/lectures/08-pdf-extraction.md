## Введение

Огромная часть рабочих данных «заперта» в PDF: договоры, отчёты, счета, статьи, регламенты. PDF — это формат для печати и чтения, а не для обработки: он хранит страницы с текстом, а не структуру таблиц. Поэтому извлечение данных из PDF — отдельное ремесло, и здесь ИИ незаменим.

Главная библиотека курса — **PyMuPDF** (и её надстройка **PyMuPDF4LLM**, которая превращает PDF в Markdown — формат, понятный LLM).

## Почему с PDF так сложно

- PDF не хранит «таблицу» — он хранит координаты текста на странице. Глазами вы видите таблицу, а программа видит разрозненные куски текста.
- Текст может быть в картинках (скан) — тогда нужно распознавание символов (OCR).
- Разные счётчики и документы имеют разную структуру — универсального парсера нет, каждый документ приходится настраивать.
- Форматирование (переносы, шрифты, колонки) ломает простые методы извлечения.

Поэтому рабочий процесс с PDF — итеративный: извлекли → посмотрели → уточнили → извлекли лучше.

## Базовое извлечение текста

```python
import fitz  # PyMuPDF

doc = fitz.open("report.pdf")
for page_num in range(len(doc)):
    page = doc[page_num]
    text = page.get_text()
    print(f"--- Страница {page_num+1} ---")
    print(text)
```

Быстрый «пересказ» всего документа:

```python
full_text = "".join(page.get_text() for page in doc)
print(full_text[:2000])
```

## PyMuPDF4LLM: PDF → Markdown

Надстройка для «пищи» языковых моделей:

```python
import pymupdf4llm

md = pymupdf4llm.to_markdown("report.pdf")
print(md[:3000])
```

Markdown сохраняет структуру: заголовки, списки, таблицы в текстовом виде. Именно в таком виде удобно отдавать документ агенту для анализа: «прочитай этот контракт и ответь на вопросы».

## Извлечение таблиц

Таблицы в PDF — самое сложное. PyMuPDF умеет находить таблицы на странице:

```python
import pymupdf4llm

# to_markdown сохраняет таблицы как Markdown-таблицы
md = pymupdf4llm.to_markdown("invoice.pdf")
```

Альтернативный путь: `page.find_tables()` в PyMuPDF:

```python
page = doc[0]
tables = page.find_tables()
if tables.tables:
    df = tables[0].to_pandas()  # таблица → DataFrame
```

Универсальной надёжности нет: если документ со сложной вёрсткой, попросите агента:

> «Извлеки таблицу со страницы 2. Покажи, что получилось. Если данные "разъехались" — попробуй другой метод (find_tables / парсинг по координатам).»

## Текстовые PDF vs сканы (OCR)

| Тип | Как выглядит | Как извлечь |
|---|---|---|
| Текстовый PDF | Текст можно выделить мышью | `page.get_text()` — мгновенно и точно |
| Скан (картинка) | Текст не выделяется | Нужен OCR: распознать символы по картинке |

Для сканов в курсе используем OCR-инструменты (например, Tesseract через pytesseract или встроенные возможности). В Colab:

```

```

Распознавание русского текста — `lang="rus"`. OCR работает хуже на плохих сканах, но для типовых документов достаточно.

## Рабочий процесс с документом через агента

Лучший способ — делегировать анализ агенту:

1. **Дать документ**: прикрепить PDF к чат-боту или указать путь агенту.
2. **Дать задачу**: «извлеки текст и таблицу из счёта, покажи все строки, суммы и итог».
3. **Проверить**: сверьте извлечённые суммы с оригиналом.
4. **Уточнить**: «таблица расползлась — попробуй другой подход».

Пример запроса:

> «В файле invoice.pdf извлеки таблицу позиций (наименование, количество, цена, сумма). Сложи суммы и проверь, что итог совпадает с общей суммой в документе. Выведи таблицу pandas и поясни, что означает каждая строка.»

## Типичные задачи с PDF

- Извлечь реквизиты и позиции из счёта;
- Собрать цитаты/условия из договора;
- Сделать таблицу «счёт → статус оплаты» из папки PDF;
- Превратить научную статью в конспект;
- Собрать выдержки из регламента в единый файл.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Пустой текст при `get_text()` | Вероятно скан — использовать OCR |
| Таблица «разъехалась» | Попробовать `find_tables()` / другой метод |
| Русский текст сломан | Проверить кодировку, PDF сделан некорректно |
| Огромный PDF тормозит | Извлекать по страницам, ограничить диапазон |
| Нужны только некоторые страницы | Указать `doc[2:5]` (страницы 3–5) |
