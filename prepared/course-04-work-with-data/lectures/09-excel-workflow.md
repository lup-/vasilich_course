## Введение

Excel — самый распространённый формат рабочих таблиц: бухгалтерия, продажи, логистика, планирование — всё живёт в `.xlsx`. В этой лекции учимся полноценно работать с Excel через ИИ: читать, анализировать и **записывать** результаты обратно в Excel-файлы.

Это первая «офисная автоматизация» в нашем курсе: вы учитесь передавать рутинную работу с таблицами агенту. Сквозная тема курса.

## Чтение Excel

```python
import pandas as pd

# Все листы сразу
sheets = pd.read_excel("company.xlsx", sheet_name=None)

# Конкретный лист
df = pd.read_excel("company.xlsx", sheet_name="Продажи")

# Информация о листах
import openpyxl
wb = openpyxl.load_workbook("company.xlsx")
print(wb.sheetnames)  # список листов
```

Ключевые тонкости Excel, которые нужно знать, чтобы объяснять их агенту:

1. **Несколько листов** — всегда уточняйте, какой лист нужен. Или просите агента сначала показать список листов.
2. **Заголовки не на первой строке** — у реальных таблиц часто сверху «шапка» с названием компании и датой. Тогда:
   ```python
   df = pd.read_excel("company.xlsx", header=2)  # заголовки на 3-й строке
   ```
3. **Формулы и значения** — при чтении pandas по умолчанию берёт значения, а не формулы. Если важно, проверяйте.
4. **Числа с запятой** — в русской локали Excel может хранить «1234,56» как текст. Попросите агента заменить запятые и привести к числам.

## Запись в Excel

Записываем результаты анализа обратно в файл — это и есть «отчёт»:

```python
# Сохранить в новый файл
df.to_excel("report.xlsx", index=False)

# Несколько таблиц по листам
with pd.ExcelWriter("report.xlsx") as writer:
    df.to_excel(writer, sheet_name="Итоги", index=False)
    by_region.to_excel(writer, sheet_name="По регионам", index=False)
    pivot.to_excel(writer, sheet_name="Сводная", index=False)
```

После этого Excel-файл открывается обычным способом, и коллеги с ним работают как с любым другим.

## Форматирование итогового отчёта

Итоговый файл для людей стоит немного украсить — агент умеет это делать через openpyxl:

```python
from openpyxl.styles import Font

ws["A1"] = "Итоговый отчёт за январь"
ws["A1"].font = Font(bold=True, size=14)

# Ширина столбцов
ws.column_dimensions["A"].width = 15
```

Не обязательно разбираться в деталях — просто просите агента: «оформи заголовок жирным, подбери ширину столбцов, чтобы всё читалось».

## Типовой сценарий: «еженедельный отчёт»

Самый частый паттерн офисной автоматизации — регулярный отчёт из сырой выгрузки:

1. Выгрузка приходит (CSV/Excel) каждый понедельник;
2. Нужно: почистить → посчитать по группам → нарисовать графики → записать итоговый Excel → отослать.

Через агента это один «рецепт», который можно сохранить как ноутбук и перезапускать каждую неделю, просто заменив файл.

Хорошая формулировка:

> «Прочитай `weekly_export.xlsx` (лист "Данные", заголовки в первой строке). Очисти: убери дубликаты и строки с пустой суммой. Посчитай итоги по неделям и по менеджерам. Построй график динамики продаж. Запиши три листа в файл `report.xlsx`: "Итоги", "По менеджерам", "График". Оформи заголовки жирным.»

## Связка с n8n: автоматизация по расписанию

Когда такой отчёт нужно делать каждую неделю без участия человека, в игру вступает **n8n** — платформа автоматизации (low-code, есть бесплатный self-hosted вариант):

- n8n может забирать файл (из почты, папки), вызывать LLM/скрипты, собирать отчёт и отправлять по почте/в Telegram;
- графически собирается «поток»: триггер (раз в неделю) → обработка → LLM → результат;
- сложные куски (расчёты) всё равно делаются на Python внутри n8n.

В этом курсе n8n — продвинутая опция для тех, кто хочет довести автоматизацию до конца (см. лекцию 10 и курс-06 про агентов).

## Частые проблемы

| Проблема | Решение |
|---|---|
| Прочитался не тот лист | `wb.sheetnames` — показать список листов |
| Данные «съехали» из-за шапки | Указать `header=N` |
| Числа как текст | Попросить агента привести к числам (запятая → точка) |
| Файл не открывается после записи | Сохранять через pandas/openpyxl корректно; не открывать одновременно в Excel |
| Даты в Excel «сломаны» | Просить агента обработать через `pd.to_datetime` |
