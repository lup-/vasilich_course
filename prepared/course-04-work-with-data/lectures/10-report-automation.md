# 10. Автоматизация отчётов: агент собирает всё вместе

> Семестр: 1 · Курс: «Работа с данными» (course-04) · Время: ~3 часа

## Введение

Мы изучили отдельные операции: таблицы, графики, API, PDF, Excel. Теперь соединяем их в **полный конвейер** (пайплайн): от сырых данных до готового отчёта, который можно отправить. Это кульминация первой части курса — реальная офисная автоматизация, выполненная руками ИИ-агента.

В этой лекции вы пройдёте сквозной сценарий и поймёте, как строить такие сценарии самостоятельно.

## Сквозной сценарий

**Задача.** Компания ежемесячно готовит отчёт по продажам. Данные:

- `sales.csv` — продажи (дата, регион, менеджер, сумма);
- `managers.xlsx` — справочник менеджеров;
- `notes.pdf` — текстовые комментарии руководителя (важно включить в отчёт).

**Требуется:** итоговый документ с цифрами, графиками и комментариями.

## Шаг 1. Разложите задачу на шаги

Хороший конвейер всегда разбивается на этапы, которые проверяются по отдельности:

1. **Загрузка**: прочитать все источники (CSV, Excel, PDF).
2. **Очистка**: дубликаты, пропуски, типы.
3. **Расчёт**: итоги по месяцам и регионам, средний чек, топ менеджеров.
4. **Визуализация**: 2–3 графика.
5. **Сборка**: итоговый PDF (или Excel) с таблицами, графиками, выводами.

## Шаг 2. Дайте агенту задачу по частям

Сразу вся задача — риск запутаться. Лучше по шагам, проверяя каждый:

> **Шаг 1.** «Прочитай `sales.csv` и `managers.xlsx` (лист "Менеджеры"). Покажи первые 5 строк каждого. Проверь типы и пропуски.»

> **Шаг 2.** «Убери дубликаты. Объедини таблицы по manager_id. Преврати дату в datetime.»

> **Шаг 3.** «Посчитай: 1) продажи по месяцам; 2) продажи по регионам; 3) топ-5 менеджеров; 4) средний чек.»

> **Шаг 4.** «Построй три графика: динамика по месяцам, доля регионов (круговая), топ менеджеров (столбчатая). Подпиши оси.»

> **Шаг 5.** «Собери итоговый PDF: титул, таблицы, графики, выводы на основе цифр.»

## Шаг 3. Сборка PDF-отчёта

Самый простой способ собрать отчёт — попросить агента сгенерировать его через библиотеки отчётов (например, reportlab или fpdf, или сгенерировать HTML и перевести в PDF). Ещё проще — собрать отчёт в Markdown и превратить в PDF инструментом вроде pandoc. Агент сам подберёт инструмент, если вы скажете «собери PDF-отчёт».

Ключевое требование к отчёту — **проверяемость**: каждый вывод должен опираться на цифру. Поэтому в отчёте должны быть:

- контрольные суммы;
- источники (какие файлы использованы);
- дата формирования;
- подписи к таблицам и графикам.

## Шаг 4. Проверка и итерации

После первого прогона почти всегда нужно что-то поправить. Цикл:

1. **Проверьте цифры**: сходятся ли итоги с исходными данными?
2. **Проверьте текст выводов**: не придумал ли агент лишнего (галлюцинации)?
3. **Дайте уточнение**: «добавь сравнение с прошлым месяцем», «убери круговую, оставь столбчатую», «подпиши графики».
4. **Повторите** до удовлетворительного результата.

Типичные уточнения:

> «В выводах ты написал "рост на 15%" — проверь, откуда эта цифра. Пересчитай по данным.»

## Когда подключать n8n для регулярной автоматизации

Если отчёт повторяется каждую неделю/месяц, ручной прогон ноутбука надоедает. Тогда:

1. **Скрипт-ноутбук**: превращаем конвейер в один ноутбук, который принимает новый файл и выдаёт отчёт. Запуск одной командой.
2. **n8n**: собираем поток: триггер «по расписанию» → забираем файл → запускаем скрипт/LLM → отправляем результат по почте или в Telegram.
3. **Агент на расписании** (см. курс-06): агент сам следит за задачей и докладывает.

Для курса достаточно шага 1 + демонстрации n8n. Полное погружение в агентов — курс-06.

## Экономика автоматизации (сквозная тема)

Перед автоматизацией задайте вопрос: **стоит ли оно того?** Простой расчёт:

- Сколько времени занимает отчёт вручную? *(например, 3 часа в месяц)*
- Сколько времени занимает через агента? *(например, 20 минут)*
- Экономия: 2 ч 40 мин × 12 месяцев ≈ 32 часа в год.
- Стоимость часа работы × 32 = ценность автоматизации.

Если задача разовая — автоматизировать может быть дороже, чем сделать руками. Если повторяется — почти всегда выгодно. Оценка «сделать или автоматизировать» — ключевой навык, который мы тренируем в итоговом проекте (лекция 12).

## Чек-лист хорошего конвейера

- [ ] Каждый шаг проверяется отдельно;
- [ ] Есть контрольные суммы (итог совпадает);
- [ ] Выводы опираются на цифры, а не на воображение;
- [ ] Отчёт содержит источники и дату;
- [ ] Скрипт можно перезапустить с новым файлом без правок;
- [ ] Оценено: автоматизация стоит затраченных усилий.

## Задание на дом

2. Прогоните конвейер из шагов 2–3: очистка → расчёт → графики → PDF-отчёт.
3. Проверьте контрольные суммы и выводы.
4. Внесите одно уточнение от агента и перегенерируйте отчёт.
5. Посчитайте экономику: сколько бы заняла ручная работа, сколько — с агентом.
6. Сохраните ноутбук.
