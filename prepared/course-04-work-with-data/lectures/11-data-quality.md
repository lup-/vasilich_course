## Откуда берутся ошибки в данных

Ошибки бывают четырёх уровней:

1. **Ошибки источника**: опечатки при вводе, двойные строки, пропуски, старые данные.
2. **Ошибки обработки**: неверный фильтр, склеенные столбцы, путаница «;» и «,», неверная группировка.
3. **Ошибки интерпретации**: выводы, которые не следуют из цифр («корреляция ≠ причина»).
4. **Галлюцинации ИИ**: уверенные, но выдуманные цифры или факты.

Хороший аналитик предполагает, что **каждая цифра может быть неверна**, пока не проверил её.

## Галлюцинации ИИ: как с ними бороться

Самые опасные моменты, когда агент «сочиняет»:

- придумывает вывода, которого нет в данных;
- «вспоминает» значение, которое должно было быть посчитано;
- называет процент роста, не посчитав его;
- подставляет число из головы вместо вычисления.

Правила защиты:

1. **Требуйте расчётов в коде**: «покажи код, которым посчитан этот процент». Если цифра не появляется из данных — она подозрительна.
2. **Пересчитывайте второй способом**: Excel, вручную, другой метод.
3. **Сверяйте с источником**: «покажи, из какой строки взято это число».
4. **Спрашивайте напрямую**: «пересчитай, не сочиняй; если не знаешь — так и скажи».

Хороший запрос:

> «Посчитай рост продаж февраля к январю. Покажи код и исходные числа. Не выдумывай — если данные не позволяют посчитать, скажи об этом.»

## Базовая статистика: минимум для понимания

Чтобы проверять выводы, достаточно четырёх понятий:

1. **Среднее** (mean) — сумма ÷ количество. Обманчиво при выбросах.
2. **Медиана** — «середина»: половина значений больше, половина меньше. Устойчива к выбросам.
3. **Минимум и максимум** — границы разброса.
4. **Разброс/стандартное отклонение** — насколько значения «прыгают» вокруг среднего.

Пример, почему это важно:

- У 9 сотрудников зарплата 50 000 ₽, у директора — 5 000 000 ₽.
- Средняя = (9×50 000 + 5 000 000) ÷ 10 = **545 000 ₽**.
- Медиана = **50 000 ₽**.

Оба числа «верны», но рассказывают разную историю. Умение спросить «это среднее или медиана?» и «а есть ли выбросы?» — важнейший навык.

В pandas это:

```python
df["сумма"].mean()    # среднее
df["сумма"].median()  # медиана
df["сумма"].min()     # минимум
df["сумма"].max()     # максимум
df["сумма"].std()     # стандартное отклонение
df["сумма"].describe()  # всё сразу
```

## Ошибки выборки: откуда взяты данные

Ещё один источник обмана — **предвзятая выборка**:

- посчитали средний чек только по крупным заказам;
- проанализировали только один регион и выдали за «все»;
- сравнили январь с февралём без учёта сезонности;
- данные за 3 дня, а вывод — «за месяц».

Правило: **прежде чем выводить, спросите — что именно покрывают данные?** «Эти цифры за какой период? По всем регионам или одному?»

## Типовые ловушки в данных и как их замечать

| Ловушка | Признак | Что делать |
|---|---|---|
| Дубликаты | Итоги «раздуты» | `df.duplicated().sum()`, `drop_duplicates()` |
| Пропуски | NaN, странные средние | `df.isna().sum()`, решить: 0/удалить/отметить |
| Выбросы | Среднее сильно больше медианы | Показать boxplot, разобраться с выбросами |
| Путаница единиц | «5» вместо «5000» | Сверять с источником, спрашивать про единицы |
| Путаница разделителей | Числа-текст | Проверить `df.dtypes` |
| Корреляция ≠ причина | «Продажи растут, мороженое дорожает» | Не путать связь и причинность |
| Галлюцинация | Цифра «из воздуха» | Требовать код и исходные данные |

## Практика критической проверки

Каждый раз, получая результат от агента, проходите «чек-лист сомнения»:

1. **Источник**: откуда данные? За какой период? Полные ли они?
2. **Количество**: сходится ли число строк с ожидаемым?
3. **Контрольная сумма**: итог по группам = общий итог?
4. **Единицы**: рубли/тысячи, проценты/доли?
5. **Смысл**: похоже ли это на правду? Абсолютно новый рекорд — повод проверить.
6. **Второй способ**: пересчитать иначе (Excel, вручную, другая библиотека).
