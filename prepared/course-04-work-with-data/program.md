# Программа курса: Работа с данными с помощью ИИ (course-04)
> Оригинального курса нет — это авторский курс-модуль в двухсеместровой программе «Генеративный ИИ на практике». Язык: русский (RU). Курс практико-ориентированный: код пишется через LLM-агентов, а не вручную.

## О курсе
Курс учит студентов работать с данными: таблицами (Excel, CSV), JSON, PDF-документами и веб-API, используя современные ИИ-инструменты (чат-боты и агенты) как основной «рабочий инструмент». Программирование выполняется через LLM: студент описывает задачу на естественном языке, агент пишет и запускает код (pandas, matplotlib, Plotly, PyMuPDF, requests). Отдельного программирования не требуется — достаточно понимать, что происходит, и уметь проверять результат.

Курс построен вокруг сквозных тем программы: **офисная автоматизация** (Excel, отчёты, n8n) и **экономика/оценка** (стоимость и ценность применения ИИ).

## Цели обучения
После прохождения курса студент сможет:
- понимать основные форматы данных (CSV, JSON, Excel, PDF) и открывать их без специальных знаний;
- с помощью LLM/агента читать, фильтровать, сортировать и сводить таблицы (pandas);
- строить графики и интерактивные визуализации (matplotlib, Plotly);
- получать данные из публичных веб-API (requests, JSON, ключи API);
- извлекать текст и таблицы из PDF (PyMuPDF);
- собирать агентов для рутинных задач: отчёт из Excel + PDF + графики;
- проверять достоверность данных и не доверять выводам ИИ без проверки;
- оценивать экономику задачи: стоит ли автоматизировать, что это даст.

## Предварительные требования
- Базовое владение компьютером (файлы, папки, браузер);
- курс-01 и курс-02 (основы генеративного ИИ и промпт-инжиниринг);
- доступ к одному из ИИ-инструментов: ChatGPT/Claude/AI Studio/локальная модель (бесплатные тарифы достаточно);
- Python не требуется — код пишет LLM, студент проверяет результат.

## Структура курса: задания
Задания (в `assignments/`) — Jupyter-ноутбуки (`*.ipynb`) с готовым кодом для запуска и файлы-инструкции (`*.md`) с формулировкой задачи «как сказать агенту». Студент даёт задание агенту, агент пишет код, студент запускает и проверяет результат.

| № | Задание | Связь с лекцией |
|---|---|---|
| 01 | Знакомство с ноутбуком и первая таблица | 02–03 |
| 02 | pandas: чистка и анализ таблицы продаж | 04–05 |
| 03 | Графики и интерактивная визуализация | 06 |
| 04 | Данные из API: погода/валюта | 07 |
| 05 | Извлечение данных из PDF-документа | 08 |
| 06 | Итоговый проект: отчёт из данных (Excel + PDF + графики) | 10–12 |

## Как использовать подготовленную папку
- `program.md` — настоящая программа курса;
- `lectures/` — 12 лекций в Markdown (01–12), картинки не скопированы (вместо них — комментарии);
- `assignments/` — ноутбуки-задания и файлы-инструкции;
- `references/` — проверенные ссылки-источники.

## Продолжительность
Ориентировочно 12 занятий; каждое занятие рассчитано примерно на 2–3 часа (чтение + практика с агентом).
