# course-05-chemistry-ai
Авторский курс-модуль «Химия и ИИ: хемоинформатика» двухсеместровой программы «Генеративный ИИ на практике». Подготовлен как исходник для дальнейшей сборки общей программы.

## Источники
- Материал авторский, создан на основе проверенных публичных ресурсов (см. `references/`):
  - RDKit — библиотека хемоинформатики;
  - PubChem (NCBI) — база соединений и её REST API;
  - TeachOpenCADD — учебная платформа по CADD;
  - ChemCrow — ИИ-агент для химии.

## Структура
- `program.md` — программа курса
- `lectures/` — 12 лекций (.md)
- `assignments/` — задания: ноутбуки (.ipynb) + файлы-инструкции (.md)
- `references/` — список проверенных ссылок-источников

## Примечания
- Язык: русский (RU). Картинки и медиа не копируются (заменены комментариями).
- Аудитория: студенты с нулевым Python; код пишется через LLM-агентов, студент проверяет результат.
- Химические знания на школьном уровне желательны, но всё объясняется в лекциях.
- Сквозные темы программы: офисная автоматизация (отчёты по данным) и экономика/оценка применения ИИ.
