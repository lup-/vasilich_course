# Задание 01. Знакомство с молекулами: SMILES → RDKit

## Цель
Научиться переводить SMILES-строки в молекулы через RDKit, проверять их и рисовать. Понять разницу между обычным и каноническим SMILES.

## Что сделать
1. Откройте `assignment.ipynb` в Google Colab.
2. Выполните шаги 1–4 по порядку (Shift+Enter в каждой ячейке). При необходимости установите RDKit: `!pip install rdkit -q`.
3. Добавьте 2 своих SMILES (например, метан `C` и уксусную кислоту) и проверьте их.
4. Заполните ячейку «Мои выводы».
5. Скачайте ноутбук: File → Download → .ipynb.

## Ответьте на вопросы (запишите в ячейку «Мои выводы»)
1. Что такое SMILES?
2. Чем канонический SMILES отличается от обычного? Приведите пример пары строк, которые канонизируются в одну.
3. Что делает RDKit, если строка неверна?
4. Какой IUPAC-имя у этанола и какая у него формула (по RDKit)?
5. Какая трудность возникла (если возникла) и как вы её решили?

## Критерии приёма
- [ ] Ноутбук содержит все шаги с видимыми результатами (включая рисунки молекул).
- [ ] Добавлены минимум 2 собственных SMILES.
- [ ] Ячейка «Мои выводы» заполнена (5 ответов).
- [ ] Файл скачан в формате `.ipynb`.
