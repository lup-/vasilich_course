# Задание 02. Свойства молекул: расчёт и сравнение

## Цель
Считать дескрипторы (масса, logP, TPSA, доноры/акцепторы H-связей) через RDKit и сравнивать вещества между собой и с данными PubChem.

## Что сделать
1. Откройте `assignment.ipynb` в Google Colab и выполните шаги по порядку.
2. Проверьте массу аспирина: сравните расчёт RDKit с PubChem (180.16 г/моль).
3. Ответьте на вопросы из шага 3 (самое тяжёлое/лёгкое, гидрофильные/липофильные).
4. Заполните «Выводы» и скачайте ноутбук.

## Ответьте на вопросы (запишите в «Выводы»)
1. Какое вещество из набора самое тяжёлое, какое самое лёгкое?
2. Какие вещества гидрофильные (logP < 0), какие липофильные (logP > 0)? Что это означает?
3. Совпадает ли масса аспирина из RDKit с PubChem? С точностью до скольких знаков?
4. Почему logP важен при разработке лекарств?
5. Добавьте одно вещество по своему выбору в набор и посчитайте его свойства.

## Критерии приёма
- [ ] Таблица дескрипторов построена для всех 5 веществ + 1 добавленного.
- [ ] Проверка массы аспирина выполнена (результат в ноутбуке).
- [ ] Ячейка «Выводы» заполнена (5 ответов).
- [ ] Файл скачан в формате `.ipynb`.
