# Задание 04. Данные из PubChem через API

## Цель
Научиться получать свойства соединений из официальной базы PubChem через PUG REST API и проверять данные (в том числе ответы ИИ).

## Что сделать
1. Откройте `assignment.ipynb` в Google Colab и выполните шаги по порядку.
2. Добавьте в шаг 2 ещё 2 вещества по своему выбору.
3. В шаге 4 спросите у LLM-агента SMILES для кофеина (или другого вещества) и проверьте его через PubChem.
4. Заполните «Выводы» и скачайте ноутбук.

## Ответьте на вопросы (запишите в «Выводы»)
1. Что такое CID и InChIKey? Зачем они нужны?
2. Из каких частей состоит URL PUG REST API? Приведите пример.
3. Какой CID у аспирина?
4. Совпал ли SMILES агента с PubChem после канонизации? Если нет — что вы сделали?
5. Как вы можете убедиться, что данные «из PubChem», а не придуманы?

## Критерии приёма
- [ ] Таблица свойств по 5 веществам + 2 добавленным построена.
- [ ] Получены CID и InChIKey для аспирина.
- [ ] Выполнена проверка SMILES агента через PubChem (сравнение после канонизации).
- [ ] Ячейка «Выводы» заполнена (5 ответов).
- [ ] Файл скачан в формате `.ipynb`.
