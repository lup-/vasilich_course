# Задание 06. Итоговый проект: анализ набора молекул

## Цель
Применить все навыки курса в сквозном проекте: данные из PubChem → свойства RDKit → фильтры → ML → сходство → проверка качества → отчёт. Проект сдаётся «как научному руководителю».

## Что сделать
1. Откройте `project_template.ipynb` в Google Colab.
2. Возьмите список из 20 лекарственных веществ из лекции 12 (или составьте свой из ≥ 15 веществ).
3. Выполните по плану ноутбука: данные из PubChem, дескрипторы RDKit, проверка качества, Липински, ML, сходство, графики, экономика.
4. Заполните все разделы «Выводы», «Ограничения», «Проверка качества данных».
5. Сохраните итоговый ноутбук и скачайте его.

## Обязательные элементы
1. **Данные**: SMILES, CID, InChIKey, масса из PubChem для всех веществ.
2. **Свойства**: масса, logP, TPSA, доноры/акцепторы H-связей (RDKit).
3. **Проверка качества**: сравнение масс RDKit ↔ PubChem, дубликаты по InChIKey, отсутствие «выдуманных» чисел.
4. **Фильтры**: Липински и PAINS.
5. **ML**: пайплайн «дескрипторы → метка», оценка на тесте, ограничения описаны честно.
6. **Сходство**: 3 похожие на заданное вещество молекулы с объяснением.
7. **Графики**: минимум 3.
8. **Экономика**: оценка «вручную vs с агентом».
9. **Раздел «Проверка качества данных»**: что проверяли и что нашли.

## Ответьте в отчёте (раздел «Выводы»)
1. Сколько веществ прошло Липински? Какие не прошли и почему?
2. Насколько точна ваша ML-модель и почему её прогнозам нельзя полностью доверять?
3. Какое вещество в наборе самое похожее на ибупрофен? Какое значение Tanimoto?
4. Расходятся ли массы RDKit и PubChem? Насколько сильно?
5. Что бы вы сделали, если бы на вход пришло 10 000 веществ?

## Критерии приёма
- [ ] Все вещества из списка получены из PubChem (ошибки обработаны).
- [ ] Таблица свойств и фильтры построены и прокомментированы.
- [ ] ML-пайплайн выполнен с честной оценкой.
- [ ] Сходство найдено и объяснено.
- [ ] Раздел «Проверка качества данных» заполнен.
- [ ] Графики присутствуют и подписаны.
- [ ] Выводы и экономика заполнены.
- [ ] Итоговый ноутбук скачан в формате `.ipynb`.
