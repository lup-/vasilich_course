# Задания курса-05 «Химия и ИИ»

Каждое задание — папка с ноутбуком `assignment.ipynb` (или `project_template.ipynb`) и файлом-инструкцией `task.md`.

## Как сдавать
1. Выполните задание в Google Colab (https://colab.research.google.com).
2. Скачайте ноутбук: File → Download → .ipynb.
3. Заполните файл `task.md` (ответы на вопросы).
4. Сдайте оба файла (или ноутбук с выводами внутри).

## Список заданий
| № | Задание | Папка | Лекции |
|---|---|---|---|
| 01 | Знакомство с молекулами: SMILES → RDKit | `01-smiles-rdkit/` | 02–03 |
| 02 | Свойства молекул: расчёт и сравнение | `02-molecular-properties/` | 04 |
| 03 | Поиск похожих молекул | `03-similarity/` | 05 |
| 04 | Данные из PubChem через API | `04-pubchem-api/` | 06 |
| 05 | Фильтры лекарственноподобности | `05-drug-likeness/` | 07 |
| 06 | Итоговый проект: анализ набора молекул | `06-final-project/` | 10–12 |

## Важно
- Код пишется через LLM-агента, но вы отвечаете за проверку результатов (сверка с PubChem, здравый смысл).
- В ноутбуках есть ячейки `TODO` и пустые — заполняйте их или просите агента это сделать.
- Пункты «Выводы» обязательны: без них задание не засчитывается.
- RDKit ставится в Colab командой `!pip install rdkit -q`.
