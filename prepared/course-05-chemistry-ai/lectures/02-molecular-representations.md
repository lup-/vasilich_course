## Введение

Чтобы ИИ работал с молекулами, их нужно записать так, чтобы компьютер понимал. У химиков для этого есть несколько «языков». Самые важные — **SMILES**, **InChI** и **SDF**. Понимание этих форматов — фундамент всего курса: без него невозможно даже правильно сформулировать задачу агенту.

## SMILES: молекула одной строкой

SMILES (Simplified Molecular-Input Line-Entry System) — способ записать молекулу текстом. Правила достаточно простые:

- **Атомы** — символами элементов: `C` (углерод), `N` (азот), `O` (кислород), `Cl` (хлор — две буквы!).
- **Связи** — дефисом `-` (одинарная), `=` (двойная), `#` (тройная). Одинарную часто пропускают.
- **Кольца** — номером: `C1CCCCC1` — циклогексан: атом, у которого оба конца помечены `1`, замыкаются.
- **Ароматика** — строчными буквами: `c1ccccc1` — бензол (ароматическое кольцо).
- **Ветвления** — в скобках: `CC(C)O` — изопропанол (ветка в середине).
- **Заряды и изотопы** — специальными знаками: `[NH4+]` — ион аммония.

Примеры:

| Вещество | SMILES |
|---|---|
| Этанол | `CCO` |
| Аспирин | `CC(=O)OC1=CC=CC=C1C(=O)O` |
| Бензол | `c1ccccc1` |
| Парацетамол | `CC(=O)Nc1ccc(O)cc1` |

Главное свойство SMILES: **можно разобрать обратно**. Из строки компьютер строит молекулу — связи, кольца, атомы. Попросите агента «прочитать SMILES и нарисовать молекулу» — и он это сделает.

Важно: **одной молекуле может соответствовать несколько SMILES** (зависит от того, с какого атома начали). Компьютер умеет приводить их к единой «канонической» форме, чтобы сравнивать.

## InChI: универсальный «паспорт» молекулы

InChI (International Chemical Identifier) — ещё один текстовый формат, но устроен иначе: он строится по строгому алгоритму и однозначно идентифицирует молекулу. Выглядит устрашающе:

```
InChI=1S/C9H8O4/c1-6(10)13-8-5-3-2-4-7(8)9(11)12/h2-5H,1H3,(H,11,12)
```

Где применяется:
- **поиск**: две записи считаются одним веществом, если их InChI совпадают;
- **базы данных**: InChI используют как ключ (например, PubChem);
- **перекрёстная проверка**: InChI надёжнее, чем название или SMILES.

Не нужно уметь читать InChI — достаточно знать: это «паспорт» молекулы, по нему вещества находят и сопоставляют. Для людей удобнее SMILES, для машин — InChI.

## SDF: формат файлов с молекулами

SDF (Structure-Data File) — файловый формат для **наборов** молекул. Это не одна строка, а блоки:

- блок координат (как молекула расположена в пространстве);
- блок свойств (название, масса, любые ваши данные);
- разделитель между молекулами `$$$$`.

Выглядит примерно так (фрагмент):

```
     RDKit          2D

  4  4  0  0  0  0  0  0  0  0999 V2000
    1.0607    0.0000    0.0000 C
   ...
  1  2  1  0
M  END
$$$$
```

Где применяется:
- хранение **наборов** соединений (библиотек, баз, результатов скрининга);
- обмен данными между программами;
- совместное хранение структуры и свойств (например, «активные» и «неактивные» вещества с метками).

## Какие форматы когда использовать

| Формат | Что это | Когда использовать |
|---|---|---|
| SMILES | Строка-молекула | Быстрое описание, ввод/вывод в коде |
| InChI | «Паспорт» молекулы | Поиск, сверка в базах |
| SDF | Файл с набором молекул + свойства | Базы, библиотеки, скрининг |
| MOL | Один блок (как в SDF, но одна молекула) | Отдельные структуры |
| CXSMILES | SMILES с доп. данными (координаты, R-группы) | Современные пайплайны |

## Как агенту «показать» молекулу

Вы можете передать агенту молекулу любым из способов:

1. **Строка SMILES**: «вот SMILES аспирина `CC(=O)OC1=CC=CC=C1C(=O)O`, посчитай его массу».
2. **Название**: «найди аспирин в PubChem и дай его SMILES» (агент сам сделает запрос).
3. **Файл SDF**: «прочитай `library.sdf` и посчитай свойства всех молекул».
4. **Название вручную**: «построй молекулу воды».

Хорошая формулировка:

> «Прочитай эти SMILES: `CCO`, `CC(C)O`, `CCOC`. Для каждой построй молекулу и покажи: формулу, массу и количество атомов. Скажи, какие из этих молекул изомеры (одинаковый состав, разная структура).»

## Типичные ошибки при работе с SMILES

| Ошибка | Признак | Что делать |
|---|---|---|
| Неверный SMILES | RDKit возвращает «None» | Проверить строку, попросить агента исправить |
| Путаница регистра | `cl` вместо `Cl` (хлор) | Строчные — ароматика, прописные — элементы |
| Лишние/пропущенные скобки | Ошибка разбора | Попросить агента нормализовать |
| Агент «изобрёл» молекулу | Странная структура | Сверить с PubChem по InChI |
