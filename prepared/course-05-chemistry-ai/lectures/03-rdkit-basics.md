## Введение

**RDKit** — открытая библиотека для работы с молекулами, «рабочая лошадка» хемоинформатики. Она умеет:

- читать SMILES/SDF и строить молекулы;
- рисовать структурные формулы;
- считать свойства (масса, формула, кольца);
- искать подструктуры и похожие молекулы;
- готовить данные для машинного обучения.

Как и с pandas, вам не нужно запоминать синтаксис — код пишет агент. Но вы должны понимать ключевые операции, чтобы формулировать задачи и проверять результаты.

После установки — первая молекула:

```python
from rdkit import Chem
from rdkit.Chem import Draw

mol = Chem.MolFromSmiles("CCO")   # этанол
print(mol)
```

Если строка SMILES корректна — RDKit вернёт объект «молекула». Если нет — вернёт `None`. Это первый и главный признак ошибки.

## Чтение молекул

```python
from rdkit import Chem

# Из SMILES (одна молекула)
mol = Chem.MolFromSmiles("c1ccccc1")   # бензол

# Из файла SDF (много молекул)
supplier = Chem.SDMolSupplier("library.sdf")
mols = [m for m in supplier if m is not None]
```

Проверка на ошибки — обязательный шаг:

```python
bad = Chem.MolFromSmiles("CO(C)C")   # некорректная валентность
print(bad is None)                    # True — RDKit не смог построить
```

## Рисование молекул

```python
from rdkit.Chem import Draw

# Одна молекула → PNG
Draw.MolToFile(mol, "aspirin.png")

# Набор молекул → сетка-картинка
mols = [Chem.MolFromSmiles(s) for s in ["CCO", "c1ccccc1", "CC(=O)O"]]
img = Draw.MolsToGridImage(mols, molsPerRow=3, legends=["этанол", "бензол", "уксусная к-та"])
img
```

В ноутбуке картинка с молекулами отображается прямо под ячейкой. Для отчётов (Word, PDF) картинку сохраняют в PNG.

## Знакомство с молекулой: что внутри

```python
mol = Chem.MolFromSmiles("CC(=O)OC1=CC=CC=C1C(=O)O")   # аспирин

print(mol.GetNumAtoms())     # сколько атомов
print(mol.GetNumBonds())     # сколько связей
print(Chem.MolToSmiles(mol)) # канонический SMILES

# Атомы: символ и номер
for atom in mol.GetAtoms():
    print(atom.GetSymbol(), atom.GetAtomicNum())
```

Это базовые «показатели», которые стоит проверять: у аспирина 13 атомов. Если агент получил 100 — он что-то перепутал.

## Запись в файлы

```python
from rdkit import Chem

# Одна молекула в SDF
writer = Chem.SDWriter("one_mol.sdf")
writer.write(mol)
writer.close()

# Набор молекул
mols = [...]
writer = Chem.SDWriter("library.sdf")
for m in mols:
    writer.write(m)

```

Запись в SDF полезна, чтобы передать результат в другие программы или сохранить для отчёта.

## SMILES наоборот: из структуры в строку

```python
# Два разных написания одной молекулы
a = Chem.MolFromSmiles("C1=CC=CN=C1")
b = Chem.MolFromSmiles("n1ccccc1")

print(Chem.MolToSmiles(a))   # c1ccncc1
print(Chem.MolToSmiles(b))   # c1ccncc1  — одинаково!
```

**Канонический SMILES** — единый вид строки для одной молекулы. Благодаря ему можно сравнивать молекулы строково: `Chem.MolToSmiles(a) == Chem.MolToSmiles(b)`.

## Как формулировать задачу агенту

Хороший «рецепт»:

> «С помощью RDKit прочитай SMILES-список из файла `smiles.txt` (по одной на строку). Для каждой молекулы: 1) проверь, что она читается (нет None); 2) посчитай число атомов и связей; 3) приведи к каноническому SMILES. Покажи таблицу pandas с результатами. Для первых 3 молекул нарисуй структурные формулы в сетке. К каждой ячейке добавь комментарий, что она делает.»

## Частые проблемы

| Проблема | Решение |
|---|---|
| `MolFromSmiles` возвращает `None` | SMILES некорректен; попросить агента исправить или взять из PubChem |
| Картинка молекулы «пустая» | Для рисования иногда нужно добавить 2D-координаты: `AllChem.Compute2DCoords(mol)` |
| Слишком много молекул в сетке | Разбить на части, `molsPerRow` увеличить |
| Русские подписи на рисунке «кракозябры» | Использовать legends с корректной кодировкой или английские подписи |
| Набор молекул, но «None» в списке | Проверить SDF, отфильтровать: `[m for m in mols if m is not None]` |
