## Введение

Молекула — это не только структура, но и **числа**: молекулярная масса, брутто-формула, количество «правил» для лекарств, показатели растворимости. Эти числа называются **свойствами** и **дескрипторами**. Они нужны, чтобы сравнивать вещества, отбирать кандидаты и готовить данные для машинного обучения.

RDKit считает многие свойства автоматически. Ваша задача — уметь просить их, понимать, что они значат, и проверять правдоподобность.

## Базовые свойства из коробки

```python
from rdkit import Chem
from rdkit.Chem import Descriptors, rdMolDescriptors

mol = Chem.MolFromSmiles("CC(=O)OC1=CC=CC=C1C(=O)O")   # аспирин

Descriptors.MolWt(mol)                    # молекулярная масса (~180)
Descriptors.NumHDonors(mol)               # доноры водорода
Descriptors.NumHAcceptors(mol)            # акцепторы водорода
Descriptors.MolLogP(mol)                  # липофильность (logP)
rdMolDescriptors.CalcMolFormula(mol)      # брутто-формула C9H8O4
```

Самое полезное — показать всё сразу:

```python
import pandas as pd

props = {
    "SMILES": Chem.MolToSmiles(mol),
    "Масса": Descriptors.MolWt(mol),
    "Формула": rdMolDescriptors.CalcMolFormula(mol),
    "logP": Descriptors.MolLogP(mol),
    "Доноры H": Descriptors.NumHDonors(mol),
    "Акцепторы H": Descriptors.NumHAcceptors(mol),
    "Кольца": rdMolDescriptors.CalcNumRings(mol),
}
df = pd.DataFrame([props])
df
```

## Как читать главные свойства

| Свойство | Что значит | Бытовой смысл |
|---|---|---|
| **Масса (MolWt)** | Молекулярная масса, г/моль | У аспирина ~180, у сахара ~342 |
| **Брутто-формула** | Количество атомов каждого элемента | C9H8O4 — 9 углеродов, 8 водородов, 4 кислорода |
| **logP** | Липофильность (в жир или воду?) | Высокий logP → вещество жирорастворимое |
| **Доноры/акцепторы H** | Умение отдавать/принимать водородные связи | Важно для лекарств |
| **Число колец** | Сколько колец в структуре | Ароматика, жёсткость |
| **Заряд** | Формальный заряд молекулы | Ионы vs нейтральные |

«Проверка здравым смыслом»: если масса аспирина получилась 18 000 — явно ошибка. Масса типичного лекарства — от 100 до 500.

## Свойства для нескольких молекул сразу

Чаще всего свойства считают для **набора** молекул (библиотеки). Тогда строят таблицу:

```python
smiles_list = ["CCO", "c1ccccc1", "CC(=O)O", "CC(=O)OC1=CC=CC=C1C(=O)O"]

rows = []
for smi in smiles_list:
    m = Chem.MolFromSmiles(smi)
    if m is None:
        continue
    rows.append({
        "SMILES": smi,
        "Масса": Descriptors.MolWt(m),
        "Формула": rdMolDescriptors.CalcMolFormula(m),
        "logP": Descriptors.MolLogP(m),
        "Кольца": rdMolDescriptors.CalcNumRings(m),
    })

df = pd.DataFrame(rows)
df
```

Дальше таблицу можно сортировать, фильтровать и сравнивать — как в курсе-04.

## Все дескрипторы сразу

RDKit умеет считать **сотни** дескрипторов разом:

```python
from rdkit.ML.Descriptors import MoleculeDescriptors

calculator = MoleculeDescriptors.MolecularDescriptorCalculator([d for d in Descriptors._descList])
names = calculator.GetDescriptorNames()
values = calculator.CalcDescriptors(mol)

props = dict(zip(names, values))
df = pd.DataFrame([props]).T
df
```

Не нужно разбираться в каждом — агент выберет нужные по вашей задаче. Но знайте: такие таблицы дескрипторов — стандартный вход для машинного обучения (лекция 08).

## Как формулировать задачу агенту

> «Возьми файл `molecules.sdf`. Для каждой молекулы посчитай: массу, брутто-формулу, logP, доноры/акцепторы водорода, число колец. Составь таблицу pandas. Отсортируй по массе. Покажи 3 самых тяжёлых и 3 самых лёгких. Для каждой молекулы добавь канонический SMILES.»

Или с фильтром:

> «В этой таблице оставь только молекулы с массой от 150 до 350 и logP не выше 5. Объясни, сколько молекул прошло фильтр.»

## Частые проблемы

| Проблема | Решение |
|---|---|
| Масса «как будто не та» | Проверить, не текст ли вместо числа; сверять с PubChem |
| Формула с водородом «не сходится» | RDKit считает «явные» атомы; проверять `Chem.RemoveHs` |
| `None` среди молекул | Отфильтровать нечитаемые SMILES |
| Агент не знает, какой дескриптор нужен | Описать словами, что важно (растворимость, размер, заряд) |
| Огромная таблица дескрипторов | Выбрать 5–10 нужных, остальное скрыть |
