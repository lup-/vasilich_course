## Введение

Один из самых частых вопросов химика: **«похожи ли эти две молекулы?»** Похожие молекулы часто обладают похожими свойствами — поэтому поиск «похожего» лежит в основе поиска лекарств, дизайна веществ и анализа баз.

Как измерить сходство молекул, чтобы компьютер мог его считать? Через **фингерпринты** (отпечатки) и меру **Tanimoto**. Разбираем, что это и как этим пользоваться через агента.

## Фингерпринт: молекула как набор «да/нет»

Фингерпринт — это строка из 0 и 1 (битов), где каждый бит означает «есть ли в молекуле определённый фрагмент/признак». Молекула превращается в фиксированный набор признаков:

```
молекула А: 1 0 1 1 0 0 1 0 1 ...
молекула Б: 1 0 1 0 0 0 1 0 1 ...
```

Две молекулы с похожим фингерпринтом — похожие молекулы.

Основные виды фингерпринтов в RDKit:

- **Morgan fingerprint** (отпечаток, основанный на окружении атомов) — самый популярный в современных задачах;
- **MACCS keys** — классические 166 признаков из хемоинформатики;
- **RDKit fingerprint** — встроенный вариант.

В коде:

```python
from rdkit import Chem
from rdkit.Chem import rdFingerprintGenerator

gen = rdFingerprintGenerator.GetMorganGenerator(radius=2)
fp1 = gen.GetFingerprint(mol1)
fp2 = gen.GetFingerprint(mol2)
```

## Коэффициент Танимото: мера сходства

Фингерпринт сам по себе — не число. Число даёт **коэффициент Танимото** (Tanimoto): доля общих признаков относительно объединения:

```
Tanimoto = (число общих битов) / (всего битов у обеих молекул)
```

- T = 1.0 — молекулы идентичны (по отпечатку);
- T = 0.0 — ничего общего;
- T ≥ 0.7 — обычно считают «похожими» (эмпирический порог).

```python
from rdkit import DataStructs

similarity = DataStructs.TanimotoSimilarity(fp1, fp2)
print(similarity)   # 0.0 .. 1.0
```

Полезно сравнивать пары: аспирин vs ибупрофен, этанол vs метанол, этанол vs бензол. Интуиция подскажет, что «похожее» — и вы увидите, как ведут себя числа.

## Поиск похожих в наборе

Практическая задача: «дана библиотека молекул, найди 5 самых похожих на вещество X».

```python
from rdkit import Chem
from rdkit import DataStructs
from rdkit.Chem import rdFingerprintGenerator

gen = rdFingerprintGenerator.GetMorganGenerator(radius=2)

query = Chem.MolFromSmiles("CC(C)Cc1ccc(cc1)C(C)C(=O)O")   # ибупрофен
library = [Chem.MolFromSmiles(s) for s in smiles_list]

query_fp = gen.GetFingerprint(query)
scores = []
for m in library:
    if m is not None:
        scores.append(DataStructs.TanimotoSimilarity(query_fp, gen.GetFingerprint(m)))
    else:
        scores.append(0.0)

# Топ-5 по сходству
import pandas as pd
df = pd.DataFrame({"SMILES": [Chem.MolToSmiles(m) for m in library if m is not None],
                   "Tanimoto": [s for s in scores if s > 0 or len([x for x in scores if x<=0])>0]})
df = df.sort_values("Tanimoto", ascending=False)
df.head(5)
```

Попроще формулировка для агента:

> «Найди 5 молекул из библиотеки, наиболее похожих на ибупрофен (SMILES: `CC(C)Cc1ccc(cc1)C(C)C(=O)O`). Используй Morgan-фингерпринт (radius 2) и коэффициент Танимото. Покажи таблицу с Tanimoto и нарисуй топ-5 структур.»

## Что такое «похожесть» на самом деле

Важно: «похожесть» здесь — **математическая**, по фингерпринту. Она не всегда совпадает с интуицией химика:

- две молекулы с похожим отпечатком обычно имеют похожий **скелет**;
- но «похожесть» не гарантирует похожих свойств (токсичность, растворимость);
- выбор фингерпринта влияет на результат — Morgan более «современный», MACCS более «жёсткий».

Поэтому результат поиска нужно проверять глазами: посмотреть на структуры, убедиться, что они «похожи» разумным образом.

## Применения

- **Поиск в базах**: «найди всё, что похоже на моё вещество» (виртуальный скрининг);
- **Кластеризация**: группировка библиотеки на похожие кластеры;
- **Удаление дубликатов**: молекулы с Tanimoto = 1.0 — по сути одно и то же;
- **Сериализация**: отбор серии аналогов с изменёнными фрагментами.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Все сходства = 1.0 | Фингерпринт посчитан для одной молекулы (перепутан query); проверить индексы |
| Все сходства = 0.0 | Молекулы не читаются (None) или разные пространства признаков |
| «Похожее» не совпадает с интуицией | Уточнить тип фингерпринта, порог |
| Таблица пустая | Отфильтровать None, проверить список |
