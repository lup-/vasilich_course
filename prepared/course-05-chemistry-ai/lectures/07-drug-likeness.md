## Введение

Не всякая молекула может стать лекарством: ей нужно всасываться, распределяться, не быть токсичной. Фармацевты используют **фильтры «лекарственноподобности»** — простые правила, которые отсекают заведомо неподходящие кандидаты. Самое известное — **правило Липински** (Lipinski's Rule of Five).

В этой лекции научимся применять эти фильтры к наборам молекул через RDKit и понимать, о чём они говорят. Примеры и готовые ноутбуки — из платформы **TeachOpenCADD**.

## Правило Липински (Rule of Five)

Лекарство «для приёма внутрь» с хорошей всасываемостью с высокой вероятностью удовлетворяет 4 условиям:

| Правило | Критерий |
|---|---|
| Масса | ≤ 500 г/моль |
| logP (липофильность) | ≤ 5 |
| Доноры H-связей | ≤ 5 |
| Акцепторы H-связей | ≤ 10 |

«Пять» — потому что все пороги кратны 5. Правило **эмпирическое**: не жёсткий закон, а быстрый отсев. Многие хорошие лекарства его нарушают, но как фильтр первой линии оно работает.

## Фильтр «5 правил» в RDKit

```python
from rdkit import Chem
from rdkit.Chem import Descriptors, rdMolDescriptors

def lipinski_pass(mol):
    if mol is None:
        return False
    mw = Descriptors.MolWt(mol)
    logp = Descriptors.MolLogP(mol)
    donors = Descriptors.NumHDonors(mol)
    acceptors = Descriptors.NumHAcceptors(mol)
    return (mw <= 500 and logp <= 5 and donors <= 5 and acceptors <= 10)

mols = [Chem.MolFromSmiles(s) for s in smiles_list]
for m in mols:
    print(Chem.MolToSmiles(m), "→ проходит:", lipinski_pass(m))
```

Этот код можно дать агенту словами:

> «Проверь для каждой молекулы правило Липински: масса ≤ 500, logP ≤ 5, доноры H ≤ 5, акцепторы H ≤ 10. Добавь в таблицу колонку “проходит” и посчитай, сколько молекул прошло.»

## Таблица-фильтр: отчёт по набору

```python
import pandas as pd
from rdkit import Chem
from rdkit.Chem import Descriptors, rdMolDescriptors

rows = []
for smi in smiles_list:
    m = Chem.MolFromSmiles(smi)
    if m is None:
        continue
    rows.append({
        "SMILES": smi,
        "Масса": Descriptors.MolWt(m),
        "logP": Descriptors.MolLogP(m),
        "Доноры": Descriptors.NumHDonors(m),
        "Акцепторы": Descriptors.NumHAcceptors(m),
        "Проходит Липински": lipinski_pass(m),
    })

df = pd.DataFrame(rows)
passed = df[df["Проходит Липински"]]
print(f"Прошло {len(passed)} из {len(df)}")
df
```

## Другие фильтры и понятия ADME

**ADME** — аббревиатура: **A**bsorption (всасывание), **D**istribution (распределение), **M**etabolism (метаболизм), **E**xcretion (выведение). Фильтры оценивают эти процессы грубо:

- **Лекарственноподобность** (drug-likeness): правило Липински и подобные.
- **Ведущий-подобность** (lead-likeness): более строгие пороги для начальных кандидатов.
- **Нежелательные подструктуры** (PAINS, Brenk): «красные флаги» — фрагменты, часто дающие ложные результаты в тестах.
- **Число «правил» в VEber**: полярная площадь поверхности (TPSA), количество вращающихся связей.

RDKit считает всё это:

```python
from rdkit.Chem import Descriptors, rdMolDescriptors

mol = Chem.MolFromSmiles("CC(=O)OC1=CC=CC=C1C(=O)O")
Descriptors.TPSA(mol)                              # полярная площадь
rdMolDescriptors.CalcNumRotatableBonds(mol)        # вращающиеся связи
rdMolDescriptors.CalcNumAromaticRings(mol)         # ароматические кольца
```

## PAINS и подструктуры-«красные флаги»

PAINS — наборы подструктур, которые часто «мешают» в высокопроизводительном скрининге (ложные срабатывания). RDKit умеет проверять:

```python
from rdkit.Chem import FilterCatalog

catalog = FilterCatalog.FilterCatalog(FilterCatalog.FilterCatalogParams.FilterCatalogs.PAINS)

for m in mols:
    match = catalog.GetFirstMatch(m)
    if match:
        print("PAINS-предупреждение:", Chem.MolToSmiles(m), "→", match.GetDescription())
```

Если ваш кандидат содержит PAINS-фрагмент — это повод внимательно проверить результаты экспериментов.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Все «проходят» — подозрительно | Проверить, что свойства посчитаны, а не придуманы; показать таблицу |
| Никто не проходит | Пороги могут быть завышены для вашей задачи; обсудить с агентом |
| PAINS не находится | Убедиться, что используется FilterCatalog правильно |
| Масса дробная «странная» | Это нормально (средние атомные массы); сверять с PubChem |
