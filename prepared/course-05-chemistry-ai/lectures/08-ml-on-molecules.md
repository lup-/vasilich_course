## Введение

Хемоинформатика не только считает свойства «по формулам» — она **предсказывает** их с помощью машинного обучения (ML): по множеству известных примеров модель учится оценивать свойства новых молекул. Растворимость, токсичность, активность против белка — всё это сегодня предсказывают модели.

Вам не нужно строить модели с нуля. Нужно понимать идею, уметь использовать готовые решения через агента и критически относиться к прогнозам.

## Идея машинного обучения на молекулах

Классический ML-пайплайн:

1. **Собрать данные**: набор молекул + известные свойства (например, растворимость для 1000 веществ).
2. **Превратить молекулы в числа**: фингерпринты или дескрипторы (лекции 04–05) — это «признаки» (features).
3. **Обучить модель**: алгоритм ищет закономерность «признаки → свойство».
4. **Предсказать**: для новой молекулы посчитать признаки и получить оценку свойства.

```
данные (молекулы + свойства)
   → признаки (фингерпринты)
   → модель (обучение)
   → предсказание для новых молекул
```

Проще говоря: **как в таблице предсказать пустую ячейку по похожим строкам**, только строки — это молекулы, а «похожесть» — фингерпринты.

## Строим простую модель (пример)

Самый простой и наглядный пример — классификация «растворимо / нерастворимо в воде» по дескрипторам. Полный код пишет агент, но схема такая:

```python
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from rdkit import Chem
from rdkit.Chem import Descriptors
from rdkit.ML.Descriptors import MoleculeDescriptors

# 1. Данные: молекулы + метки (0/1)
# df = pd.read_csv("molecules.csv")   # колонки: SMILES, soluble

# 2. Признаки: дескрипторы для каждой молекулы
calculator = MoleculeDescriptors.MolecularDescriptorCalculator(
    ["MolWt", "MolLogP", "TPSA", "NumHDonors", "NumHAcceptors"])
X = df["SMILES"].apply(lambda s: calculator.CalcDescriptors(Chem.MolFromSmiles(s)))
y = df["soluble"]

# 3. Модель
model = RandomForestClassifier(n_estimators=200, random_state=42)
model.fit(X, y)

# 4. Предсказание для новой молекулы
new_fp = calculator.CalcDescriptors(Chem.MolFromSmiles("CCO"))
prediction = model.predict([new_fp])
```

## Почему это работает и где ломается

ML работает, потому что похожие молекулы обычно ведут себя похоже. Но есть подводные камни:

1. **Данные важнее модели**: модель на 100 молекул хуже, чем на 10 000. Ошибки в данных → ошибки в прогнозах.
2. **Утечка данных**: если в тест попали молекулы из обучения — точность «завышена». Проверяйте, что обучающая и тестовая выборки разделены правильно.
3. **За пределами данных**: модель предсказывает только в «области», где были примеры. Нельзя предсказать растворимость экзотического полимера моделью, обученной на простых органических молекулах.
4. **Прогноз ≠ факт**: предсказанное свойство — это оценка с погрешностью, а не измерение.

## Честная оценка прогнозов: «насколько можно верить»

Чек-лист при работе с прогнозом:

- [ ] Модель обучена на данных, похожих на нашу молекулу?
- [ ] Есть ли метрики качества (точность, ROC-AUC) и какие они?
- [ ] Данные в обучающей выборке — из проверенного источника?
- [ ] Прогноз проверен хоть на одном «эталонном» веществе?

Правило: **предсказание — гипотеза, а не факт**. Для решений (выбор лекарства, производство) прогноз всегда подтверждают экспериментом.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Точность 100% — подозрительно | Вероятно утечка данных (одинаковые молекулы в train и test) |
| Ошибка при расчёте дескрипторов | Проверить, что молекулы читаются (None фильтруются) |
| sklearn не установлен | `!pip install scikit-learn -q` |
| Плохая точность | Больше данных, другие признаки, проще задача |
| Прогноз «нереальный» | Проверить область применимости модели |
