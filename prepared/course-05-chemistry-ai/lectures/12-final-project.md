# 12. Итоговый проект: «Анализ набора соединений»

> Семестр: 2 · Курс: «Химия и ИИ» (course-05) · Время: ~6–8 часов

## Введение

Итоговый проект объединяет все навыки курса: работа с данными (курс-04), работа с молекулами в RDKit, использование PubChem, ML-модель, проверку качества данных и автоматизацию. Вы анализируете набор из известных лекарственных соединений и готовите отчёт «как для научного руководителя».

## Задание

Вы — химик-аналитик. Заказчик дал список из 20 известных лекарственных веществ (аспирин, ибупрофен, парацетамол, кофеин, амоксициллин, метформин, аторвастатин, омепразол, кодеин, теофиллин, варфарин, левотироксин, диазепам, сальбутамол, целекоксиб, метопролол, эналаприл, дигоксин, сиролимус, ривароксабан) и просит:

1. Собрать для каждого вещества: канонический SMILES, CID, InChIKey — из PubChem.
2. Построить таблицу свойств (RDKit): масса, logP, TPSA, доноры/акцепторы H-связей, число вращающихся связей, число колец.
3. Проверить правило Липински и PAINS-фильтры для каждого вещества.
4. Обучить модель: по свойствам (признаки) предсказать категорию «соответствует Липински» (да/нет). Оценить качество модели.
5. Найти 3 вещества из списка, похожие на заданное (например, на ибупрофен) по фингерпринтам, и объяснить, почему они похожи.
6. Сделать отчёт: таблицы, 2–3 графика, выводы. Пометить, где значения расчётные, а где фактические (из PubChem).
7. Проверить данные: все ли SMILES читаются, нет ли дубликатов, нет ли «выдуманных» чисел. Описать, какие проверки выполнялись.

## План выполнения (рекомендуемый)

**Шаг 1. Соберите данные (2 часа).**
- Через PubChem API получите SMILES, CID, InChIKey, массу для всех 20 веществ.
- Сохраните в CSV. Проверьте: для каждого вещества запрос отработал успешно.

**Шаг 2. Расчёт свойств и фильтры (1 час).**
- Посчитайте дескрипторы RDKit для каждого вещества.
- Добавьте колонки «проходит Липински» и «есть PAINS».
- Сравните массы из RDKit и из PubChem — они должны совпадать (проверка качества, лекция 10).

**Шаг 3. Модель (1 час).**
- Признаки: 5–6 дескрипторов. Цель: «проходит Липински» (0/1).
- Разделите на обучение/тест, обучите RandomForest, покажите метрики и важность признаков.
- Честно оцените: на 20 веществах модель слабая — так и напишите в отчёте. Важнее само понимание пайплайна.

**Шаг 4. Сходство (1 час).**
- Для заданной молекулы (например, ибупрофен) найдите 3 наиболее похожих по Танимото (лекция 05).
- Покажите таблицу сходства и объясните «почему похожи» структурно.

**Шаг 5. Отчёт (2 часа).**
- Jupyter Notebook с анализом + отдельный markdown-отчёт или PDF-выгрузка.
- Графики: гистограмма масс, распределение logP, столбчатая диаграмма «прошло/не прошло».
- Выводы: какие вещества проходят фильтры, какие нет и почему; ограничения прогнозов.
- Раздел «Проверка качества данных»: что проверяли и что нашли.

## Как работать с агентом

Делите проект на шаги и проверяйте после каждого. Пример задания:

> «Шаг 1. Для списка из 20 названий получи из PubChem SMILES, CID, InChIKey и массу. Сохрани CSV. Если для какого-то названия ошибка — выведи это вещество отдельно и продолжай. Покажи итоговую таблицу.»

На финальном этапе — комплексное задание:

> «Собери весь анализ из шагов 1–5 в один ноутбук, чтобы при его запуске заново получался весь отчёт. Каждый шаг — с заголовком и пояснением. В конце — раздел “Выводы и проверка качества”.»

Правила из курса-10 обязательны: просите код и источники, не принимайте числа «на веру».
