# Программа курса: Химия и ИИ: хемоинформатика (course-05)
> Оригинального курса нет — это авторский курс-модуль двухсеместровой программы «Генеративный ИИ на практике». Язык: русский (RU). Курс практико-ориентированный: код пишется через LLM-агентов, а не вручную.

## О курсе
Курс знакомит студентов с тем, как ИИ помогает работать с химическими данными: молекулами, базами соединений (PubChem), расчётом свойств и поиском похожих веществ. Основные инструменты — библиотека **RDKit** (работа с молекулами), база **PubChem** и её API, учебная платформа **TeachOpenCADD**, а также ИИ-агенты для химии (**ChemCrow**).

Как и в остальных курсах, программирование выполняется через LLM: студент описывает задачу словами, агент пишет и запускает код, студент проверяет результат. Специальных знаний программирования не требуется. Базовые химические знания полезны, но не обязательны — главные понятия объясняются внутри курса.

Курс соединяет две сквозные темы программы: **офисную автоматизацию** (регулярные отчёты по химическим данным) и **экономику/оценку** (стоит ли автоматизировать анализ).

## Цели обучения
После прохождения курса студент сможет:
- понимать, что такое SMILES, InChI и SDF — способы «записать молекулу в компьютере»;
- с помощью LLM/агента работать с молекулами через RDKit: читать, рисовать, описывать;
- считать свойства молекул (масса, формулы, logP, дескрипторы);
- искать и сравнивать похожие молекулы (фингерпринты, Tanimoto);
- получать данные о соединениях из PubChem через API;
- применять фильтры «лекарственноподобности» (drug-likeness) и понимать, что они значат;
- понимать, как ИИ предсказывает свойства молекул, и как использовать готовые модели;
- использовать ИИ-агентов (включая ChemCrow) для химических задач;
- проверять качество химических данных и не доверять выводам без проверки.

## Предварительные требования
- курс-01 и курс-02 (основы генеративного ИИ и промпт-инжиниринг);
- курс-04 (работа с данными: pandas, Jupyter) — желательно;
- доступ к ИИ-инструменту (бесплатный тариф);
- Python не требуется — код пишет агент;
- базовые школьные знания химии (что такое молекула, формула) — желательны, но всё объясняется по ходу.

## Структура курса: задания
Задания (в `assignments/`) — Jupyter-ноутбуки (`*.ipynb`) с готовым кодом и файлы-инструкции (`*.md`) с формулировками «как сказать агенту».

| № | Задание | Связь с лекцией |
|---|---|---|
| 01 | Знакомство с молекулами: SMILES → RDKit | 02–03 |
| 02 | Свойства молекул: расчёт и сравнение | 04 |
| 03 | Поиск похожих молекул | 05 |
| 04 | Данные из PubChem через API | 06 |
| 05 | Фильтры лекарственноподобности | 07 |
| 06 | Итоговый проект: анализ набора молекул | 10–12 |

## Как использовать подготовленную папку
- `program.md` — настоящая программа курса;
- `lectures/` — 12 лекций в Markdown (01–12), картинки не скопированы (вместо них — комментарии);
- `assignments/` — ноутбуки-задания и файлы-инструкции;
- `references/` — проверенные ссылки-источники.

## Продолжительность
Ориентировочно 12 занятий; каждое занятие рассчитано примерно на 2–3 часа (чтение + практика с агентом).
