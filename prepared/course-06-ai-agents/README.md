# course-06-ai-agents
Авторский курс-модуль «ИИ-агенты и протокол MCP» двухсеместровой программы «Генеративный ИИ на практике». Подготовлен как исходник для дальнейшей сборки общей программы.

## Источники
- Материал авторский, создан на основе проверенных публичных ресурсов (см. `references/`):
  - OpenAI Agents SDK — фреймворк для создания агентов;
  - Gemini CLI и aider — терминальные ИИ-агенты;
  - MCP (Model Context Protocol) — протокол подключения инструментов;
  - browser-use и Playwright — браузерные агенты;
  - n8n и Open WebUI — автоматизация и интерфейсы.

## Структура
- `program.md` — программа курса
- `lectures/` — 12 лекций (.md)
- `assignments/` — задания: ноутбуки (.ipynb) + файлы-инструкции (.md)
- `references/` — список проверенных ссылок-источников

## Примечания
- Язык: русский (RU). Картинки и медиа не копируются (заменены комментариями).
- Аудитория: студенты с нулевым Python; код пишется через LLM-агентов, студент проверяет результат.
- Курс практический: ставка на готовые инструменты, а не на написание сложного кода.
- Сквозные темы программы: офисная автоматизация и экономика/оценка применения ИИ.
