# Задание 01. Знакомство с Gemini CLI: первая автоматизация

## Цель
Установить терминального ИИ-агента (Gemini CLI) и получить первый реальный результат — созданные файлы, а не просто «ответ».

## Что сделать
1. Установите Node.js (если нет) и Gemini CLI:
   ```
   npm install -g @google/gemini-cli
   ```
2. Запустите `gemini` и дайте задачу создать файлы.
3. Проверьте, что файлы реально созданы (откройте их).
4. Заполните ноутбук `assignment.ipynb` и файл `task.md`.

## Задача агенту
> «Создай в этой папке подпапку `задание`. Создай в ней файл `план.md` с пятью шагами работы ИИ-агента и файл `привет.txt` со словом „привет“. Покажи содержимое обоих файлов.»

## Ответьте на вопросы
1. Чем агент (Gemini CLI) отличается от чат-бота?
2. Какие инструменты он использует при выполнении задачи?
3. Как вы проверили, что файлы реально созданы?
4. Какие шаги «думай → действуй → наблюдай» вы увидели?
5. Какая трудность возникла (если была) и как вы её решили?

## Критерии приёма
- [ ] Gemini CLI установлен и запускается.
- [ ] Файлы `план.md` и `привет.txt` созданы и показаны.
- [ ] Ноутбук заполнен (выводы по шагам).
- [ ] Ячейка «Мои выводы» заполнена (5 ответов).
- [ ] Файл скачан в формате `.ipynb`.
