# Задание 03. Свой первый агент на OpenAI Agents SDK

## Цель
Собрать своего агента на OpenAI Agents SDK с инструментами и проверить его работу.

## Что сделать
1. Получите API-ключ (OPENAI_API_KEY). Варианты: OpenAI, Groq (бесплатно, https://console.groq.com/) или локальная модель через Ollama.
2. Установите библиотеку: `pip install openai-agents`.
3. Выполните шаги ноутбука `assignment.ipynb`.
4. Проверьте результаты ручным расчётом.
5. Заполните ноутбук и `task.md`.

## Задачи
1. Создайте агента «Бухгалтер» с инструментом `sum_sales`.
2. Добавьте инструмент `gross_profit` (выручка минус затраты).
3. Проверьте: сумма 100+250+300 = 650; прибыль 1000−400 = 600.
4. Задайте агенту вопрос без инструментов и с инструментами — сравните.

## Ответьте на вопросы
1. Что такое Agent, tool, Runner в OpenAI Agents SDK?
2. Почему результат вызова функции — «реальный», а не «придуманный»?
3. Как хранить API-ключ безопасно?
4. Совпали ли результаты агента с ручным расчётом?
5. Какую задачу вы хотите дать своему агенту в итоговом проекте?

## Критерии приёма
- [ ] Агент «Бухгалтер» запущен, инструмент `sum_sales` работает.
- [ ] Инструмент `gross_profit` добавлен и проверен.
- [ ] Результаты сходятся с ручным расчётом.
- [ ] Ячейка «Мои выводы» заполнена (5 ответов).
- [ ] Файл скачан в формате `.ipynb`. Ключ в код не вставлен.
