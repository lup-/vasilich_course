# Задание 05. Свой MCP-сервер на Python

## Цель
Написать собственный MCP-сервер на Python, подключить его к агенту и вызвать свои инструменты.

## Что сделать
1. Установите библиотеку `mcp`.
2. Создайте файл `server.py` с инструментами `get_weather` и `sum_list` (код в ноутбуке).
3. Запустите сервер в отдельном терминале и проверьте, что он стартует.
4. Добавьте сервер в конфиг MCP-клиента.
5. Перезапустите агента, вызовите оба инструмента, проверьте результаты.
6. Добавьте третий инструмент по своему выбору.
7. Заполните ноутбук и `task.md`.

## Ответьте на вопросы
1. Что делает MCP-сервер?
2. Из чего состоит инструмент на сервере (функция)?
3. Как вы подключили сервер к агенту?
4. Совпали ли результаты `sum_list([1,2,3])` = 6 и `get_weather("Москва")` с ожиданиями?
5. Какую функцию из вашей работы вы хотели бы отдать агенту и почему?

## Критерии приёма
- [ ] `server.py` создан и запускается без ошибок.
- [ ] Оба инструмента вызваны через агента, результаты записаны.
- [ ] Добавлен третий инструмент по своему выбору.
- [ ] Конфиг подключения записан в ноутбук.
- [ ] Ячейка «Мои выводы» заполнена (5 ответов).
- [ ] Файл скачан в формате `.ipynb`.
