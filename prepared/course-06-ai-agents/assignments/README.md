# Задания курса-06 «ИИ-агенты и протокол MCP»

Каждое задание — папка с ноутбуком `assignment.ipynb` (или `project_template.ipynb`) и файлом-инструкцией `task.md`.

## Как сдавать
1. Выполните задание: ноутбук в Google Colab + практика в терминале (Gemini CLI).
2. Скачайте ноутбук: File → Download → .ipynb.
3. Заполните файл `task.md` (ответы на вопросы).
4. Сдайте оба файла (или ноутбук с выводами внутри).

## Список заданий
| № | Задание | Папка | Лекции |
|---|---|---|---|
| 01 | Знакомство с Gemini CLI: первая автоматизация | `01-gemini-cli/` | 04 |
| 02 | Инструменты агента: файлы, код, поиск | `02-agent-tools/` | 03 |
| 03 | Свой первый агент на OpenAI Agents SDK | `03-agents-sdk/` | 05 |
| 04 | Подключение готовых MCP-серверов | `04-mcp-servers/` | 07 |
| 05 | Свой MCP-сервер на Python | `05-mcp-server-python/` | 08 |
| 06 | Итоговый проект: агент для вашей задачи | `06-final-project/` | 10–12 |

## Важно
- Для заданий 01, 02, 04, 05 нужен терминальный агент (Gemini CLI) — установите его заранее.
- Для задания 03 нужен API-ключ (OPENAI_API_KEY). Никогда не вставляйте ключ в код.
- Код пишется через LLM-агента, но вы отвечаете за проверку результатов (лекция 11).
- Пункты «Выводы» обязательны: без них задание не засчитывается.
- В ноутбуках есть ячейки `TODO` и пустые — заполняйте их или просите агента это сделать.
