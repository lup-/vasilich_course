# 01. Что такое ИИ-агент

> Семестр: 2 · Курс: «ИИ-агенты и протокол MCP» (course-06) · Время: ~2 часа

## Введение

Чат-бот отвечает на вопросы. ИИ-агент **делает** работу: пишет файлы, вызывает программы, собирает данные, запускает отчёты. Разница не в «умности», а в том, что агент может **действовать**.

## Чат-бот против агента

| | Чат-бот | ИИ-агент |
|---|---|---|
| Получает | Вопрос | Задачу |
| Делает | Отвечает текстом | Выполняет действия |
| Инструменты | Нет | Есть (файлы, код, браузер, API) |
| Шаги | Один ответ | Цепочка шагов |
| Результат | Текст | Файл, таблица, действие, отчёт |

Простой пример:

- **Чат-боту**: «Объясни, что такое SMILES» → текст.
- **Агенту**: «Прочитай файл `sales.csv`, посчитай продажи по регионам и сохрани отчёт в Excel» → готовый файл.

## Почему агенты стали возможны

Раньше модели отвечали только текстом. Теперь модели умеют:

1. **Вызывать функции** — на выходе не только текст, но и «вызови функцию X с такими аргументами»;
2. **Читать результаты** — смотреть вывод программы и продолжать;
3. **Планировать** — разбивать задачу на шаги.

Из этих трёх умений собирается цикл работы агента (подробнее в лекции 02).

## Что такое «инструменты» агента

Инструмент (tool) — это то, что агент может «вызвать», как человек вызывает программу:

- прочитать файл;
- выполнить код;
- поискать в интернете;
- открыть сайт в браузере;
- отправить запрос к API.

Важно: инструменты не «придумываются» агентом — они **описаны** заранее (функция, её название, параметры, описание). Агент выбирает, какой вызвать. Подробнее — лекция 03.

## Виды агентов (по готовности)

1. **Готовые агенты**: Gemini CLI, aider, Open WebUI — уже настроены, вы ими пользуетесь (лекция 04).
2. **Агенты из фреймворков**: OpenAI Agents SDK — собираются кодом, но код пишет ИИ (лекция 05).
3. **Агенты с браузером**: browser-use, Playwright — работают с сайтами (лекция 09).

В курсе почти везде используются готовые решения. Наша цель — не программировать агента «из бумаги», а заставить его работать на нас и **проверять результат**.

## Правило курса: «агент делает, вы проверяете»

Самое важное правило, которое проходит через все лекции:

- агент пишет код, запускает его, собирает данные;
- **вы** решаете, правильный ли результат;
- агент может ошибиться, «придумать» файл или число;
- проверка — ваша работа (лекция 11).

Пример формулировки задачи агенту:

> «Создай папку `отчёт`. Прочитай `sales.csv`. Посчитай сумму продаж по каждому региону. Сохрани таблицу в `отчёт/regions.xlsx` и напиши файл `отчёт/итоги.md` с двумя предложениями о результатах. Покажи мне, что получилось.»

## Практика прямо сейчас

Если у вас установлен Gemini CLI (лекция 04) — попробуйте:

> «Создай файл `привет.txt` со словом „привет“ и покажи его содержимое.»

Агент выполнит действия и вернёт результат. Вы увидите разницу между «ответом» и «работой».

## Частые проблемы

| Проблема | Решение |
|---|---|
| Агент «просто ответил», а не сделал | Сформулировать задачу как действие: «создай», «сохрани», «выполни» |
| Агент делает слишком много | Ограничить: «только создай файл, ничего не запускай» |
| Агент придумал результат | Проверить файлы/вывод самостоятельно (лекция 11) |
| Непонятно, что агент делал | Просить показывать каждый шаг и промежуточные результаты |
