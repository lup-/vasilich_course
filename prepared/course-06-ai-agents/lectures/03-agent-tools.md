# 03. Инструменты (tools) агента

> Семестр: 2 · Курс: «ИИ-агенты и протокол MCP» (course-06) · Время: ~2 часа

## Введение

Инструменты — то, что отличает агента от чат-бота. Разберём, как они устроены: как модель «знает», что можно вызвать, как передаются аргументы и почему инструмент — это просто функция.

## Что такое инструмент технически

Инструмент — это функция (программа) с описанием:

- **название** — например `read_file`;
- **параметры** — например `путь` (строка);
- **описание** — «читает содержимое файла и возвращает его текст».

Модель «знает» список таких описаний. Когда задача требует действия, модель выдаёт не текст, а **запрос на вызов**: «вызвать `read_file` с аргументом `path="sales.csv"`».

Затем среда (то, где работает агент) реально выполняет функцию и возвращает результат модели. Так работает вызов инструментов.

## Примеры инструментов

| Инструмент | Что делает | Задача |
|---|---|---|
| `read_file` | читает файл | «посмотри, что в отчёте» |
| `write_file` | пишет файл | «сохрани результат» |
| `execute_code` | выполняет Python | «посчитай по формуле» |
| `web_search` | ищет в интернете | «найди свежие данные» |
| `browse_url` | открывает сайт | «прочитай страницу» |
| `send_request` | вызывает API | «получи данные из PubChem» |

Готовые агенты уже имеют набор таких инструментов. Вы не пишете их код — вы просто даёте агенту задачу, и он сам вызывает нужный инструмент.

## Как «увидеть» инструменты в действии

Попросите агента:

> «Показывай, какой инструмент ты вызываешь и с какими параметрами.»

В выводе появится что-то вроде:

```
[инструмент: read_file, path="sales.csv"]
[результат: дата,регион,сумма
2025-01-01,Москва,1200
...]
```

Так вы видите: агент **действительно** прочитал файл (а не «представил» его содержимое). Если вызова нет, а агент говорит «я прочитал» — это «галлюцинация», результат не подтверждён.

## Почему инструменты важны

1. **Точность**: числа берутся из реальных данных, а не из «головы» модели.
2. **Действие**: файл реально создаётся, таблица реально сохраняется.
3. **Проверяемость**: вы можете открыть файл и увидеть результат своими глазами.
4. **Расширяемость**: добавить новый инструмент — добавить агенту возможность (лекции 06–08, MCP).

## Ошибки и подводные камни

- **Агент не вызвал инструмент**: если результат «очевиден» из текста, модель может не вызывать функцию. Требуйте: «вызови инструмент и покажи результат вызова».
- **Неверные параметры**: агент передал не тот путь к файлу. Проверяйте имена файлов.
- **Инструмента нет**: агент не имеет нужной функции (например, нет браузера). Это ограничение набора инструментов.
- **Инструмент ошибается**: код упал, файл не найден — агент должен сообщить об ошибке, а не выдумать результат.

## Формулировка задачи «через инструменты»

Заставляйте агента действовать через инструменты явно:

> «Не отвечай текстом „готово“ — реально создай файл `итог.csv` с результатом и покажи его первые строки. Для этого вызови инструменты записи и чтения файла.»

Так вы получаете проверяемый результат.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Агент «говорит», а не «делает» | Требовать вызов инструмента и показ результата |
| Файл создан не там | Проверять имена и пути, давать абсолютные пути |
| Агент выдумал данные | Просить вызвать чтение/запись и показать содержимое |
| Нет нужного инструмента | Добавить через MCP (лекции 06–08) |

## Задание на дом

1. Напишите список из 5 задач и для каждой — какой инструмент нужен агенту.
2. Если есть агент — дайте задачу «создай файл и покажи его содержимое» и запишите, какой инструмент вызывался.
3. Попросите агента «посчитать сумму в таблице» двумя способами: (а) только текстом, (б) с вызовом кода. Сравните и запишите разницу.
4. Сформулируйте своими словами, почему вызов инструмента важнее «честного ответа» модели.

## Проверка знаний

- Что такое инструмент агента? Из чего состоит его описание?
- Как модель «решает», какой инструмент вызвать?
- Приведите пример: какая задача требует инструмента, а какая нет?
- Как понять, что агент «придумал» результат вместо вызова инструмента?
- Что делать, если нужного инструмента нет?
