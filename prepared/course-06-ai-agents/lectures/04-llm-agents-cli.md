# 04. Готовые агенты: Gemini CLI, aider, Open WebUI

> Семестр: 2 · Курс: «ИИ-агенты и протокол MCP» (course-06) · Время: ~3 часа

## Введение

Не нужно писать агента с нуля. Существуют готовые агенты, которые уже умеют читать файлы, выполнять код и вызывать инструменты. Разберём три самых полезных: **Gemini CLI** (терминал), **aider** (парный программист) и **Open WebUI** (веб-интерфейс). Плюс правила безопасной работы.

## Gemini CLI — агент в терминале

Что это: официальный инструмент Google — агент в командной строке, который видит файлы проекта, умеет их менять, запускать команды и общаться с вами.

Где взять: https://github.com/google-gemini/gemini-cli

Установка (на Linux/macOS, или в Windows через WSL):

```bash
npm install -g @google/gemini-cli
```

Запуск и первый диалог:

```bash
gemini
```

Внутри — обычный чат, но с возможностями агента:

> «Покажи, какие файлы есть в этой папке.»
> «Создай файл `notes.md` с тремя пунктами про агентов.»
> «Найди в проекте все упоминания слова „агент“ и перечисли их.»

Что важно знать:
- агент работает в текущей папке и может её менять;
- он показывает, какие файлы редактирует;
- без вашего разрешения менять опасные вещи (удалять, git push) он не должен;
- требует API-ключ или вход в аккаунт (бесплатный тариф).

## aider — парный ИИ-программист

Что это: агент, специализированный на программировании. Правки кода прямо в проекте, с git-коммитами и объяснениями.

Где взять: https://aider.chat/docs/

Установка:

```bash
python -m pip install aider-chat
```

Запуск в папке проекта:

```bash
aider
```

Пример:

> «Добавь в файл `main.py` функцию, которая читает CSV и считает сумму. Объясни, что ты изменил.»

aider создаёт коммиты в git, поэтому любую правку можно откатить. Это его главная защита: даже если агент «сломал» код — всё восстанавливается.

## Open WebUI — веб-интерфейс для моделей

Что это: браузерный интерфейс, где вы разговариваете с моделями (в том числе локальными через Ollama/LM Studio), а в последних версиях есть и агентные возможности, и подключение инструментов (MCP).

Где взять: https://docs.openwebui.com/

Запуск (через Docker или pip):

```bash
pip install open-webui
open-webui serve
```

Затем открыть http://localhost:8080 в браузере. Плюс: удобный интерфейс, история, несколько моделей. Минус: для простых задач терминальный Gemini CLI проще.

## Как выбрать

| Задача | Инструмент |
|---|---|
| Быстро поработать с файлами в папке | Gemini CLI |
| Правки кода с git-историей | aider |
| Веб-интерфейс + локальные модели | Open WebUI (+ Ollama/LM Studio) |
| Длинные задачи с инструментами | Gemini CLI + MCP (лекции 06–08) |

Для курса основной рабочий инструмент — **Gemini CLI**, потому что он бесплатен, прост и поддерживает MCP.

## Безопасность при работе с агентами

Правила, которые нельзя нарушать:

1. **Агент работает в ваших файлах**: запускайте его только в папке, которую не жалко изменить (копия проекта, рабочая папка).
2. **Проверяйте команды**: не давайте агенту «полный доступ к системе» без необходимости.
3. **Не доверяйте без проверки**: файлы, которые он создал, надо открыть и проверить.
4. **Секреты**: не вставляйте пароли и ключи в промпты и не просите агента их «вытащить» из файлов.
5. **Откат**: в aider правки в git — вернитесь к прошлой версии, если что-то сломалось.

## Практика: первый полезный результат

Цель — за 15 минут получить реальный результат:

> «Создай в этой папке подпапку `задание`. Создай в ней файл `план.md`, в котором перечислены 5 шагов работы ИИ-агента, и файл `привет.txt` со словом „привет“. Покажи содержимое обоих файлов.»

Агент создаст файлы — вы их увидите и проверите. Это уже «работа», а не «ответ».

## Частые проблемы

| Проблема | Решение |
|---|---|
| `npm install` не работает | Установить Node.js (nodejs.org), проверить версию |
| Нет API-ключа | Бесплатный ключ: Google AI Studio / aistudio.google.com |
| Агент «не видит» файлы | Запускать из нужной папки (терминал), показывать путь |
| Слишком много изменений | Давать точные инструкции, ограничивать рамки |
| Сломал файлы | Если aider — git revert; в любом случае иметь копию |
