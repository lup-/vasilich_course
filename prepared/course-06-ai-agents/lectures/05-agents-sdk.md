> Семестр: 2 · Курс: «ИИ-агенты и протокол MCP» (course-06) · Время: ~3 часа

## Введение

Готовые агенты удобны, но их возможности ограничены. Фреймворки позволяют собрать **своего** агента: свои инструменты, свой сценарий, своя логика. Мы возьмём **OpenAI Agents SDK** — простую библиотеку, где агент описывается кодом, но код пишет ИИ.

<!-- изображение (не скопировано): схема: код агента → агент с инструментами → задача → результат -->

## Что такое OpenAI Agents SDK

Это библиотека Python от OpenAI для создания агентов. Ключевые понятия:

- **Agent** — агент с «персоной» и набором инструкций;
- **tool** — функция, которую агент может вызвать;
- **Runner** — «запускатель», который выполняет цикл «думай-действуй».

Мы не будем разбирать все детали — в курсе важно понять идею, а код поручим ИИ.

## Первый агент: идея

```python
from agents import Agent, Runner

# Агент — это модель + описание, что и как делать
agent = Agent(
    name="Помощник",
    instructions="Ты — дружелюбный помощник. Отвечай коротко и по делу.",
)

# Запуск: даём задачу, получаем результат
result = Runner.run_sync(agent, "Поздоровайся и назови себя")
print(result.final_output)
```

Здесь агент — простой «чат-бот с персоной». Настоящая сила появляется с инструментами.

## Добавляем инструменты

Инструмент — обычная функция с описанием. Например, «узнать время»:

```python
from agents import Agent, Runner
import datetime

def current_time() -> str:
    """Возвращает текущие дату и время."""
    return str(datetime.datetime.now())

agent = Agent(
    name="Ассистент",
    instructions="Ты — ассистент. Если нужна информация — используй инструменты.",
    tools=[current_time],
)

result = Runner.run_sync(agent, "Который сейчас час?")
print(result.final_output)
```

Модель сама поймёт, что для ответа нужно вызвать `current_time`, выполнит его и вернёт вам результат. Обратите внимание: время — реальное, не выдуманное моделью.

## Практический пример: инструмент с параметрами

Функция, которая считает продажи: инструменты с аргументами — как обычные функции Python.

```python
def sum_sales(receipts: list[float]) -> float:
    """Считает сумму списка чисел (продаж)."""
    return sum(receipts)

agent = Agent(
    name="Бухгалтер",
    instructions="Ты считаешь суммы. Вызывай инструмент sum_sales.",
    tools=[sum_sales],
)

result = Runner.run_sync(agent, "Посчитай сумму: 100, 250, 300")
print(result.final_output)
```

Агент «вызовет» функцию с числами из задачи и вернёт результат. Через ИИ вы можете расширять агента: описать новую функцию словами — и попросить его же её написать.

## Как строить агента «словами через ИИ»

Вам не нужно писать код руками. Скажите агенту (например, Gemini CLI):

> «Напиши код для OpenAI Agents SDK: агент с двумя инструментами — 1) current_time() возвращает время, 2) multiply(a, b) умножает числа. Инструкции: „ты — помощник, вызывай инструменты, когда нужно“. Покажи код и пример запуска.»

Затем скопируйте код, запустите, проверьте. Так фреймворк становится инструментом, а не «препятствием».

## Где взять API-ключ

OpenAI Agents SDK работает с моделями OpenAI и совместимыми (Groq, локальные через Ollama). Для курса подойдёт:

- ключ OpenAI (бесплатные лимиты есть, но обычно платно);
- Groq — бесплатный доступ: https://console.groq.com/ ;
- локальная модель через Ollama (не требует ключа, лекция курса-07).

Ключ в коде задаётся переменной окружения `OPENAI_API_KEY`. **Никогда не вставляйте ключ в сам код** и не показывайте его в отчётах.

## Ограничения фреймворка

- Нужен API-ключ и/или доступ к модели (часто платно).
- Агент «глуп» без инструментов: без них это чат-бот.
- Сложная логика требует больше кода — но этот код пишет ИИ.
- Нужна установка: `pip install openai-agents`.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Нет модуля `agents` | `pip install openai-agents` |
| Ошибка авторизации | Проверить `OPENAI_API_KEY`, не вставлять ключ в код |
| Инструмент не вызывается | Проверить описание функции и что он в `tools=[...]` |
| Агент «отвечает сам» | В инструкциях написать: «всегда вызывай инструмент X» |
| Результат не тот | Проверить код инструмента (код пишет ИИ, но отвечаете вы) |
