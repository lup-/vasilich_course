# 07. MCP: подключение серверов

> Семестр: 2 · Курс: «ИИ-агенты и протокол MCP» (course-06) · Время: ~3 часа

## Введение

Протокол MCP мы разобрали. Теперь практика: подключить **готовые серверы** к агенту (клиенту) и использовать их инструменты. Основной клиент курса — Gemini CLI. Покажем на примере файлового сервера и браузера.

## Подготовка

1. Установите Gemini CLI (лекция 04).
2. Найдите документацию вашей версии (команды и путь к конфигу могут отличаться — спросите агента):
   - официальная документация Gemini CLI: https://github.com/google-gemini/gemini-cli

Главное: конфигурация MCP у Gemini CLI лежит в файле настроек, где прописываются серверы. Точный путь выясняем через агента или документацию.

## Шаг 1. Найти готовый сервер

Готовые серверы — программы, которые «запускаются» и отдают инструменты. Примеры:

- файловый сервер (доступ к папкам);
- браузерный сервер;
- сервер поиска.

Многие опубликованы в открытых репозиториях и устанавливаются одной командой (npm/pip). Точные команды зависят от версии — уточняйте у агента, но не доверяйте «придуманным» командам: проверяйте по официальной документации.

## Шаг 2. Прописать сервер в конфиг

Общая идея (на примере, не как точная команда вашей версии):

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/folder"]
    }
  }
}
```

- `filesystem` — имя сервера (как его будет видеть агент);
- `command` / `args` — как его запустить;
- `/path/to/folder` — какие папки открыть агенту (только те, что вы разрешили).

Точные поля вашей версии проверьте в документации Gemini CLI. Главное — понять структуру: имя сервера + команда запуска.

## Шаг 3. Перезапустить агента и проверить

После изменения конфига перезапустите агента. Затем спросите:

> «Какие инструменты тебе доступны? Покажи список.»

Если сервер подключён, агент назовёт инструменты (например, «чтение файлов», «список папок»). Теперь можно использовать:

> «Покажи список файлов в папке, к которой у тебя есть доступ.»

## Шаг 4. Работа с браузерным сервером

Подключив браузерный сервер, агент может открывать страницы и собирать данные:

> «Открой страницу https://example.com и выпиши заголовок и первый абзац текста.»

Вы увидите реальные данные с сайта, а не «представленные» агентом. Это основа для лекции 09.

## Что важно помнить

- **Доступ ограничен**: давайте агенту только те папки и сайты, которые нужны.
- **Проверяйте команды**: команды запуска серверов должны браться из официальных источников, а не «из головы» агента.
- **Безопасность**: не подключайте серверы с полным доступом к системе без необходимости.
- **Несколько серверов**: можно подключать сразу несколько — файлы, браузер, поиск.

## Как формулировать задачи агенту по настройке

> «Подскажи, как в моей версии Gemini CLI подключить MCP-сервер для доступа к папке `/home/user/данные`. Покажи точный конфиг и команды. Сверь с официальной документацией.»

И обязательно после настройки — проверка:

> «Перечисли доступные тебе инструменты и покажи результат вызова одного из них.»

## Частые проблемы

| Проблема | Решение |
|---|---|
| Сервер не появляется | Проверить конфиг, перезапустить агента, проверить путь |
| Ошибка запуска сервера | Проверить, установлен ли нужный пакет (npm/pip) |
| Нет доступа к папке | Убедиться, что путь в конфиге правильный и разрешён |
| Агент не использует инструменты | В явном виде попросить: «вызови инструмент X» |
| Команды «из головы» | Проверять по официальной документации |

## Задание на дом

1. Узнайте, поддерживает ли ваш Gemini CLI MCP (документация/спросить агента).
2. Подключите файловый сервер к папке с рабочими документами.
3. Спросите агента: «какие инструменты доступны?» — запишите ответ.
4. Дайте агенту задачу: «перечисли файлы в папке и покажи содержимое одного из них».
5. Подключите браузерный сервер (по желанию) и откройте одну страницу.
