# 08. Свой MCP-сервер на Python

> Семестр: 2 · Курс: «ИИ-агенты и протокол MCP» (course-06) · Время: ~3 часа

## Введение

Готовых серверов много, но не всегда есть нужный. Хорошая новость: написать свой MCP-сервер несложно, а код напишет ИИ. Вы описываете функции — агент превращает их в сервер, который подключается к вашему же агенту.

<!-- изображение (не скопировано): схема: вы описываете функции → код пишет ИИ → сервер MCP → подключается к клиенту -->

## Идея

MCP-сервер — это программа, которая:
1. объявляет свои инструменты (название, параметры, описание);
2. ждёт запросы от клиента (агента);
3. выполняет функции и возвращает результаты.

Для Python есть библиотеки (например, `mcp` от официального проекта), которые упрощают это. Точная установка — в документации https://modelcontextprotocol.io/.

## Простой сервер: идея кода

```python
# server.py — упрощённая схема своего MCP-сервера
from mcp.server.fastmcp import FastMCP

server = FastMCP("my-tools")

@server.tool()
def get_weather(city: str) -> str:
    """Возвращает "погоду" для города (демо)."""
    return f"Погода в {city}: +18°C, солнечно"

@server.tool()
def sum_list(numbers: list[float]) -> float:
    """Считает сумму чисел."""
    return sum(numbers)

if __name__ == "__main__":
    server.run()
```

Два инструмента: `get_weather` и `sum_list`. Каждая функция — обычный Python с типизацией и описанием. Именно это описание агент «увидит» и сможет вызвать.

## Как создать сервер через ИИ

Вам не нужно разбираться в деталях протокола. Опишите ИИ:

> «Напиши MCP-сервер на Python с библиотекой mcp (FastMCP). Два инструмента: 1) get_weather(city) — возвращает строку с погодой, 2) sum_list(numbers) — сумма списка чисел. Покажи код, команду установки библиотеки и команду запуска.»

ИИ напишет код (похожий на пример выше), вы сохраните его в файл, запустите. Проверьте, что сервер запускается без ошибок.

## Подключение к агенту

Затем в конфиг клиента (лекция 07) добавляете свой сервер — командой запуска вашего скрипта, например:

```json
{
  "mcpServers": {
    "my-tools": {
      "command": "python",
      "args": ["/path/to/server.py"]
    }
  }
}
```

Перезапустите агента и проверьте:

> «Какие инструменты тебе доступны? Вызови sum_list со списком 1, 2, 3.»

Агент вызовет вашу функцию и вернёт результат.

## Что можно сделать своим сервером

- **Данные компании**: функция, читающая таблицу продаж и считающая итоги;
- **Внутренние базы**: функция запроса к вашей БД;
- **Расчёты**: специфические формулы вашей работы;
- **Документы**: генерация отчёта по шаблону.

Важно: сервер — это «мост» между агентом и вашими данными/программами. Всё, что умеет Python, можно «отдать» агенту как инструмент.

## Безопасность своего сервера

1. **Только нужные функции**: не открывайте агенту «весь компьютер», добавляйте конкретные инструменты.
2. **Проверка ввода**: функция должна аккуратно обрабатывать входные данные (не падать, не выполнять опасные команды).
3. **Ограничение доступа**: к файлам/БД давать доступ только к нужному.
4. **Проверка результата**: код пишет ИИ, но проверяете вы — тестируйте каждую функцию отдельно.

## Практический пример: таблица продаж

Функция, которая полезнее «погоды»:

```python
@server.tool()
def sales_report(path: str) -> str:
    """Читает CSV с продажами (дата, регион, сумма) и возвращает сумму по регионам."""
    import pandas as pd
    df = pd.read_csv(path)
    return df.groupby("регион")["сумма"].sum().to_string()
```

Подключив такой сервер, агент сможет: «прочитай sales.csv и покажи продажи по регионам» — и получит реальный результат из файла.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Библиотека `mcp` не найдена | `pip install mcp` (или по инструкции проекта) |
| Сервер запускается, но не подключается | Проверить команду и путь в конфиге, перезапустить клиент |
| Функция падает | Добавить обработку ошибок (`try/except`), тестировать отдельно |
| Агент не вызывает инструмент | Проверить описание функции и инструкции агента |
| Код «придуманный», не работает | Сверять с официальной документацией MCP, просить ИИ исправить |
