# 09. Браузерные агенты

> Семестр: 2 · Курс: «ИИ-агенты и протокол MCP» (course-06) · Время: ~3 часа

## Введение

Многие данные лежат на сайтах: цены, таблицы, новости, отчёты. Браузерные агенты умеют «ходить» по сайтам и собирать их. Разберём два пути: **browser-use** (ИИ управляет браузером) и **Playwright** (автоматизация по скриптам), а также связь с MCP.

## Зачем браузерные агенты

- Собрать данные с сайта, где нет API;
- Проверить информацию на странице (цены, характеристики);
- Заполнить формы, нажать кнопки;
- Собрать таблицы с сайтов в один файл.

Главное отличие от «просто спросить модель»: агент реально открывает страницу и берёт данные оттуда — а не «придумывает» их.

## Путь 1: browser-use (ИИ сам управляет браузером)

**browser-use** — библиотека, которая даёт ИИ-агенту возможность управлять реальным браузером: открывать страницы, кликать, читать.

Установка:

```bash
pip install browser-use
```

Идея (код пишет ИИ):

```python
from browser_use import Agent
import asyncio

agent = Agent(
    task="Открой https://example.com и выпиши заголовок страницы",
)

asyncio.run(agent.run())
```

Агент сам решит, как открыть сайт и что вытащить. Код, как обычно, писать не нужно вручную — опишите задачу другому агенту и скопируйте код.

## Путь 2: Playwright (автоматизация по шагам)

**Playwright** — инструмент автоматизации браузера: не «ИИ решает», а вы/код задаёте шаги.

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://example.com")
    print(page.title())
    browser.close()
```

Пример задачи для ИИ:

> «Напиши скрипт на Playwright: открой страницу с таблицей, прочитай таблицу и сохрани в CSV.»

Playwright надёжнее для повторяющихся задач, browser-use гибче (сам придумывает шаги), но требует модели и может ошибаться.

## browser-use + MCP

browser-use можно подключить как MCP-сервер — тогда ваш основной агент (например, Gemini CLI) получит «браузер» как инструмент (лекции 06–07). Вы просто говорите:

> «Открой https://... и собери таблицу цен в CSV.»

Агент через MCP-инструмент браузера реально это делает.

## Как собирать данные с сайтов правильно

План «сбор данных со страницы»:

1. **Проверьте легальность**: права на данные, условия сайта, не трогать личные данные.
2. **Начинайте с одного**: откройте страницу вручную, посмотрите структуру.
3. **Просите агента по шагам**: «открой, подожди, прочитай таблицу, сохрани в CSV».
4. **Проверяйте результат**: откройте CSV и сравните с сайтом.
5. **Паузы и вежливость**: не «долбить» сайт сотнями запросов.

## Типичные задачи и примеры

| Задача | Как |
|---|---|
| Собрать таблицу со страницы | Playwright: прочитать таблицу → CSV |
| Проверить цену товара | browser-use: открыть страницу, выписать цену |
| Собрать новости с сайта | browser-use: собрать заголовки → список |
| Данные за несколько страниц | Скрипт с переходом по ссылкам (пагинация) |

## Частые проблемы

| Проблема | Решение |
|---|---|
| Сайт блокирует автоматизацию | Некоторые сайты защищены (антиботы); использовать аккуратно и этично |
| Нет данных на странице | Дождаться загрузки (ожидание), обновить скрипт |
| Агент «выдумал» данные | Проверить, что он реально открыл страницу (показать скриншот/текст) |
| Слишком много запросов | Добавить паузы, уменьшить число страниц |
| Код не работает | Сверять с документацией Playwright/browser-use, просить ИИ исправить |

## Этика и правила

- Собирайте только открытые данные, не обходите защиту.
- Не собирайте личные данные без оснований.
- Уважайте сайты: не «долбите» их запросами.
- Проверяйте, что вы имеете право использовать собранные данные (лицензия сайта).
