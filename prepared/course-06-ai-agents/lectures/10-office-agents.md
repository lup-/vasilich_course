# 10. Агенты для офиса

> Семестр: 2 · Курс: «ИИ-агенты и протокол MCP» (course-06) · Время: ~3 часа

## Введение

Офисная рутина — таблицы, отчёты, документы — идеальная работа для агентов. В этой лекции собираем всё вместе: агент готовит отчёт по данным, а автоматизация (n8n) делает это регулярно. Это сквозная тема программы «офисная автоматизация».

## Какие офисные задачи подходят агентам

1. **Собрать данные** (из файлов, API, сайтов);
2. **Обработать** (посчитать, очистить);
3. **Сформировать отчёт** (таблица, текст, график);
4. **Разослать/сохранить** (файл, письмо).

Идеально: задача повторяющаяся, с понятным правилом и проверяемым результатом.

## Пример: еженедельный отчёт по продажам

Задача: «Каждую неделю посчитать продажи по регионам и сделать отчёт». Раньше — руками (30 минут). Теперь — агентом (2 минуты).

Формулировка агенту:

> «Прочитай `sales.csv`. Посчитай сумму и количество продаж по каждому региону. Отсортируй по сумме по убыванию. Построй столбчатую диаграмму и сохрани её в PNG. Сохрани таблицу в `отчёт/regions.xlsx`. Напиши `отчёт/итоги.md` с 3 предложениями: лидер, динамика, предложение. Покажи, что получилось.»

Проверка: открыть `regions.xlsx` и сравнить числа с исходным файлом.

## Агент + Excel: таблицы и формулы

Агент умеет работать с Excel-файлами через код (pandas/openpyxl). Пример задач:

- «Добавь столбец "итого" = цена × количество»;
- «Сведи данные из трёх листов в один»;
- «Построй диаграмму и вставь в файл»;
- «Проверь, что суммы сходятся между листами».

Важно: после изменений открыть файл и убедиться, что всё на месте. Агент «делает», вы — проверяете.

## Автоматизация по расписанию: n8n

n8n — инструмент автоматизации: «если наступил момент времени / произошло событие → запусти шаги». n8n умеет вызывать LLM/агентов, читать файлы, отправлять уведомления.

Идея связки:

```
n8n (расписание: каждую неделю)
   → запускает агента/скрипт
   → формирует отчёт
   → сохраняет и уведомляет
```

Где взять: https://n8n.io/ (self-hosted бесплатно или облако).

## Экономика офисной автоматизации

Оценка (сквозная тема «экономика»):

| | Вручную | С агентом |
|---|---|---|
| Время на отчёт | 45 мин | 5 мин |
| Раз в неделю | 39 ч/год | 4 ч/год |
| Стоимость (при 600 руб/ч) | ~23 000 руб/год | ~2 500 руб/год |

Даже простая автоматизация экономит заметные деньги. В итоговом проекте (лекция 12) вы посчитаете экономику своей задачи.

## Что автоматизировать не стоит

- Задачи с неоднозначным результатом;
- Единоразовые действия (сложность настройки не окупается);
- То, что требует решения и ответственности человека;
- Работу с данными, которые нельзя «отдать» ИИ (секреты, личные данные) без согласования.

## Проверка результатов в офисе

Офисные отчёты ошибочные = дорого. Поэтому:

1. **Контрольные суммы**: «сумма по регионам должна равняться общей сумме» — просить агента проверять.
2. **Сверка с источником**: числа из файла должны совпадать с исходными данными.
3. **Резервные копии**: перед изменением файла — копия.
4. **Человек решает**: отчёт готовит агент, решение принимает человек.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Агент «сдвинул» данные | Сравнить с исходным файлом, контрольные суммы |
| Excel не открывается | Проверить библиотеку, открыть в LibreOffice/Excel |
| Отчёт «красивый, но неверный» | Проверить числа, а не картинки |
| n8n сложно настроить | Начать с простого сценария «по времени → запуск скрипта» |
| Автоматизация не окупается | Посчитать экономику до внедрения |
