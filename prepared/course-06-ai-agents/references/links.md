# Ссылки-источники: курс-06 «ИИ-агенты и протокол MCP»

Все ссылки проверены (webfetch, работающий контент). Группировка по темам лекций.

## Терминальные и локальные агенты (лекции 01–04)
- Gemini CLI (официальный репозиторий Google): https://github.com/google-gemini/gemini-cli
- aider — парный ИИ-программист: https://aider.chat/docs/
- Open WebUI — интерфейс для локальных моделей: https://docs.openwebui.com/
- Ollama — запуск моделей локально: https://docs.ollama.com/
- LM Studio — локальные модели: https://lmstudio.ai/

## Фреймворки агентов (лекция 05)
- OpenAI Agents SDK (документация): https://openai.github.io/openai-agents-python/
- OpenAI платформа (модели и API): https://platform.openai.com/docs

## MCP (лекции 06–08)
- Model Context Protocol, введение: https://modelcontextprotocol.io/
- Быстрый старт MCP для пользователя: https://modelcontextprotocol.io/quickstart/user

## Браузерные агенты (лекция 09)
- browser-use — управление браузером через ИИ: https://github.com/browser-use/browser-use
- Playwright — автоматизация браузера: https://playwright.dev/

## Автоматизация и офис (лекция 10)
- n8n — автоматизация рабочих процессов: https://n8n.io/
- pandas — работа с таблицами: https://pandas.pydata.org/

## Модели и сервисы (вспомогательно)
- Groq — бесплатный доступ к моделям: https://console.groq.com/
- Google AI Studio — тестирование моделей: https://aistudio.google.com/
- Hugging Face — модели и демо: https://huggingface.co/models

## Примечания
- Ссылка https://chatgpt.com не проверяема автоматически (403, JS-защита), но ресурс известен.
- Некоторые сервисы (browser-use, Agents SDK) требуют Python-окружения или API-ключа; в заданиях даются упрощённые альтернативы.
