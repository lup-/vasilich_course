# course-07-local-models
Авторский курс-модуль «Локальные ИИ-модели и приватность» двухсеместровой программы «Генеративный ИИ на практике». Подготовлен как исходник для дальнейшей сборки общей программы.

## Источники
- Материал авторский, создан на основе проверенных публичных ресурсов (см. `references/`):
  - Ollama — запуск локальных моделей;
  - LM Studio — локальные модели с интерфейсом;
  - Open WebUI — веб-интерфейс для локальных моделей;
  - Hugging Face — каталог открытых моделей.

## Структура
- `program.md` — программа курса
- `lectures/` — 12 лекций (.md)
- `assignments/` — задания: ноутбуки (.ipynb) + файлы-инструкции (.md)
- `references/` — список проверенных ссылок-источников

## Примечания
- Язык: русский (RU). Картинки и медиа не копируются (заменены комментариями).
- Аудитория: студенты с нулевым Python; код пишется через LLM-агентов, студент проверяет результат.
- Курс практический: ставка на готовые инструменты (Ollama, LM Studio, Open WebUI).
- Сквозные темы программы: приватность/контроль данных и экономика/оценка применения ИИ.
