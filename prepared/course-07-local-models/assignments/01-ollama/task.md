# Задание 01. Установка Ollama и первая модель

## Цель
Установить Ollama, скачать маленькую модель и получить первый ответ полностью локальной модели (без интернета и облака).

## Что сделать
1. Установите Ollama по документации: https://docs.ollama.com/
2. Проверьте версию: `ollama --version`
3. Скачайте модель: `ollama pull qwen2.5:3b`
4. Запустите чат: `ollama run qwen2.5:3b` — задайте 3 вопроса.
5. Выполните вызов без чата: `ollama run qwen2.5:3b "Назови столицу Франции."`
6. Проверьте список моделей: `ollama list`
7. Заполните ноутбук `assignment.ipynb` и `task.md`.

## Ответьте на вопросы
1. Как установить Ollama? Какая команда проверяет версию?
2. Как скачать модель и как её запустить?
3. Какие команды вы используете: pull, run, list, rm, ps?
4. Что такое «офлайн-работа» модели?
5. Какая трудность возникла (если была) и как вы её решили?
