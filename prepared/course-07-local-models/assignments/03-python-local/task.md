# Задание 03. Локальная модель из Python

## Цель
Вызывать локальную модель через Ollama API из Python: отдельные запросы, цикл вопросов, функция-обёртка.

## Что сделать
1. Убедитесь, что Ollama запущена и модель `qwen2.5:3b` скачана (`ollama list`).
2. Выполните шаги ноутбука `assignment.ipynb`.
3. Проверьте ответы на факты (например, 2+2=4).
4. Попросите агента написать улучшенную функцию `ask_local` и сравните.
5. Заполните ноутбук и `task.md`.

## Ответьте на вопросы
1. Как Python «общается» с локальной моделью?
2. Что означает `stream: False` в запросе?
3. Какие ошибки вы встретили и как их решили (ConnectionError, model not found)?
4. Проверьте: совпал ли ответ на «2+2» с 4?
5. Чем локальный вызов из Python похож на облачный API?

## Критерии приёма
- [ ] Первый запрос к модели выполнен, ответ получен.
- [ ] Функция `ask_local` написана и работает.
- [ ] Цикл из 3 вопросов выполнен, таблица собрана.
- [ ] Ответы проверены на факты.
- [ ] Ячейка «Мои выводы» заполнена (5 ответов).
- [ ] Файл скачан в формате `.ipynb`.
