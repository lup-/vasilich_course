# Задание 05. Локальная модель + агент

## Цель
Подключить агента (OpenAI Agents SDK) к локальной модели через Ollama и проверить работу инструментов без облака.

## Что сделать
1. Убедитесь, что Ollama запущена и модель скачана (`ollama list`).
2. Установите библиотеку: `pip install openai-agents`.
3. Настройте переменные окружения на локальный сервер (ноутбук, шаг 1).
4. Создайте агента и задайте вопрос.
5. Добавьте инструмент `sum_sales` и проверьте его вызов.
6. Проверьте, что агент работает без облака (`ollama ps`).
7. Заполните ноутбук и `task.md`.

## Ответьте на вопросы
1. Как подключить агента к локальной модели?
2. Что означают `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL` в этом контексте?
3. Вызываются ли инструменты агента на локальной модели? Приведите пример.
4. Проверьте: сумма 100+250+300 = 650 — совпала ли с агентом?
5. В чём разница между локальной и облачной моделью в работе агента?

## Критерии приёма
- [ ] Агент отвечает на локальной модели.
- [ ] Инструмент `sum_sales` работает, результат верный.
- [ ] Проверено, что модель запущена локально (ollama ps).
- [ ] Ячейка «Мои выводы» заполнена (5 ответов).
- [ ] Файл скачан в формате `.ipynb`.
