# Задания курса-07 «Локальные ИИ-модели и приватность»

Каждое задание — папка с ноутбуком `assignment.ipynb` (или `project_template.ipynb`) и файлом-инструкцией `task.md`.

## Как сдавать
1. Выполните задание: ноутбук в Google Colab + практика на компьютере (Ollama/LM Studio/Open WebUI).
2. Скачайте ноутбук: File → Download → .ipynb.
3. Заполните файл `task.md` (ответы на вопросы).
4. Сдайте оба файла (или ноутбук с выводами внутри).

## Список заданий
| № | Задание | Папка | Лекции |
|---|---|---|---|
| 01 | Установка Ollama и первая модель | `01-ollama/` | 04 |
| 02 | Выбор модели под своё железо | `02-choose-model/` | 03, 05 |
| 03 | Локальная модель из Python | `03-python-local/` | 06 |
| 04 | Open WebUI: свой веб-чат | `04-open-webui/` | 07 |
| 05 | Локальная модель + агент | `05-agent-local/` | 08 |
| 06 | Итоговый проект: локальный ИИ под вашу задачу | `06-final-project/` | 10–12 |

## Важно
- Для заданий 01, 03–05 нужен локальный запуск моделей (Ollama) — установите заранее.
- Некоторые ноутбуки требуют, чтобы Ollama была запущена, а модель скачана (проверка: `ollama list`).
- Код пишется через LLM-агента, но вы отвечаете за проверку результатов.
- Пункты «Выводы» обязательны: без них задание не засчитывается.
- Не отправляйте секретные данные в облачные модели (лекция 10).
