# 03. Ваше железо и выбор модели

> Семестр: 2 · Курс: «Локальные ИИ-модели и приватность» (course-07) · Время: ~2 часа

## Введение

Какая модель «потянет» ваш компьютер, зависит от трёх вещей: **ОЗУ** (оперативной памяти), **видеокарты** (GPU) и **процессора** (CPU). Научимся оценивать свой компьютер и выбирать подходящую модель.

## Три компонента

### ОЗУ (оперативная память)
Самый важный показатель для локальных моделей. Модель должна **помещаться в память** вместе с системой и контекстом.

- 8 ГБ ОЗУ → модели 1–3B, иногда 7B (сильно сжатые, Q4);
- 16 ГБ ОЗУ → модели 7–8B (Q4–Q5) уверенно;
- 32 ГБ ОЗУ → модели 13–32B;
- 64+ ГБ ОЗУ → большие модели (70B и более).

Правило: **модель + контекст + система должны уместиться в ОЗУ с запасом**.

### Видеокарта (GPU)
GPU сильно ускоряет работу: модель отвечает быстрее. Видеопамять (VRAM) определяет, какая модель поместится в видеокарту.

- 8 ГБ VRAM → модели 7–8B быстро;
- 16 ГБ VRAM → модели 13–32B;
- без GPU (только CPU) → модели работают, но медленнее.

Если GPU нет — модель работает на процессоре: медленнее, но для учебных задач терпимо.

### Процессор (CPU)
При отсутствии GPU процессор «тянет» модель. Важна память процессора и его скорость. Процессорные модели 7B дают ответ за десятки секунд — для курса нормально.

## Как узнать характеристики компьютера

**Linux:**
```bash
free -h        # ОЗУ
lscpu | grep "Model name"   # процессор
nvidia-smi     # видеокарта (если есть NVIDIA)
```

**Windows:** Диспетчер задач → «Производительность» (память, GPU).
**macOS:** меню  → «Об этом Mac» (память, чип).

Запишите: сколько ОЗУ, есть ли видеокарта и сколько в ней памяти, какой процессор.

## Как выбрать модель под своё железо

Пошагово:

1. Узнайте ОЗУ (например, 16 ГБ).
2. Оставьте ~2–4 ГБ на систему и контекст → доступно ~12 ГБ.
3. Выберите размер файла модели до ~12 ГБ → это модели 7–8B (Q4–Q5) или 13B (Q4, близко).
4. Если есть GPU с 8 ГБ VRAM → 7–8B будут работать быстро.
5. Для начала возьмите **маленькую модель** (3B) — проще, быстрее, меньше памяти.

## Примеры выбора

| Компьютер | Рекомендация |
|---|---|
| Ноутбук 8 ГБ ОЗУ, без GPU | 1–3B модели (например, qwen2.5:3b) |
| ПК 16 ГБ ОЗУ, GPU 8 ГБ | 7–8B (например, llama3.2:7b / qwen2.5:7b) |
| ПК 32 ГБ ОЗУ, GPU 12 ГБ | 13B, иногда 32B (Q4) |
| Сервер 64+ ГБ | 32B–70B |

## Что значит «модель подходит»

Модель «подходит», если:
- размер файла модели влезает в свободную память;
- отвечает с приемлемой скоростью;
- качество ответов достаточно для задачи.

Если не влезает — берём меньше параметров или сильнее квантование. Если медленно — меньше модель или GPU.

## Практика: оценка своего компьютера

> «Определи характеристики моего компьютера (ОЗУ, видеокарта, процессор) и предложи 3 подходящие модели из каталога Ollama с объяснением.»

Можно дать агенту вывод `free -h` и `nvidia-smi` — он подберёт варианты.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Модель «не влезает» | Меньше параметров, сильнее квантование, закрыть программы |
| Очень медленно | Меньше модель; использовать GPU; Q4 вместо Q8 |
| Память заканчивается | Закрыть браузер/программы, уменьшить контекст |
| Ошибка «out of memory» | Модель больше памяти; выберите другую |
