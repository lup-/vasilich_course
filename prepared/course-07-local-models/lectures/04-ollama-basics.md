# 04. Ollama: установка и первые модели

> Семестр: 2 · Курс: «Локальные ИИ-модели и приватность» (course-07) · Время: ~3 часа

## Введение

**Ollama** — самая простая программа для запуска локальных моделей. Одна команда — и модель скачана и работает из терминала. Начнём с установки и первого диалога с локальной моделью.

## Установка

Официальный источник: https://docs.ollama.com/

**Linux:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

**macOS / Windows:** скачать установщик с официального сайта Ollama.

Проверка установки:
```bash
ollama --version
```

## Скачивание и запуск первой модели

Выберите маленькую модель (подходит для среднего компьютера):

```bash
ollama pull llama3.2:3b
```

Команда `pull` скачивает модель (размер ~2 ГБ). Затем запуск:

```bash
ollama run llama3.2:3b
```

Откроется чат в терминале:

```
>>> Привет! Расскажи, кто ты.
```

Модель отвечает **без интернета** — данные не уходят на серверы. Выход из чата: `/bye`.

## Основные команды

| Команда | Что делает |
|---|---|
| `ollama list` | список скачанных моделей |
| `ollama pull <модель>` | скачать модель |
| `ollama run <модель>` | запустить модель (чат) |
| `ollama rm <модель>` | удалить модель |
| `ollama ps` | что сейчас запущено |

Примеры моделей (от маленьких к большим):
- `qwen2.5:3b` — маленькая, быстрая;
- `llama3.2:3b` — маленькая, хороша для тестов;
- `llama3.2:7b` — средняя (нужно ~8–16 ГБ ОЗУ);
- `qwen2.5:7b` — средняя, хорошо для задач;

## Простой вызов без чата

Модель можно попросить ответить одной командой (без интерактивного чата):

```bash
ollama run llama3.2:3b "Напиши краткий план отчёта по продажам."
```

Это удобно для автоматизации: любой скрипт может «спросить» локальную модель. Из Python — в лекции 06.

## Что важно знать

- Модели скачиваются с каталога Ollama (модели открытые, из Hugging Face).
- Размер модели показывает `ollama list` — следите за свободным местом на диске.
- Если памяти не хватает — Ollama предупредит; выберите модель меньше (лекция 03).
- Всё работает офлайн после скачивания.

## Практика через агента

> «Выполни в терминале: ollama list. Скачай модель qwen2.5:3b и запусти её с вопросом „придумай три идеи для учебного проекта по анализу данных“. Покажи полный вывод.»

Агент выполнит команды (или вы сами) и покажет результат.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `ollama: command not found` | Не установлена / не перезапущен терминал |
| Медленное скачивание | Большая модель; подождать или выбрать меньше |
| Модель отвечает медленно | Меньше модель, Q4; закрыть тяжёлые программы |
| Не хватает памяти | Модель больше ОЗУ; выбрать 1–3B |
| Нет интернета | Модель уже скачана — работает офлайн |

## Задание на дом

5. Выполните `ollama list` и запишите занятое место.
