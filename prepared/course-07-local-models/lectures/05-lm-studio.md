# 05. LM Studio: локальные модели с интерфейсом

> Семестр: 2 · Курс: «Локальные ИИ-модели и приватность» (course-07) · Время: ~2 часа

## Введение

Ollama — терминал. **LM Studio** — та же идея, но с окнами: скачивание моделей, чат, настройки — всё через интерфейс. Отлично подходит, если терминал неудобен.

## Установка

Скачайте установщик с официального сайта: https://lmstudio.ai/

Подходит для Windows, macOS, Linux. Установите как обычную программу.

## Интерфейс (главные окна)

- **Каталог моделей (Discover/Models)**: поиск и скачивание моделей из открытых источников (Hugging Face и др.).
- **Чат (Chat)**: общение с выбранной моделью.
- **Настройки модели**: контекст, GPU/CPU, параметры ответа.

Всё управление мышью — без команд.

## Скачивание модели

1. Откройте каталог моделей.
2. Найдите модель (например, `llama 3.2 3B` или `qwen 2.5 7B`).
3. Выберите **квантование** (лекция 02). Для среднего компьютера — `Q4` или `Q5`.
4. Нажмите «Download» (скачивание занимает время — модель весит гигабайты).
5. После скачивания — «Load» (загрузить) и «Chat».

## Чат и настройки

В окне чата:
- выберите загруженную модель;
- задавайте вопросы;
- смотрите ответы.

Полезные настройки:
- **Context length** — длина контекста (лекция 02): начните с 4096;
- **GPU offload** — задействовать видеокарту (если есть) для скорости;
- **Temperature** — «фантазия» ответов (ниже — строже, выше — креативнее).

## Локальный сервер (важно для курса-06)

LM Studio может запускать локальный сервер: другие программы (Python, агенты) обращаются к модели как к API. Это аналог «облачного» сервиса, но на вашем компьютере.

Как включить: в интерфейсе есть раздел «Local Server» (или Developer) — там запускается сервер с адресом вида `http://localhost:1234`. Подробности — лекция 06.

## Ollama или LM Studio?

| | Ollama | LM Studio |
|---|---|---|
| Стиль | терминал | окна |
| Удобство | команды | мышь |
| Автоматизация | легко из скриптов | через локальный сервер |
| Кому подходит | кто любит терминал | кто хочет интерфейс |

Можно использовать оба: Ollama для автоматизации, LM Studio для экспериментов.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Модель не скачивается | Проверить интернет/место на диске; выбрать файл меньше |
| Медленно | Меньше модель/квантование; включить GPU |
| Модель «не отвечает» | Нажать Load для модели перед чатом |
| Непонятные файлы (GGUF, Q4…) | Это квантование/формат; Q4–Q5 — нормальный выбор |

## Задание на дом

1. Установите LM Studio.
2. Скачайте маленькую модель (3B) с квантованием Q4–Q5.
3. Загрузите модель и побеседуйте: 3 вопроса, запишите ответы.
4. Настройте контекст (4096) и temperature (0.7) — посмотрите, как меняются ответы.
5. Найдите раздел «Local Server» и запустите его (без настройки) — запишите адрес.
