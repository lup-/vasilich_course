## Ollama как «локальный сервер»

Когда Ollama установлена, она уже работает как сервис на вашем компьютере (по адресу `http://localhost:11434`). Любая программа может «спросить» модель через этот адрес. Это похоже на облачный API, но всё локально.

## Простой вызов из Python

```python
import requests

url = "http://localhost:11434/api/generate"
data = {
    "model": "qwen2.5:3b",
    "prompt": "Объясни, что такое локальная ИИ-модель, в трёх предложениях.",
    "stream": False,
}

resp = requests.post(url, json=data)
result = resp.json()
print(result["response"])
```

Что происходит: Python отправляет запрос к локальной модели, она отвечает, ответ печатается. Код простой — его можно попросить написать агента.

## Разбор кода

- `url` — адрес локального сервера Ollama;
- `"model"` — какая модель отвечает;
- `"prompt"` — ваш вопрос;
- `"stream": False` — ждать полный ответ (а не «поток»);
- `resp.json()` — ответ в виде JSON;
- `result["response"]` — сам текст ответа.

## Обработка ошибок

Если Ollama не запущена или модель не скачана — код упадёт. Добавим проверки:

```python
import requests

try:
    resp = requests.post(
        "http://localhost:11434/api/generate",
        json={"model": "qwen2.5:3b", "prompt": "Привет!", "stream": False},
        timeout=120,
    )
    if resp.ok:
        print(resp.json()["response"])
    else:
        print("Ошибка сервера:", resp.status_code)
except Exception as e:
    print("Не удалось связаться с Ollama:", e)
    print("Проверьте: ollama установлена? модель скачана? (ollama list)")
```

## Несколько вопросов подряд (список)

```python
import requests

questions = [
    "Назови столицу Франции.",
    "Сколько будет 2+2?",
    "Переведи на английский: «доброе утро».",
]

for q in questions:
    r = requests.post(
        "http://localhost:11434/api/generate",
        json={"model": "qwen2.5:3b", "prompt": q, "stream": False},
    ).json()
    print("Вопрос:", q)
    print("Ответ:", r["response"].strip(), "\n")
```

Так можно автоматически обработать много вопросов. Замечание: локальная модель может ошибаться в фактах — результаты проверяйте (лекция 11 курса-06).

## Применение на практике

Из Python локальную модель можно использовать для:
- пакетной обработки текстов (резюме, классификация);
- составления отчётов из данных (вместе с pandas);
- подсказок и проверки текстов;
- сборки агентов (лекция 08).

## Частые проблемы

| Проблема | Решение |
|---|---|
| `ConnectionError` | Ollama не запущена — запустите (лекция 04) |
| «model not found» | Модель не скачана: `ollama pull qwen2.5:3b` |
| Долгий ответ | Меньше модель; меньше контекст; терпеливее таймаут |
| Кодировка/русский текст | Проверить кодировку терминала/ноутбука (UTF-8) |
