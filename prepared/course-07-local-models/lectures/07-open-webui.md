# 07. Open WebUI: веб-интерфейс для локальных моделей

> Семестр: 2 · Курс: «Локальные ИИ-модели и приватность» (course-07) · Время: ~3 часа

## Введение

**Open WebUI** — веб-интерфейс, который подключается к локальным моделям (Ollama, LM Studio) и даёт «личный ChatGPT» на вашем компьютере: красивые чаты, история, несколько моделей в одном окне.

## Что это и зачем

Open WebUI — программа, которая запускается у вас и открывается в браузере по адресу `http://localhost:8080`. Она умеет:

- подключаться к локальным моделям (Ollama и др.);
- давать чат-интерфейс с историей;
- переключаться между моделями;
- настраиваться под себя.

Главное: **всё работает на вашем компьютере** — данные не уходят в облако (лекция 10).

## Установка

Самый простой способ — через Python:

```bash
pip install open-webui
```

Запуск:

```bash
open-webui serve
```

В браузере откройте http://localhost:8080 . При первом входе создайте аккаунт администратора (локальный, на вашем компьютере).

**Важно:** точные команды установки и зависимости (Docker/Python) зависят от версии — сверяйтесь с документацией https://docs.openwebui.com/ и давайте команды агенту, который сверит их с источником.

## Первый вход и настройка

1. Создайте локальный аккаунт (первый пользователь — администратор).
2. В настройках подключите источник моделей — Ollama (адрес `http://localhost:11434`).
3. В списке моделей появятся скачанные (например, `qwen2.5:3b`).
4. Начните чат — выберите модель и задайте вопрос.

## Работа в чате

- Выбор модели — вверху окна чата;
- история чатов сохраняется;
- можно создавать несколько чатов с разными моделями;
- есть настройки ответа (temperature, контекст).

Интерфейс похож на привычные веб-чаты — осваивается за пару минут.

## Подключение моделей

Open WebUI сама по себе не хранит модели — она «оборачивает» Ollama/LM Studio:

- Ollama: модели скачиваются в Ollama (лекция 04) и появляются в Open WebUI;
- LM Studio: включить локальный сервер (лекция 05) и указать его адрес.

Если модель видна в `ollama list` — она станет доступна в Open WebUI после подключения источника.

## Для чего это вам

- «Личный помощник» с красивым интерфейсом без отправки данных в облако;
- удобный способ попробовать несколько моделей в одном окне;
- основа для корпоративного решения «ИИ внутри компании» (данные не покидают сеть).

## Частые проблемы

| Проблема | Решение |
|---|---|
| Страница не открывается | Проверить, что `open-webui serve` запущен, порт 8080 |
| Моделей нет | Подключить источник (Ollama), проверить `ollama list` |
| Не запускается (Python) | Сверяться с документацией; версия Python, зависимости |
| Забыли пароль | Локальный аккаунт — пересоздать (см. документацию) |
