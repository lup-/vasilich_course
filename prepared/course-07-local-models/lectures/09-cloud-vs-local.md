# 09. Сравнение: локальные vs облачные

> Семестр: 2 · Курс: «Локальные ИИ-модели и приватность» (course-07) · Время: ~2 часа

## Введение

Выбирать между локальной и облачной моделью — значит взвешивать качество, скорость, стоимость и приватность. Научимся сравнивать их системно и делать обоснованный выбор.

## Критерии сравнения

| Критерий | Облачная | Локальная |
|---|---|---|
| Качество | высшее (последние версии) | зависит от размера модели |
| Скорость | быстрая (мощные серверы) | зависит от вашего железа |
| Стоимость | по подписке/за запрос | бесплатно после установки (но есть железо/электроэнергия) |
| Приватность | данные уходят в облако | данные на вашем компьютере |
| Интернет | нужен | не нужен после скачивания |
| Установка | не нужна | нужна (этот курс) |

## Качество

Облачные топ-модели решают самые сложные задачи. Локальные модели меньшего размера — «достаточно хороши» для типовых задач: суммаризация, перевод, шаблоны, простые рассуждения.

Проверка на практике (сделайте в задании):

1. Задайте **один и тот же** вопрос облачной и локальной модели.
2. Сравните ответы: полнота, точность, стиль.
3. Оцените по шкале «хорошо/средне/плохо» для своей задачи.

Пример вопроса: «Объясни, чем отличается аспирин от парацетамола, в трёх предложениях».

## Скорость

- Облачная: ответ за секунды (зависит от сервера).
- Локальная: маленькая модель (3B) — секунды; средняя (7B) на CPU — десятки секунд; на GPU — быстрее.

Измерьте: сколько секунд уходит на один ответ. Для интерактивной работы важна скорость, для пакетной обработки — менее критична.

## Стоимость

- Облачная: тариф или оплата за токены. При большой нагрузке — заметно дорого.
- Локальная: бесплатные модели, но нужен компьютер (если он уже есть — расходы только на электроэнергию).

Детальный расчёт — в лекции 11 (экономика). Ключевой вопрос: **часто ли вы делаете запросы?** Если часто и много — локально может окупиться.

## Приватность

Самое важное различие:

- **Облачная**: ваши тексты и файлы обрабатываются на серверах компании. Даже в «безопасном» режиме данные покидают ваш компьютер.
- **Локальная**: данные не уходят никуда.

Для документов компании, личной переписки, медицинских/финансовых данных — локальная модель часто единственный допустимый вариант. Подробнее — лекция 10.

## Что выбрать: решающая таблица

| Ваша ситуация | Выбор |
|---|---|
| Секретные/личные данные | Локальную |
| Нужно максимальное качество | Облачную |
| Нет интернета | Локальную |
| Мало запросов, нужен простой помощник | Любую (по удобству) |
| Много запросов, экономия | Локальную |
| Слабый компьютер, но нужна мощная модель | Облачную |
| Обучение/тренировка | Локальную (бесплатно) |

## Гибридный подход

Не обязательно выбирать одно: можно использовать и то, и то.

- рутинные/повторяющиеся задачи → локальная модель;
- сложные разовые задачи → облачная;
- секретные данные → только локальная.

Такой «гибрид» часто оптимален: экономия без потери качества.

## Практика: объективное сравнение

Сделайте таблицу сравнения для своей задачи:

1. Один вопрос, одинаковый для обеих моделей.
2. Запишите: качество (оценка), скорость (секунды), стоимость (рубли/запрос или 0).
3. Сделайте вывод: какая модель подходит для вашей задачи.

## Частые проблемы

| Проблема | Решение |
|---|---|
| «Локальная хуже, значит всё» | Для простых задач разница мала; мерить по своей задаче |
| «Облачная дорого» | Посчитать объём запросов; возможно, гибрид дешевле |
| «Локальная медленно» | Меньше модель, GPU, пакетная обработка вместо интерактива |
| Сравнение «в голове» | Делать сравнение на одинаковых вопросах с замерами |

## Задание на дом

1. Выберите 3 вопроса для сравнения (факт, рассуждение, творчество).
2. Задайте их облачной и локальной моделям. Запишите ответы.
3. Оцените качество по шкале и измерьте время ответа.
4. Заполните таблицу сравнения и сделайте вывод: что выбрать для вашей типовой задачи.
5. Решите: когда вы бы использовали гибридный подход.
