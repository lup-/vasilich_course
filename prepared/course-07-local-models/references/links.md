# Ссылки-источники: курс-07 «Локальные ИИ-модели и приватность»

Все ссылки проверены (webfetch, работающий контент). Группировка по темам лекций.

## Локальные модели (лекции 01–04)
- Ollama — запуск моделей локально (документация): https://docs.ollama.com/
- LM Studio — локальные модели с интерфейсом: https://lmstudio.ai/
- Каталог открытых моделей (Hugging Face): https://huggingface.co/models

## Интерфейсы (лекции 05–07)
- Open WebUI — веб-интерфейс для локальных моделей: https://docs.openwebui.com/
- Open WebUI (официальный сайт/демо): https://openwebui.com/

## Связка с агентами (лекция 08)
- OpenAI Agents SDK (можно подключать локальные модели): https://openai.github.io/openai-agents-python/
- Gemini CLI (терминальный агент): https://github.com/google-gemini/gemini-cli
- MCP, протокол подключения инструментов: https://modelcontextprotocol.io/

## Облачные сервисы для сравнения (лекция 09)
- Google AI Studio (бесплатное тестирование моделей): https://aistudio.google.com/
- Groq (бесплатный доступ к моделям): https://console.groq.com/
- OpenAI платформа: https://platform.openai.com/docs

## Приватность (лекция 10)
- Официальная документация Ollama (локальность данных): https://docs.ollama.com/
- Open WebUI (self-hosted, данные на вашем сервере): https://docs.openwebui.com/

## Примечания
- Ссылка https://chatgpt.com не проверяема автоматически (403, JS-защита), но ресурс известен.
- Локальный запуск не требует API-ключей и сети — все данные остаются на вашем компьютере.
